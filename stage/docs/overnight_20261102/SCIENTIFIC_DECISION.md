# 今夜需要回答的问题及论文证据边界

## 为何五米成功不能推出六米成功

当前五米结果来自固定场景/起终点族的闭环验收，不能推出沿同一路线简单再走一米。目标距离和方位从第一步就进入Actor当前观测及历史目标字段，因此六米目标会改变整段反馈轨迹，遇到的障碍相位、余量和最后接近行为也会变化。地图相同不意味着策略输入分布相同。

已有证据支持两个可分的问题：LEFT六米主要接触，RIGHT主要原时限内接近不足；T299能扩大右侧成功集合至10/27，但同时旧五米dev24接触。更新造成的旧任务退化确实存在，不能据此把六米失败全部归为灾难性遗忘——冻结安全T255在没有任何新更新时，六米本来就是0/54。场景交互和算法覆盖/目标条件泛化都有关，尚无单一根因或场景不可达的证明。

T304的动作分支说明真实动作能够改变后续轨迹和回报，但该小值头留出动作误差比盲头更差，不能指导策略。相同碰撞事件的回报增加可能只代表更晚碰撞，不能当安全路线学会。旧20接受集合不是“禁止所有有用更新”的证明：曾有被拒绝候选原六米同样失败；完整新路线能力和旧路线保持必须分别测量。

## T308在区分什么

本项从同一安全父Actor采当前明确iid策略的真实六米轨迹，让价值学习对象、动作分支的随机续行和评价的占用定义一致。两头同容量、同初值、同批次和更新数，对照只删除新动作输入。整reset家族留出防止仅记住一条轨迹；真实首动作干预检查预测能否分辨控制作用。重生不是新独立样本，四条noise流也不是四次独立训练。

若预测与控制双门槛失败，只能说明本次固定有限数据/函数类/预算下的头不足以指导Actor，不足以否定整个CRL方向、判定环境无解或证明需要无限训练。届时优先看动作效应尺度、训练覆盖、坐标目标占用与首次安全命中的差别、观测别名，以及有限噪声反事实排序的不确定性；不事后换核宽/筛选容易病例/增加该头步数。

若双门槛通过，也只是进入一次受控Actor提案的依据，仍非通用Q或安全证书。Actor更新后必须重新测旧275和原六米54，全部过再16fresh与78独立原生重载。头变准、探索出现成功都不能替代导航门槛。

## 可作为研究问题，尚不能作为已成立创新

[CRL](https://arxiv.org/abs/2206.07568)与[SGCRL](https://arxiv.org/html/2408.05804)已有未来占用对比价值和大规模实现；RLOO、课程、保持回放、投影和Actor梯度也不是本项目原创。工程合同、备份和更严验收是可信实验基础，不单独构成顶刊算法贡献。

值得继续研究的是：有终止/接触的有限时域无地图导航中，目标条件价值如何在**完整因果目标历史**下支持可验证的动作改进，同时保持旧路线能力。要成为论文方法，需要明确价值目标和策略改进的关系，提出超出现有近邻的机制，并以控制验证、消融和跨起终点/跨场景/多训练seed证据支持。当前只完成了问题定位与工程实现，T308结果尚未知，不能提前宣称原创或达到顶刊标准。

10米和全图是后续独立任务：六米严格通过之后才逐级七/八米；全图还要注册未见起终点/环境分布和比较方法。两条固定长路线不会自动变成全图泛化。
