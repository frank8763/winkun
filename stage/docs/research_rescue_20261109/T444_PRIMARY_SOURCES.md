## 对T444的具体推导（项目建议，非论文原结论）

冻结T255与T443困难采样最终Actor，固定8个已知失败起态；两策略各自独立闭环，共16条不同策略/任务轨迹，另16条精确重生只核验确定性，不充作独立样本。不追加训练、起态或噪声网格，不用诊断结果宣称完整旧275恢复或fresh16/reload78通过。

**比较对象必须包含历史。** 令`F0(H)`为T255按其逐步hidden-reset规则读取实际观测历史所得动作，`F1(H)`为T443从自身规定h0重建carry所得动作。对两条实际历史`H0,H1`，分别计算`Aij=Fi(Hj)`的2×2响应；历史里的真实前动作、时钟、hold及120维观测保持原值。不得将T255的hidden塞入T443，或只给同一当前观测就称同一完整控制器状态；这里衡量的是“同历史上的策略函数差”，包含架构与记忆规则差异，不能命名为纯参数变化。

在共同存活且物理时间对齐的前缀上，逐drive/steer同时报告裁剪前输出和实际命令；用两种加减顺序给出对称恒等式：

```text
闭环动作差 D = A11 − A00
同历史策略响应项 P = [(A10−A00) + (A11−A01)] / 2
历史响应项 H = [(A01−A00) + (A11−A10)] / 2
D = P + H
```

保留两顺序各自的原项，并核对恒等式残差；报告每项时序、逐通道RMS/最大值。两项可相互抵消，范数比不是可相加的“原因百分比”，接近零的分母不报放大倍数。`H`包含状态、感知和记忆历史的共同变化；2×2离线响应不生成四条新的物理反事实，因此不是独立因果效应。

闭环另报预注册阈值下首次动作/位置/航向偏离时刻、碰撞对象和原生终止；同物理时刻及碰撞前固定窗口列出车速、实际舵角/舵速、命令与当前几何净空。几何净空的对象范围和采样分辨率须注明，不能把决策端点最小值称为连续物理最小值。终止后不补造轨迹、不跨不同物理时刻配对。

“同历史差很小但轨迹偏离大”仅与反馈放大解释相容；“起步动作已变”仅定位策略响应变化更早。两者均不排除覆盖不足、局部控制边界、记忆状态或多次历史训练的共同影响；若要建立某因素的物理因果作用，须另立单一受控干预，不能在T444中顺手追加。

以上使用的是已有分布漂移、稳定性与后向迁移思想，加上可核验的代数分解；不作为原创算法或新的安全保证。
