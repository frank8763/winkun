## 当前证据及必须收窄的解释

[现有复盘](../review_20261109/WHY_STILL_FAILS.md)显示：T425 A宽六米54/54、旧264/275；最近完整T437宽52/54、旧271/275，共323/329，仍有六项失败。T439四轮面板每次修5–6项、丢1–2项，全部回退，未测完整329；不能给它填写新的52/54。当前循环是**共享参数提案产生能力交换，而逐轮旧成功零失守的门阻断积累**；这还不能确定冲突来自数据、观测、容量还是优化。T440只有执行预算失败，没有功能约束有效性的科学结论。

**修正先前解释的范围：self-KL起始梯度为零是正常性质，不能据此否定PPO/TRPO。** 令参考为θ₀，光滑策略有

`KL(πθ₀ || πθ₀+Δ) = ½ ΔᵀFΔ + o(||Δ||²)`。

一阶导为零，二阶Fisher通常非零。[TRPO §6–7](https://proceedings.mlr.press/v37/schulman15.pdf)正是利用KL Hessian、共轭梯度及实际线搜索；[PPO §3–4](https://arxiv.org/pdf/1707.06347)利用概率比裁剪或自适应KL罚项，首步概率比为1也正常。现有证据仅揭示“用当前自匹配损失的一阶梯度构造单个保护半空间”首步没有方向信息；平均保持和Adam后的有限位移也未保证逐任务闭环。它不证明规范信赖域无效，也不证明标准PPO提供全329逐项不退化保证。

## 十篇一手资料：支持什么、不能外推什么

链接均于本次打开核验；查看了全文相应方法/实验段落，不只依赖摘要。

| 一手资料 | 与当前问题直接相关的结论和边界 |
|---|---|
| [Schulman等，TRPO，ICML 2015](https://proceedings.mlr.press/v37/schulman15.html) | 二阶KL约束与候选线搜索有别于初始KL梯度投影；实用平均KL是理论方案的近似。 |
| [Schulman等，PPO，2017](https://arxiv.org/abs/1707.06347) | 在当前采样批次做有限多轮代理目标更新；不支持把任意旧教师轨迹直接混成当前on-policy PG。 |
| [Haarnoja等，SAC，ICML 2018](https://proceedings.mlr.press/v80/haarnoja18b.html) | replay状态/转移训练价值，Actor在这些状态采样当前策略动作；off-policy不等于未知动作价值可靠。 |
| [Rusu等，Policy Distillation，2015/2016](https://arxiv.org/abs/1511.06295) | 独立教师可经监督合并知识；原多任务实验使用game label和独立controller输出层，不能当成Stage无路由双输出头的直接成功证据。 |
| [Schwarz等，Progress & Compress，ICML 2018](https://proceedings.mlr.press/v80/schwarz18a.html) | active column先学、再向knowledge base蒸馏并用online EWC保持；面向连续任务且无需旧任务数据。不是每一步都要求旧任务闭环完全不变。 |
| [Hessel等，Multi-task RL with PopArt，2018](https://arxiv.org/abs/1809.04474) | 按任务归一化价值目标/优势并补偿输出层，减少奖励尺度支配；Actor可不接任务ID，训练期价值头用任务ID。不能解决缺信息或矛盾标签。 |
| [Yu等，PCGrad，NeurIPS 2020](https://arxiv.org/abs/2001.06782) | 投影负点积任务梯度，针对梯度干扰；梯度几何改善不是有限步后所有闭环任务不退化的证书。 |
| [Farajtabar等，OGD，AISTATS 2020](https://proceedings.mlr.press/v108/farajtabar20a.html) | 约束的是历史输出Jacobian方向，其局部意义不同于拟合已为零的loss梯度；有限锚点不能覆盖整个未来访问分布。 |
| [Ball等，RLPD，ICML 2023](https://proceedings.mlr.press/v202/ball23a.html) | 区分离线池和在线池、对称混采并控制critic外推；单纯塞满旧数据的replay可限制后期提升。50/50是其基准起点，不是Stage最优比例定理。 |
| [McLean等，Multi-Task RL Enables Parameter Scaling，2025预印本](https://arxiv.org/html/2503.05126v3) | 等参数量普通MLP可超过复杂架构，critic扩容收益更明显；使用分任务等量replay、one-hot任务ID和Meta-World特权状态，短程密集奖励结果不能直接迁移到Stage。 |

## 能打破循环的一条主线

**先回答“单Actor能否从一开始共同学习这些行为”，再回答“旧策略怎样继续学”。** Stage保存了旧数据，任务也可共同采样，因而不必先把自己限制成无法访问旧任务的持续学习问题。当前“强旧策略起步＋少量修复＋每轮硬回退”不是干净从头联合学习反例。

主对照只使用普通多任务PPO：A从固定随机初始化联合学习；B从固定研究Actor起步，采用相同联合任务分布、网络和预算。两者都不做逐轮零失守回退，研究副本允许中途能力变化，部署仍保持safeT255且最终严格验收不变。此项改变必须在未来协议明确授权，不能借本报告取消现有门。329是验收病例，不应简单按轨迹帧数混采：先均衡距离/左右/任务组，再覆盖成功历史、失败学生实际访问态和合法恢复；长回合不能凭帧数获得更大权重。旧history自目标只维持旧函数，不能教会原来失败的恢复。

Actor保持单一合法观测→双动作头；Actor与critic使用独立骨干，避免价值/辅助梯度暗中改变策略。T439仅开放已有参数，不是新增容量试验。只有同数据联合拟合已经暴露容量瓶颈，才预先选一个普通MLP扩容；若使用actor-critic，则单独检查critic拟合/校准，不能只加Actor或复杂模块。PopArt仅在确有组间回报尺度差异时有针对性；PCGrad与OGD暂作解释工具，不与新结构同时堆叠。若唯一诊断指向约束几何，再固定同数据/PG提案，比较平均保持与关键窗口实际最大输出变化约束，并对Adam后候选做非线性读回；更新全压成零仍判失败。

若预算决定必须大量利用历史转移，才以SAC替换PPO作为**后续单独路线**：固定任务权重及离线/在线池比例，记录每组最近学生数据占比、接触/超时与终止语义，限制更新/数据比，并验证critic在当前Actor动作附近的可靠性。历史成功池、旧失败池和新学生池不能被“统一replay”名称掩盖分布差异。[SAC §4](https://proceedings.mlr.press/v80/haarnoja18b/haarnoja18b.pdf)、[RLPD §4–5](https://proceedings.mlr.press/v202/ball23a/ball23a.pdf)支持这一区分。切换SAC同时增加容量、改奖励再加PCGrad，会失去可判定性。

独立教师→单学生是条件备选：若单任务能学、联合RL持续互相破坏，可把“获取新能力”和“压缩共存”分开；教师仅用于训练，所有教师交互计入总预算，最终学生独立运行。原Rusu/P&C提供已有框架，连续动作回归和本项目训练期教师整合只是适配，不能宣布原创；蒸馏误差小仍须自主闭环验收。

## 最小决定性对照与停止规则

| 顺序 | 最小比较 | 结果怎样改变判断 |
|---|---|---|
| 先辨信息/数据 | 整history按家族划分；核对相近合法输入是否有互斥教师标签，分别检查各任务拟合与联合拟合 | 标签不同未必矛盾，必须有合法恢复/后续行为依据；若必要区别只存在未观测状态，再改优化器无从解决。 |
| 再辨联合学习 | 上述A从头与B warm-start，匹配任务/网络/新增交互/更新和验收预算，明确B历史预训练成本 | A成功B失败支持路径依赖；两者失败只说明该固定资源设置未解决，不能断言任务无解。 |
| 仅一个条件诊断 | 联合拟合差而各任务拟合好：只测一次MLP容量；拟合好而自主失败：只补学生分布恢复；实际Adam位移破坏约束：同批比较方向与实际位移 | 数据冲突、容量不足、闭环分布偏移和optimizer几何得到不同证据；负梯度余弦不能单独定因。 |

完整329只决定最终候选是否合格，面板用于开发且不冒充全测；真正fresh留出不参与选模型。预先固定最终断点、交互/更新/墙钟/储存上限，不挑最优seed、不借新编号补预算。若无合法恢复标签、输入语义不一致、critic失准或预算不足，停在相应结论；主对照与一个由结果触发的诊断后仍无可保留联合收益，则停止该路线，不再同时追加PPO/SAC/蒸馏三套作业。标准组件、保护门和数据工程均不是新算法贡献；原创性只能来自相对这些强基线的可重复新增结果与机制证据。
