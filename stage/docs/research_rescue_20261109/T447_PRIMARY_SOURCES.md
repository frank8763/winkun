# T447：联合拟合梯度与时段误差的一手依据

2026-11-09。仅Stage；本笔记只查论文及作者代码，无模型计算、原生交互或优化器更新。[T446复核](T446_FINDINGS_AND_NEXT.md)：1500步BC后旧LEFT5动作RMSE=.052706、闭环14/35，宽53/54；PPO实际0轮。以下支持诊断问题，不构成本项目机制成立或新颖性证明。

## 三项一手来源

1. **PCGrad，Yu等，NeurIPS 2020。** 负内积表示两任务梯度局部冲突，方法去掉冲突投影后再合并；论文还讨论梯度量级差异及曲率，不能只凭一个负余弦断言失败根因。作者代码先逐任务求梯度，再依次投影并求和。支持保存十组完整梯度、范数、余弦及原权重合成方向；投影仅作离线对照，不在本轮接优化器。[论文](https://arxiv.org/abs/2001.06782)、[作者代码](https://github.com/tianheyu927/PCGrad/blob/master/PCGrad_tf.py)

2. **GradNorm，Chen等，ICML 2018，§3。** 对`L=ΣwᵢLᵢ`，权重直接缩放各任务反传梯度；算法结合梯度范数和相对训练速率调整权重。它支持同时核算采样权重、原始/加权范数与损失变化，不能由终点loss大小反推出任务获得的学习份额。T446声明旧组总权重.5、宽组.5；八旧组和两宽组均匀抽样时，每宽组期望权重是每旧组四倍，但这本身不是错误或退化因果证明。[会议论文正文](https://proceedings.mlr.press/v80/chen18a/chen18a.pdf)

3. **TaSIL，Pfrommer等，NeurIPS 2022，§1、§3–4。** 策略小误差可经状态反馈累积；其理论以专家的增量输入到状态稳定性等条件为前提，并匹配策略的高阶Taylor项。它支持区分教师状态动作误差与学生闭环漂移；本项目未验证这些稳定性条件，单纯时段加权也不是TaSIL复现。论文没有推出“前2秒必然最关键”。[作者正文](https://arxiv.org/html/2205.14812v2)、[正文指定作者实现](https://github.com/unstable-zeros/TaSIL)

## 对T447的有限推导

- 固定已有219条成功history及同一T446末模型，按原十组和真实物理时间记录执行动作残差；首2秒/其余只是预先固定的定位切片，同时保留全时间序列，不能事后挑窗口。
- 梯度用原BC代理损失及完整因果hidden/BPTT重算；执行动作RMSE单列，二者不能混称。报告原权重与等组权重的合成方向，及每组`gᵢ·g合成`；正值只意味着沿负合成梯度的无穷小欧氏步一阶下降，不保证有限步、Adam或闭环改善。投影后的方向同样逐组检查，不能默认多任务全部改善。
- 单一末模型梯度只能描述当前位置，不能重建1500步训练全程；固定成功历史也不包含学生偏离后的恢复标签。诊断为0原生/0Adam，不改变参数和原门槛。
- 若误差时段和方向证据支持，再独立注册时段加权BC对原权重BC的匹配对照：同父Actor及Adam状态、同数据/批序/新预算，仅改一个权重因素；之后仍须原起点闭环检验。若证据不支持，不自动追加训练，不放宽T446准入门，不将本轮称PPO实验或算法创新。

实现范围补注：T447正式解析对照为“仅旧LEFT5权重×4后重新归一化”与原权重，不执行十组等权或PCGrad投影；相关论文只提供诊断依据。成熟Adam方向包含原clip-norm1、已有moments/step/lr，仍只是一阶解析预测，不调用optimizer.step。
