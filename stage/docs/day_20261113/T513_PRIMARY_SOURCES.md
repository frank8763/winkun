# T513 primary source and scope

2026-11-13 inspected CMU publisher description and technical-report geometry text for R. Craig Coulter, [Implementation of the Pure Pursuit Path Tracking Algorithm, CMU-RI-TR-92-01](https://publications.ri.cmu.edu/storage/publications/pub_files/pub3/coulter_r_craig_1992_1/coulter_r_craig_1992_1.pdf). The report derives curvature from goal offsets and lookahead distance and discusses parameter sensitivity. Our 2sin(error)/distance calculation is the related point-target curvature relation; this test has only the final goal, no planned path/lookahead waypoint or obstacle model. Current body pose is not an exact rear-axle frame. The report does not establish success of this teacher or a collision guarantee.

Speed reduction/inverse native command mapping are project engineering choices fixed before native testing, not an original method or a claimed reproduction of the CMU controller. True simulator parameters are saved and used; no replacement simulator or faster dynamics. This is a training-only data acquisition experiment, not a hybrid deployed navigator or a new RL update. A subsequent learned single Actor would require its own independent closed-loop and retention checks.

DAgger's learner-distribution motivation remains relevant ([Ross et al., 2011](https://proceedings.mlr.press/v15/ross11a.html)), but one teacher recovery is not DAgger training, a no-regret algorithm, a deterministic student gain or a paper novelty result. T512 failures establish only that four fixed iid suffixes did not recover this same actual state.
