# T532/T533后的明确决策

2026-11-13，两个有界实验均已结束，独立审计/全部原件远端逐成员SHA/源码精确根树完成。当前没有Actor训练或MuJoCo仿真运行。

## 已得到的结果

T532：四个预定1秒窗口的未拟合准静态模型全部不合格。最大位置误差分别0.350592/0.188538/0.396281/0.406032米。源策略完整因果动作/hidden精确重建，排除了该次计算中的重建错误；不能据此排除其他工程问题或解释整个导航失效。

T533：574条既有训练转移，一次固定ridge0.001线性速度响应辨识；前40%训练、5秒隔离、后段连续1秒自递归预测。验证152窗，79窗同时达到位置2cm/航向1deg，73窗未过。逐族：旧成功13/20、旧失败9/18、新父失败20/72、新候选成功37/42；各族最差位置5.331/3.635/12.689/4.149cm，均未满足全部窗口门槛。原始数组、数据切分、模型系数、递归预测已独立重算一致。

两项的验证窗口集合不同，不能把最大误差相减当作公平模型改进率。79/152是时间窗模型精度合格数，不是79次导航成功、独立样本或成功率提升。T533是已有轨迹时间块验证，部分原轨迹曾被观察，不称未消费留出。一次辨识和一次审计重构分开，0Actor/Value/策略梯度/新native。

## 本轮停止条件已触发

拒绝把这两个模型接入Actor。继续增加ARX阶数/拟合次数/放宽阈值不是已授权的自动接力，不执行。T507旧8/8+field11/24接受最佳和所有研究失败保持原字节；本轮没有新增自主导航成绩。

这没有检验“原生正确物理梯度能否解决保持/新学习冲突”，只否定了这两种便宜模型作为可信梯度入口的资格。上一方案离可执行的完整可微导航还有实际工作量，不应继续用论文名称掩盖这一点。

## 下一优先方向：用原生分支验证真实后果，先解决状态恢复

不再直接把理想轮径×轮速或低阶拟合当原生物理。拟准备一个**原生状态恢复与局部反事实方向测量**协议：

1. 从明确T507/T527源模型与原任务真正重生既有前缀，计入所有物理步。保存当时完整原生integration、Python执行器/观测history/clock/prevaction/终止状态和对应Actor因果hidden。现有中途文件没有完整integration，不能用pose/120输入伪造。
2. 第一个资格条件是同模型、同动作恢复后的短段与不中断连续运行所有数组及末积分逐位一致。失败则停止，不做方向或训练。此项验证的是恢复接口，不宣称新导航进步。
3. 资格过后，预注册少量神经参数方向和两尺度正负扰动，所有未来观测由各自真实MuJoCo状态生成。得到的是条件窗口原生有限差分，不是模型估计、不是全回合策略梯度；每次扰动要按锁定约定重建该权重自己的hidden。
4. 接触/饱和/近零效应/尺度不稳定独立报告，不把任意方向当可信下降。原生测量可用于否定物理辅助方向或衡量已有RL/模仿方向，不自动将低维参数搜索冒称新DRL或原创。

这一步仍需独立实现、源/输入SHA、容量/全部前缀与分支物理预算、绝对截止准入及零步检查。**本文未注册、未启动下一实验，不扩大17:30窗口。** 先完成真实接口与预算后才决定能否在当前窗口执行；余时不足则保留准备成果，不假称后台继续。
