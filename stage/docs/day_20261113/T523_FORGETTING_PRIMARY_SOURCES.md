# T523：修一项丢一项的遗忘解释与数据资格

2026-11-13。仅 Stage 文献核对；本笔记没有启动训练、模拟器或资源操作。现场事实仅据 [午间依据](LUNCH_RELAY_PRIMARY_SOURCES.md) 与 [T522 12:15复核](T522_CHECK_1215.md)，没有新增原始结果审计。

**结论：出现了学习后旧能力回退的“遗忘现象”，但尚未证明灾难性遗忘是唯一原因，更没有证明两任务无法由同一 Actor 兼容。** T519 新任务改善但旧项失败、T520 修旧后新项失败，以及 T522 BC loss下降但field回退，均是行为退化证据。要区分参数覆盖、任务干扰、有限样本优化误差与闭环访问分布偏移，需要额外对照；当前报告未做这样的因果分解。CLEAR §4.1明确区分任务不兼容造成的 interference 与序列学习覆盖旧能力造成的 forgetting，因此不能把取舍直接等同于不可解冲突。[Rolnick et al., CLEAR, NeurIPS 2019, §4.1](https://arxiv.org/html/1811.11682v2)

## 论文支持什么措施

- **共同训练与经验保护有直接依据。** CLEAR以新经验维持可塑性，以历史经验的离策略学习及策略/价值克隆保护稳定性；原法是 V-trace actor–critic，不是本项目无 critic 的同行RTG/PPO。它支持同时考虑新旧表现，不能保证这两个起点一定共同成功，也不能将历史轨迹直接改称新鲜on-policy。[CLEAR §3、§5](https://arxiv.org/html/1811.11682v2)
- **EWC是候选保护机制，不是已验证修复。** 原始EWC用旧解附近的对角Fisher/Laplace近似形成参数二次惩罚，强度λ控制新旧目标取舍。工程推论：有限旧轨迹估出的局部参数重要性不等于完整闭环到达约束；它不能直接补足学生新访问状态的覆盖，也没有本场景成功证书。本轮不新增EWC/Fisher/λ变量。[Kirkpatrick et al., EWC, §2、Eq.3](https://arxiv.org/html/1612.00796v2)
- **平衡必须落在任务loss上。** PCGrad论文研究负余弦、梯度幅值差和曲率共同影响，且指出冲突梯度本身不必然有害。按任务先聚合再等权联合，是明确目标选择；直接拼接决策行会让长轨迹改变任务权重。4+4条、等权和既有组内缩放均只是有限工程选择，不保证每项改善，不构成已经测得梯度冲突的证据；本轮不追加投影方法。[Yu et al., NeurIPS 2020, §2.1–2.2](https://proceedings.neurips.cc/paper/2020/file/3fe78a8acf5fda99de95303940a2420c-Paper.pdf)
- **低BC误差不能替代闭环验收。** DAgger针对动作改变后续观测分布的问题，依赖学生访问状态上的专家反馈；仅拟合两条旧成功轨迹不是DAgger。T522现象与这种风险相容，却未单独证实分布偏移是根因。[Ross et al., AISTATS 2011, §2–3](https://proceedings.mlr.press/v15/ross11a.html)

## T522八轨迹首次用于PG的条件

PPO的批次由行为策略采集，固定旧概率密度，再有限次优化clipped surrogate；公式没有“每任务必须已有GOAL”的资格条件。接触/超时轨迹仍可按原奖励合同产生回报和优势；如果奖励全同或估计噪声很大，信号可能无用，合法不等于有效。[Schulman et al., PPO, §2–3、Algorithm 1](https://arxiv.org/pdf/1707.06347)

**数据的日历年龄本身不决定on-policy身份。** 若T522八条此前确实零Actor更新，且本轮初始化精确等于其T519行为策略，完整输入/合法h0/因果GRU历史、实际噪声条件密度、动作边界语义和behavior logp全部核验，环境及预处理合同未改变，那么可把这八条作为该行为策略批次的首次有限PPO使用。这是由PPO定义作出的工程推论，须由主管线实际SHA与密度审计确认；“同一模型名称”不足。优化后仍固定行为分母，并用当前Actor从合法h0重算完整历史的分子，不能沿用教师隐藏状态冒充当前状态。[PPO §3、§5](https://arxiv.org/pdf/1707.06347)

此前笔记笼统称“旧T519/T520轨迹只能作replay”须按上述条件限定：来源不同或行为策略已变时不能冒充当前on-policy；**本次是同策略且此前未优化的T522既有批次**，可在核验通过后首次使用。不得筛掉失败后仍称原采样分布；不得把这次使用称为新采集、新独立八样本或独立重复实验。已见结果后修改准入规则也应透明披露为探索性后续检验。

当前最直接的有限检验是取消人为GOAL准入、保留全部八条、按预先固定任务权重真正联合更新；同一个冻结single120/causal64GRU共享动作头仍须真实old8+field24逐ID验收与失败回退。既有批次覆盖仍仅两任务，不能据此声称保护了所有任务的状态分布；完整32项验收也不等于泛化。16步上限、shadow重构、32项原生及精确重生、单Actor部署等约束以T523正式协议为准，本笔记不授权追加预算或重复启动。
