# 已有方法能解决到哪一步（2026-11-13）

**已有研究分别提供保持旧能力、学习偏离后的恢复、以及有条件的稳定性方法；没有一项可直接保证当前120维输入/64维因果GRU Ackermann策略同时通过旧任务与全场地。** [当前证据](CURRENT_PROBLEMS_REVIEW.md)中T524最终old8/8、field10/24，T522轨迹BC误差大降但闭环9/24；因此下一步不能仅换算法名称或继续压同两起终点的BC误差。本次仅文献研究，不启动训练、仿真或修改协议。

## 建议顺序（仅建议，非启动授权）

1. **先确定学习合同及可用教师。** 核对旧任务成功依据、当前失败状态及恢复标签是否存在；原soft19参考父模型旧7/8，不是全旧集已验证专家。若没有可靠恢复教师，DAgger/TaSIL前提不成立，不能用同成功history继续拟合来冒充恢复学习。
2. **若允许学习阶段教师：优先“学生访问状态上的纠正/恢复 + 覆盖旧任务的序列replay + 有界离策略RL”。** 教师只提供学习数据，最终部署可保持原观测合同的单Actor，无地图、waypoint或外部规划器。选择离策略RL是数据复用工程选项，不是解决证明；历史多次BC/soft keep和RLPD式SAC已失败，只有恢复覆盖、可靠参考或学习合同产生实质变化时，才值得另行讨论有界试验。
3. **若要求无教师纯RL：** 优先讨论旧新任务交错采样/序列replay、恢复状态覆盖及确定性验收，不能把教师辅助路线称为纯RL。CLEAR理念可用，但原V-trace方法不是SAC现成补丁；样本效率和探索成功仍无保证。
4. **理论增强最后排队。** TaSIL需先确认教师及稳定性/导数条件；EWC只处理保持的一部分；收缩DS需改接口和控制假设，不宜当当前GRU的快速替换。无论哪条路线，旧任务与新场地都须对同一冻结模型逐项闭环检验，探索GOAL、训练loss及精确重生分别报告。

判断：最有实践依据的是把“保持已学会的能力”和“在自己访问的状态中学会恢复”同时补齐；这是一组已研究的机制与条件，不是单篇论文已经替Stage解题。研究结论不授权重复T524、扩大预算或新建训练任务。


## 本项目下一步的具体选择

学习初始化回到仍保留old8/8、field11/24的接受T507模型，不沿被拒绝T524（field10）延续。T524失败状态可作诊断证据，但下一次实际学生状态采集应来自选定学生自身，不能把退化研究副本的状态当成当前部署基线分布。旧参考优先使用原成功策略实际序列及其历史分布，不把失败父模型在这些输入上的刷新输出当恢复专家。

先验证教师在该学生真实偏离状态的可恢复性及短暂纠正后的自主交回能力，再把合格标签用于有限更新。每次学生更新后，重新采其访问状态，而非只重复同8原批。保留旧成功ID与失败类的代表性完整序列，学习后同模型验收旧8和原field11逐ID保持、新任务提高。

教师标签/异策略旧经验可用于监督或合法离策略RL；不能直接塞进现有on-policy PPO批次。若沿当前PPO，则RL部分采更新学生自己的新轨迹，旧/教师数据只走清楚标识的监督保持支路；若另选RLPD类，则须独立核实Q/终止/奖励/GRU replay合同及预算，不以名称替代实现。部署仍传感器/目标/历史→单Actor→驱动/转向；有训练期教师应称示范/教师辅助端到端RL，不称从零无专家纯RL。

这是一份方法选择建议，本次没有实现或启动下一轮。
