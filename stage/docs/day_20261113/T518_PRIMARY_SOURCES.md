# T518 primary-source check

2026-11-13 checked primary publisher [Farajtabar et al., Orthogonal Gradient Descent for Continual Learning, AISTATS2020](https://proceedings.mlr.press/v108/farajtabar20a.html) and publisher-hosted [paper](https://proceedings.mlr.press/v108/farajtabar20a/farajtabar20a.pdf) method description. OGD stores output-gradient directions and projects new gradients into orthogonal subspaces to reduce output interference. Direction projection for retention has clear prior art; not originality.

Our T518 is not a direct OGD reproduction: local active per-episode output-error gradients are recomputed at each accepted state, actual Adam parameter displacement (not raw gradient) is projected, and actual nonlinear stored-output hard checks/backtracking determine acceptance. Equality projection may be conservative. Linearized orthogonality does not guarantee exact function preservation after finite steps, unchanged induced states, return improvement or safe navigation. SVD truncation/rank and nonlinear rejection are recorded.

T517 showed two accepted steps reached an output-error boundary; shrinking the same third direction to1/128 still exceeded a .002 RMSE threshold. It did not prove no other feasible direction exists. T518 probes one finite constrained-direction method; failure likewise does not prove the feasible manifold empty. Held teacher labels never enter direction/step selection; alternating blocks from the same causal trajectory are interpolation validation, not independent navigation holdouts. No native training or algorithm novelty claim follows from offline success.
