# T516 primary-source check and limits

2026-11-13 rechecked [Johannink et al., Residual Reinforcement Learning for Robot Control](https://arxiv.org/abs/1812.03201), author abstract, and selective method/results discussion of [Rusu et al., Policy Distillation](https://arxiv.org/html/1511.06295v2). Residual composition and policy consolidation are established techniques. Their demonstrations do not establish that our supervised, frozen-neural-parent, nonlinear logit residual will preserve navigation. This is not a reproduction of residual RL (this round has0newPG), a safety certificate or a novel formula.

T515 local evidence: one globally modified linear output fitted teacher actions better but actual20 checks collapsed to2GOAL, then exact rollback/audit. T511's±.1 bounded location residual also failed an earlier two-task data experiment; its amplitude/data/architecture differ, so it does not rule out all nonlinear correction or establish capacity as sole cause. T516 changes nonlinear representation and available correction range jointly and uses a newer actual recovery source. No isolated capacity/variance/safety attribution is justified.

Strong finite stored-input output-preservation and blocked-label checks are a cheap prerequisite for native experiments, not a theorem about induced state distributions. Same-trajectory held blocks retain causal observation histories including prior teacher actions and are not independent navigation tests. Only future independently registered pure Actor native rollouts could show improvement. Original learned parent is always recoverable by immutable checkpoint/hash.
