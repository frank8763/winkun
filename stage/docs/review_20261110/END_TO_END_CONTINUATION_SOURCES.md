# Stage端到端续行：一手文献与有界路线

2026-11-10，只读研究；本文没有启动原生仿真、Actor/V优化器或新训练，也没有修改既有证据。已读仓库AGENTS、当前RESEARCH_STATUS和[T451复盘](T451_FINDINGS_AND_WINDOW_REVIEW.md)。以下路线是新协议草案，不是已注册任务或成功保证。

## 当前判断

保留研究父模型T449 recovery为宽六米54/54、旧274/275，合328/329，唯一旧00失败，未晋升。T451完成400BC、0PPO，结果322/329；不能称本轮强化学习失败。其192次恢复决策只有5次由学生自主执行，随后187次教师接管；这支持优先检查学生实际访问分布的覆盖，但不是梯度占比或唯一因果证明。来源：[当前状态](../RESEARCH_STATUS.md)、[T451复盘](T451_FINDINGS_AND_WINDOW_REVIEW.md)。

部署合同保持：单一Actor，120维因果观测与自身GRU历史直接输出drive/steer；只接受原任务最终目标。教师查询、数据聚合和价值函数只用于训练；运行时没有教师切换、地图、规划器、人工路点或路由。使用示范辅助训练仍可形成端到端部署，但不能称纯RL从零学习；DAgger、PPO、RLPD、GRU均为既有方法。

## 建议的新有界路线

以下为结合本地失败证据的研究推断，不是论文给出的Stage超参数或可直接launch的协议。

1. **先验证纠正源的有效域。** 冻结328/329父模型，在旧00的三个预先固定中段时刻（可取4、12、24秒）保存原生状态、120输入前缀和学生GRU历史。从每个同状态分别测试T255能否到原最终目标，并各做一次精确重生；最多3条独立分支＋3条重生，0Actor/V更新。不换时刻、教师或seed补救失败。通过只能证明这些起点的恢复能力，不能把整个区间声明为正确标签域。
2. **再让学生自己走，教师只提供训练侧查询标签。** 若源验证通过，预注册一次有限数据聚合：保存学生从回合开始真实诱导的完整历史，在这些状态查询教师动作；将学生访问状态上的标签、教师接管之后的标签、既有成功保持样本分开计数与计损失，重叠前缀去重。恢复分支成功不是学生成功。保留所有碰撞/超时样本，不只选择成功回合来计算RL。
3. **用新学生交互做真正PPO，示范作为辅助监督。** 可将上限草案固定为2轮，每轮4条fresh学生探索轨迹＋4条精确重生、既有4epoch PPO；只用真实学生采样动作、原奖励/终止、正确行为密度及真实历史计算PPO/GAE。重生不是新增独立样本；教师标签及旧示范只进入单独BC/保持项。采用一个预声明权重与seed，不扫BC步数/学习率网格。若本轮仍0PPO，明确报告为监督提案或门槛未过。
4. **保持因果GRU合同与完整闭环验收。** 每条训练序列从真实回合前缀重建hidden；参数改变后，不能将旧参数生成的中段hidden当作新网络的准确hidden。先核验逐步/序列一致、动作密度、Adam回退及序列化容量，再进行更新。这来自当前递归模型的计算合同，未宣称DAgger/RLPD已证明其效果。冻结encoder/GRU只调动作头可以另立消融，但不与上述主试验同时混入。
5. **验收和接力事先写死。** 最终学生无教师执行完整329，须保留父模型原328成功并修复00；全过才准入16fresh和78独立原生读回，不以MSE替代闭环成功、不直接扩8米。注册总物理/命令/储存/墙钟上限、学习截止及审计空间；检查点以未压缩最坏字节预留。纠正源失败、回归或无保留更新时，结束该机制，按事前独立登记的下一任务接力，不能继续原T451预算或靠硬截止填满窗口。

主问题应表述为：**在部署接口和原生安全判据不变的条件下，学生实际访问状态上的纠正覆盖，加上有限的新学生策略梯度，能否补00且保留原328成功？** 这比继续增加同一教师后缀BC步数更能检验当前证据指向的缺口；效果仍须由新有界实验回答。

PPO的数据采集与策略更新依据[原始论文](https://arxiv.org/abs/1707.06347)；上述2×4采集只是可证伪的短pilot草案，并非充分样本量或覆盖整个无人值守窗口的保证。正式注册前须按实测吞吐核算工作量，分别报告预计耗时与硬截止；若安排更长窗口，须事先实现不同机制的有限接力和失败转移，不能以重复同机制或等待填时间。

潜在论文问题是：能否以真实自主偏离及可恢复性来选择纠正数据，同时减少对既有任务的闭环损伤？这是待检验的研究问题，不是现有创新结论。必须与普通BC、普通DAgger和相同预算的示范辅助PPO比较，再补多训练初始化、未见布局/距离及实体机验证；标准GRU、DAgger、PPO的组合本身不构成原创。原六米完整门通过后才按既有授权另注册八米，再讨论更远目标；有限开发集全过不等于全地图泛化。
