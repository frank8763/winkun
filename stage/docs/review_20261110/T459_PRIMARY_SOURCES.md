# T459：零初始化神经残差的证据边界

2026-11-10；Stage 专用。仅核对下列原论文 PDF 的指定章节，未运行模型、优化器或原生环境。

## 一手依据

- **零增量起步**：[LoRA §4.1，PDF p4，式(3)](https://arxiv.org/pdf/2106.09685#page=4)冻结原权重，随机初始化 A、令 B=0，使初始增量 BA=0。支持“新增分支初始不改变函数”的构造；其研究对象是语言模型的线性低秩增量，本案 Tanh MLP 不是 LoRA，论文不保证本案旧任务闭环保留。
- **固定基座加修正**：[Johannink 等，Residual RL §III-A/B，PDF p3，式(5)/Algorithm 1](https://arxiv.org/pdf/1812.03201#page=3)把固定控制与学习输出相加，并以环境回报训练残差。主体实验基座是外部人工反馈控制器；[§V-D，PDF p5](https://arxiv.org/pdf/1812.03201#page=5)也用仿真预训练参数策略作基座，所以神经基座残差本身不新颖。本案冻结神经 Actor，全部分支每步同时计算，没有外部控制器。本文不是零初始化或 BC 保留定理；仅做 BC 的 T459 不能称新增 RL。
- **冻结与容量扩展**：[Progressive Neural Networks §2，PDF p2–3，含 Limitations](https://arxiv.org/pdf/1606.04671#page=2)冻结旧列、为新任务增列并用非线性适配器迁移；旧列函数不受新列改变。作者明确推理选列需要任务标签。本案一个联合输出始终叠加残差，故其“免遗忘”不能移植为联合策略保证；参数随任务增长也是原文限制。
- **闭环覆盖**：[DAgger §2.1、§3/Algorithm 3.1，PDF p2、4](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf#page=2)说明学生动作改变后续状态分布，算法反复采集学生访问状态并取得专家标注。单条已有混合恢复轨迹只覆盖有限学生前缀；本案不新增专家查询/迭代采集，不能继承 DAgger 的无悔保证。
- **动作拟合不等于轨迹保留**：[TaSIL §2–3，PDF p3–8，Definition 3.1、Proposition 3.1、Theorems 3.1/3.2](https://arxiv.org/pdf/2205.14812#page=3)将闭环误差联系到专家增量输入状态稳定性及邻域函数/导数匹配。本案未验证稳定性、未匹配导数；固定 history 上保持很小不推出新闭环安全。
