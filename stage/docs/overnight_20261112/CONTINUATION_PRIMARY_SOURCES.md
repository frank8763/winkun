# Frozen-parent global residual: continuation source check

2026-11-12. Stage only. Research note; no run launched, no simulator/data/model/optimizer changed. Project results below are the coordinating agent's supplied evidence, not an independent run audit. Read selective method/results text of the primary papers linked below; this is not a claim to have read all historical chats or every cited paper in full.

## Decision supported by the sources

A new, zero-output residual on a fully frozen accepted parent is a reasonable bounded capacity test after T510's three raw-projection arms were rejected. It is established residual/continual-learning machinery, not an originality result or a guarantee of improvement. Freezing parameters preserves the parent function and its recoverability; adding a globally active residual changes the composed function everywhere it is nonzero. The actual old/keep/field rollout gates therefore remain necessary.

Supplied local context: all three T510 arms retained the same accepted old8 and field11 outcome; joint protection of 19 still lost sector2off2 despite old8 safety, with no increment. This motivates testing extra trainable capacity, but does not establish that capacity caused the failures or that a new head resolves their cause.

## Concrete implications for the bounded test

The supplied candidate freezes all accepted-parent GRU/carry computation, including the 11906 adapter parameters, and keeps old Adam state immutable. A fresh 184→64 tanh→2 MLP has `(184×64+64)+(64×2+2)=11970` parameters. Define composition unambiguously as existing final transform applied to `parent_raw + 0.1 * residual`; do not silently move the scale across tanh. A zero final layer and bias makes the residual initially zero while a nonzero hidden initialization permits learning. Zeroing every layer would prevent the hidden features from learning initially and can degenerate into a constant correction. The final linear layer means scale 0.1 is not by itself a hard bound on residual magnitude.

These are algebraic deductions, not empirical guarantees:

- With exact parent targets and zero residual, every keep MSE and its gradient are initially zero. Replacing a mean by the maximum per-episode keep loss does not create a first-step protection gradient. Once errors appear, max loss emphasizes the worst stored episode; its ties/subgradient and episode normalization must be fixed before execution.
- Parent hidden/carry is immutable as a computation on a given input history; changed actions can change later observations and thus the carry encountered online. Stored parent carry matching does not prove online carry or trajectories remain identical.
- Added capacity changes the hypothesis class and optimization path simultaneously. A successful candidate would show an improvement under this protocol, not isolate capacity as the unique cause or establish algorithmic novelty. A rejection would not establish impossibility of residual learning.

Keep the supplied fixed experiment contract: train only the new head, with fresh Adam at step zero; use only eight own-success labels from the two T509 hard tasks plus 19 parent-own keep episodes; success BC weights half full-time/half within 1 m. No new teacher or on-policy policy-gradient data. At most four blocks of 32 steps, each followed by the fixed 21 actual guard cases and their 21 exact replays, protecting the initial 19 success IDs individually and stopping on first rejection. Final acceptance still requires field success above 11, old8 safe, all original field11 retained, and contact count at most 9. A zero-initialized parent-equivalence check and immutable-parent/old-Adam hashes are implementation checks, not evidence that trained candidates pass these gates. Any budget, loss convention or acceptance detail still unspecified must be fixed in the run protocol before launch; this note grants no extra launch, retry, teacher, seed, or grid budget.

## Final registration clarification

The final T511 implementation keeps the parent raw action location and adds `0.1*tanh(new_head([hidden64, normalized120]))`, then clips the location to [-1.25,1.25]. Thus the additive location residual has absolute per-axis bound 0.1; it is added **after** the parent's 1.25*tanh, not before it. Only the final layer/bias is zero-initialized, with deterministic nonzero hidden features. Actual complete-history initial function equality must be verified exactly. The original full mature parent optimizer is immutable in its original protected checkpoint; the new head has a separate fresh optimizer, not a silent reset or remapping of original moments. This adds capacity and changes optimization/data allocation together, so no single-factor capacity attribution is possible.

Final bound is at most six fixed blocks of 32 new-head steps, with actual complete worst-case next-block-plus-final-capacity admission before every block; root cap40MiB/global1GiB may stop before six. First native protected-ID failure stops learning with whole new Actor/Adam rollback. At least one new-task success under a retained block is required before remaining11 and24exact. All limits retain the already authorized Nov13 09:00 cutoff. The preceding T510 finite three-arm results remain untouched; this is a separately registered new mechanism.
