## 固定数据和精确数学合同

既有Actor为`Linear(184,108) → Tanh → Linear(108,2)`，以残差加在完整冻结T694父链的raw location上。[原Actor代码](../../experiments/t699_matched_value/t699_actor.py)。原T701对整个残差MLP做有限全批L-BFGS；原记录明确不是BC全局最优。[原精修代码](../../experiments/t701_compact_retention/fit.py)。因此只冻结其已经学成的非线性特征再解末层，是一个范围明确的新问题，并非再延长原L-BFGS预算。

原缓存具有81956个旧决策和1737个七源决策，403+7条完整任务记录；旧目标**确为零残差**，七源目标为原执行动作减父链raw location。不能将旧403标签换成新的refined108输出，否则会蒸馏其遗忘；也不能把old零目标改成`clamp(parent)`造成未经声明的目标变化。[原数据构造](../../experiments/t699_matched_value/t699_prepare.py)。旧父轨迹特征使用其自身历史carry；源特征也来自已锁定历史，固定来源并不使它们成为修复模型的on-policy轨迹。

令`z_i=[tanh(W1 x_i+b1),1]∈R^109`，`B∈R^(109×2)`包含末层weight和bias，`B0`为原refined108末层。`W1,b1`、父链、状态构造、carry、执行精度和最终clamp/float32路径全部冻结。对任一任务集合`S`定义

```text
L_S(B) = (1 / |S|) Σ[g∈S] (1 / (2 T_g)) Σ[t=1..T_g] ||z_gt B - y_gt||²
O = 原403旧任务，N = 原7源任务
c0 = L_N(B0)

唯一目标：min_B L_O(B)  subject to  L_N(B) ≤ c0.
```

2是动作维度；每个任务等权，任务内决策均值。原T701目标等于`(L_O+L_N)/2`；这里不再自由选择old/new权重。原`B0`本身必可行，因此**该问题不因两集合冲突而不可行**；但“严格降低旧损失”的要求可能无法实现。理想数学解必有`L_O(B*)≤L_O(B0)`，实际输出仍须独立重算和数值证书才可如此报告。

用正平方根任务权重吸收行权，记矩阵为`A_O,A_N`及`Y_O=0,Y_N`，损失即Frobenius平方范数。该问题也是

```text
minimize t
subject to ||A_O B||_F ≤ t,
           ||A_N B-Y_N||_F ≤ sqrt(c0).
```

这是SOCP形式；平方目标和范数目标有相同最小解。218个可修改参数替换原218个参数，新增部署张量应仍为161584B（108隐层共19980参数，加218末层参数，全float64），加共同父链2621976B；不是只按1744B可修改末层报告整个模型成本。无新中心、支持、第二网络或运行时教师。训练缓存、求解workspace、独立重建、延迟/RSS及旧父链仍须计成本。

## 如何一次确定性求解，而不是隐蔽扫权重

可使用固定锥求解器，或使用该单约束的标量对偶求解；选择一个实现并在执行前锁定。若采用后者，记`H_O=A_OᵀA_O`、`H_N=A_NᵀA_N`、`C_N=A_NᵀY_N`，在正规可逆情形

```text
B(λ) = solve(H_O + λ H_N, λ C_N), λ≥0.
```

先检查无约束旧最小解是否满足七源上界。若满足，直接取该旧最优解；否则解唯一约束的对偶边界，找`L_N(B(λ))=c0`。固定次数的区间扩张/二分是求解同一个已锁定凸问题，λ是其拉格朗日乘子，**不是挑效果最好的训练权重**。不能看闭环结果选择某个λ，也不能新增一串候选再从中选最好者。

不能假定所有数值退化不存在。应事前固定float64、线程/顺序、求解容差、最大分解/标量迭代数及奇异解的确定性规则；用QR/SVD或稳定分解处理条件数，不能为过门临时加ridge、删方向或放宽source上界。若源`c0`恰为该固定特征的最小源损失，Slater严格可行性可能不存在，有限λ根可能不存在；应预定义以源最小解的仿射集合求旧最小损失的退化分支，或明确数值拒绝，不能不断增大λ称已收敛。多解时仅用不改变主最优值的预定规则（如主最优解集合内最接近`B0`），并如实报告规则。

至少保存和独立重算：`B0`与候选完整状态SHA；固定隐层/父链逐张量相同；全部逐ID old/source损失、两集合均值、矩阵秩与奇异值/条件指标；原始可行性、λ≥0、stationarity、互补及可计算的primal-dual gap。正规情形stationarity为`H_O B+λ(H_N B-C_N)=0`。对偶下界来自同一Lagrangian最小值，不能只报告参数差小、solver状态或loss下降。数学的“≤c0”与有限精度验收容差分别报告；不能将舍入容差包装成允许源损失实质增长。预算内无合格证书即数值失败，不续扫容差。

## 最关键的可行性上限

1. **旧严格零响应可能消灭所有新能力。** 旧目标为零，`L_O(B)=0`等价于`A_O B=0`。若81956×109的旧设计矩阵满列秩，唯一解是`B=0`，即完全移除回放残差。它能满足源约束，当且仅当`L_N(0)≤c0`；通常不能预期成立，必须实测而非从样本数推断秩。满秩时旧正定二次目标在凸可行域上至多一个最优解。秩不足时存在旧零空间，也仍须检验该空间能否容纳七源目标。本审查没有加载特征，所以不声称实际rank或可达最小旧损失。
2. **保持原refined108的旧输出也不是修复。** 若要求`A_O(B-B0)=0`且旧设计满列秩，则只能`B=B0`。OGD式精确零漂移与降低旧蒸馏误差不是同一个要求；本提议选择允许有结构的函数改变来修复，而非强行证明两者同时满足。
3. **最优解可能几乎就是原模型。** 如果`B0`已在当前特征的约束Pareto边界，单末层没有可用改善；如果受约束最优旧损失仍显著非零，这只是该固定特征/目标的限制，不能推出原始108宽MLP或全Actor容量不足。此时停止，不改源容忍度、特征seed或隐层继续救。
4. **平均七源保持可能牺牲个别源。** 一个源损失增大可被其他源减少抵消。必须全部七ID列出，闭环七源另测；不能把一个aggregate二次约束说成逐任务保持。若未来改逐源约束，那是另一实验，不在本轮暗加或按结果替换。

## 拟合、闭环保持与迁移必须分开

低旧raw残差不会保证403个旧起点全部成功。策略动作改变会改变物理状态，进而改变GRU carry与下一个184维输入；固定历史上的均方误差既没有约束这些新状态，也没有限制关键单步最大误差。clamp与float32命令可能掩盖某些raw误差，也可能使很小误差跨过命令边界。顺序决策中动作改变未来观测的分布问题是既有一手结果，不能仅据监督损失推出闭环性能。[Ross等，AISTATS2011](https://proceedings.mlr.press/v15/ross11a.html)

同样，`L_N(B*)≤c0`不保证保住原7/7源闭环、不保证曝光78的53成功，更不保证T704的97/224。T704已经用于提出本假设，后续同224测试只能是**曝光回归与保持代价检查**，不能再次叫盲测。无论结果好坏，都报告成对gain/loss、原旧403实际丢失ID、逐源与分组，不以一个合成总分制造全面赢家。正式保留仍须按当前保留模型的全部成功集合合同处理；修复T694父链的403旧集合，不自动等于保持T696/T698后来增加的全部成功。

建议先锁一份新有界协议，完成唯一候选及独立重建/数值证书后，才进入预先固定的原生known套件和必要的曝光回归；不以源loss过门替代原生审计，也不反复测试并回改读出。资源不足则明确missing或不准入，不重启T701/T704，不借旧额度。若要在本次改进后提出迁移结论，需要另立此前未用于本候选选择的评测；本审查不生成这类初态。
