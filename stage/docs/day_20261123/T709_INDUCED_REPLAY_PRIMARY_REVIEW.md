# T709: fixed candidate-induced-history replay review

2026-11-23. Stage only. Research and read-only metadata/code inspection; no Actor fit, native integration, trajectory regeneration, run registration or ledger change. This note covers the proposed finite comparison, not all Stage history or an exhaustive literature search. Current status, repository instructions, Stage context/progress and migration report were consulted.

**Recommendation: admit one fixed coverage ablation, with modest expectations.** Compare a single induced-history candidate against the exactly reconstructed, already evaluated T705 **balanced** control. The only objective change should be the old-history distribution. This is an adaptation of established imitation/functional-replay ideas, not a new learning mechanism. It is distinguishable from T691 by the fixed feature class and exact convex fit, but T691 remains directly relevant negative evidence. No recovery, DAgger guarantee, new-map generalization or automatic promotion follows.

## Teacher history and zero-residual targets

The actual readout is `184 -> tanh108 -> 2` in [T699 actor](../../experiments/t699_matched_value/t699_actor.py), not219×2 final parameters. With a bias feature, `z=[tanh(W1 x+b1),1]` is109-dimensional and the trained matrix is **B∈R^(109×2), 218 scalars**. Freeze the entire T694 parent, encoder/GRU64, normalization and first residual layer at original T701 refined108 B0. [T708 fit](../../experiments/t708_agem_replay/fit.py) confirms only `replay_head.2.weight/bias` changed; the full added readout capacity remains161584 tensor bytes, not merely1744 bytes of fitted coefficients.

The frozen recurrence's [actual `step`](../../experiments/t496_neural_speed_profile/speed_actor.py) updates GRU state from normalized observation and prior carry; the residual readout is applied afterward. Therefore, **on the exact same observed history with the same reset and frozen recurrent tensors**, T694 and each candidate have the same carry. This is an algebraic inference from the code, conditional on the data/loader contract. Their own independently generated trajectories need not have the same observations or carry.

For each stored candidate history, replay the complete observation sequence from reset with the actual externally executed action history already represented in its observations. Use T694's own recurrent calculation, compare every hidden-before and final hidden-after against the candidate tape, and certify frozen recurrent/normalization tensors and precision/reset rules. [T694 `trajectory`](../../experiments/t694_full_history_compatibility/t694_actor.py) provides the relevant batch1 assertions. Do not feed counterfactual teacher actions into the replayed history, reset hidden per row, transplant a hidden state from a different history, or require the teacher's commands to equal the candidate's executed commands. The latter would incorrectly reject the very disagreement being supervised.

For a frozen actual history H, write `mu_student(H)=mu_T694(H)+z(H)B`. The distillation target `mu_student(H)=mu_T694(H)` is **exactly y=0 raw residual**. It preserves T694's entire frozen function, including its compatibility readout, rather than the candidate's residual or its failed executed action. Compute teacher outputs as an audit of this interpretation even though the residual label is algebraically zero. Clipping to float32 commands occurs afterward; zero raw error is sufficient for matching commands, whereas matching clipped commands does not imply zero raw error. Source7 targets must retain their existing executed-command-minus-T694-raw-location semantics from [T699 preparation](../../experiments/t699_matched_value/t699_prepare.py).

This establishes a valid conditional function query, **not** expert recovery. T694 was successful on the original protected histories; it has not been shown to recover all candidate-induced histories. A teacher can legitimately be evaluated on a bad history while returning a bad action. Terminal truncation also removes any unseen post-contact or post-timeout continuation. No takeover branch, native teacher recovery test or runtime teacher is needed to make the local query well-defined, but none may be claimed as supporting safety. New candidate rollouts can visit further histories absent from all102 frozen tapes.

## One fixed objective and an economical exact control

Let each trajectory loss be `ell_H(B)=sum_t ||z_t B-y_t||²/(2 T_H)`. Let `O_i`, `M_i`, `W_i` denote original, mean-candidate and worst-candidate trajectories for protected ID i. With S the fixed51-ID intersection, define:

```text
R_control(B) = (1/403) sum_i ell_O_i(B)
R_induced(B) = (1/403) [sum_(i not in S) ell_O_i(B)
                  + sum_(i in S) (.5 ell_O_i(B)
                                  +.25 ell_M_i(B)+.25 ell_W_i(B))]
N(B)         = (1/7) sum_source_j ell_j(B)
rho         = 1e-10 trace(G_original)/109
J_arm(B)    = R_arm(B)+N(B)+rho ||B-B0||²_F
```

Each old ID retains total coefficient1/403; differing trajectory lengths do not alter that coefficient. Source weights/data and nominally computed rho stay identical. Fixing rho to the original Gram is essential: recalculating rho from augmented data introduces another objective change. The original histories remain present, with half weight on covered IDs. This tests a redistribution of fixed old-ID weight toward selected off-distribution histories, not a pure increase in old-group regularization.

Use the same double-precision Gram convention and one109×109 Cholesky solve per objective as [T705 `solve` / balanced trial](../../experiments/t705_constrained_replay/fit.py). The strictly positive rho makes the finite quadratic strongly convex; its numerical stationary solution addresses optimization error within these frozen features, not representational adequacy or closed-loop optimality. This is one fixed data swap, not a solver/seed/weight grid. Extra rows increase feature construction/RAM/time; equal solve dimensions and fits do not mean equal total FLOPs or equal information.

First reconstruct the **original T705 balanced** matrix and model state using the exact original arithmetic path and verify its saved B/state hashes, unchanged tensors, source data, rho and successful native audits. Reuse its historical known/joint evaluation only if this identity and environment/evaluation contracts hold. Do not replace balanced with T705 constrained, select a better historical control, or recompute its native episodes as independent evidence. Identity failure is a control-admission failure, not permission to change arithmetic or tolerance after seeing results. The candidate then gets one live construction, one shadow and one independent reconstruction with explicit solve/assignment accounting; the control reconstruction is also real work and must be counted.

This is a substantively cleaner optimization comparison than T691's trainable11906-parameter adapters/64Adam steps/KL-censored candidates: the class, exact optimizer and source tradeoff are fixed and numerical fit uncertainty is narrowed. It is still the **same broad occupancy-function-preservation hypothesis**, with a different teacher/data/class, not a mechanism-level novelty. The new51-ID coverage and observed T708 regressions provide a concrete local test; they do not justify another indefinite replay campaign.
