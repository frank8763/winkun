# T703后：停止支持调参，先作一次前瞻冻结新起姿评估

2026-11-23。**建议下一实验只评估、不学习：冻结T694父模型、T696、T703和refined108，在结果揭晓前一次锁定新的联合XY+yaw起姿。** 本文是设计审查，未注册或启动；只新增本文，未读模型、执行前向、拟合、优化器或物理步，未修改代码、旧运行、归档或保留模型。Stage only，无规划器、路点或教师。

## 为什么此时停止调支持范围

[T703结果](t703/FINDINGS.md)记载396核心/原403成功零丢失/7源全成功，曝光78中45成功，新增157,684B；T702为42/78，T696为47/78但新增约2.6MB。refined108为53/78、新增161,584B，却丢11个原成功。共同T694父链占2,621,976B，不能把新增部署字节当总模型大小。T698仍单独保留，本研究不替换它。

这些结果已足以说明有限保持与迁移存在折中；还不足以根据45、47或53选出普适优胜者。78起点已反复用于观察、提出新支持规则和比较，只能作为开发回归证据。继续围绕它调维度、核、半径、精度或seed，回答的会越来越偏向这一固定集合。[前次一手审查](T703_SUPPORT_PRIMARY_REVIEW.md)

## 建议保留四模型

T694父模型是必要基线：可区分候选在新起姿上的收益与父模型本来已有的能力。T703是当前小存储、零旧损失候选；refined108揭示相近新增存储下的迁移—遗忘折中；T696提供较高存储参照，帮助判断压缩是否牺牲新起姿表现。

因此优先四模型。若独立资源核算容不下，应在生成/揭晓测试结果前减为父模型/T703/refined108三模型，并明确放弃高存储比较；不能看结果后挑三者。已有T702和量化方案不加入，避免继续扩大候选选择。四者均使用实际保存hash、各自owner和原生动作路径；不重新拟合或重构模型。

## 起姿与相关层级必须如实命名

可考虑24个field父起点加4个非field成功源父起点，每父8个新联合XY+yaw扰动，4近4外，共224新起姿/模型；按主设计，每父预选近圈第一项作一次精确重生，共28个exact/model，252条/模型、四模型1008条科学执行。这些精确重生不是原父中心的新验收，也不是新增独立样本。

**28个父起点不是28个独立任务或世界。** field是8个sector各3个offset；4个非field源`dev6_05/11/15/hold6_03`共享同一个原始5m LEFT快照。全部仍属同一几何，原父起点也已曝光。“新”的仅是经历史清单核验未测试过的完整起姿，不是新父家族、真正holdout家族或地图。field源/非源、offset、近/外分别保留；非field单独列，不能混进field均值制造优势。

[主设计草案](NEXT_AFTER_T703.md)给出具体候选：近圈XY向量长度0.02m、yaw交替±0.5度；外圈0.06m、yaw交替±1.5度；各圈XY方向45/135/225/315度。XY是向量长度，不是每轴幅度；相对各自真实父reset叠加，不能忽略非field父自身已有的delta。这是固定格点设计，不是随机抽样，因而也不自动产生随机起姿总体的置信区间。数值尚未注册，不是可启动协议。

任何候选动作前须锁定父ID与层级、坐标系、方向与yaw符号对应、完整初态恢复合同及全起姿清单SHA。不得用模型输出、置信度、支持命中、到达表现或轨迹筛选。以实际完整reset/初态hash至少对403旧、7源、旧431、旧78及同合同历史去重；披露实际历史覆盖范围，不能声称穷尽所有旧测试。只改初始起姿；地图、目标、传感器、初始carry/历史构造、动作、时标、终止、安全判据与时限保持锁定合同。

碰撞/越界/初始已达目标等无效起姿规则须预先定义且对所有模型相同。固定清单的无效、重复、初始化失败均留存，不按表现删除或补样；同时报告计划数、有效数、执行数、无效及删失原因。成功率以有效完成测试为条件另报，并列计划覆盖率；缺测不算失败，也不补成成功。可由严格物理有效性事先拒绝整个设计，不得看政策表现再换范围。

## 主要报告应回答什么

主要对比先锁定T703减T694的**配对安全成功差**；T703减refined108和T696为预声明次要对比，不依总体排名更改主问题。成功仍按原native GOAL及安全合同，不能用剩余距离或回报改善替代。逐起姿保存双方新增成功、双方成功、双方失败、退步及终止原因，保留所有原失败ID。

field先按每sector汇总其3个offset，再给8个sector等权汇总；同时列源/非源、近/外及逐父描述。非field四行及共享快照另表报告，不宣称四个独立家族。除成功外，列碰撞/边界失败/超时/行政删失，以及成功条件下用时和失败剩余距离，注明条件分母，避免只比较成功者用时。

**不把224或1008当独立伯努利试验给二项置信区间；不在28父上做伪独立bootstrap。** 本轮优先报告完整配对表、sector分布及固定集合效应，不强求显著性结论。如果随后确需随机起姿不确定性，必须在实际采样法下另行锁定、仅估计给定几何和固定父起点条件下的蒙特卡洛误差；不能把它解释为新sector、地图、训练seed或算法总体的不确定性。8个相关sector加1个共享源快照不支持广泛外推。[Agarwal等§2、§4](https://proceedings.neurips.cc/paper_files/paper/2021/file/f514cec81cb148559cf475e7426eed5e-Paper.pdf)

旧403保持/7源和核心历史仍与新起姿结果并列，明确复用旧证据；28个新起姿精确重生不能替代完整旧集合验收。若精确重生不一致，保留工程反例并按预声明规则停下，不现场修模型后续测。T698保持不变。

## 有界性与结果判读

1008科学条目的既有最坏物理步估算为55,941,696，已包含预选的28exact/model，尚未计入管理命令、任何科学预检或故障保守上界；独立审计拟为零新物理但其墙钟/存储成本另计。“7 workers约一小时”只能作粗估，不能写成预算保证。正式协议还须锁定逐条/全局真实step上限、墙钟与绝对截止、worker资源、全部输出最坏字节、审计及备份余量。固定4近4外或四模型若超限，应在结果前改设计；不得靠中途加时/追加批次补齐。当前只设计，不运行任何预检或native。

若T703只保住旧历史而新起姿无配对增益，结论是有限保持尚未转成这项前瞻分布上的收益，支持停止继续调同一支持规则；不等于RBF、BC或导航无解。若T703收益集中少数sector，报告集中性；若超过父模型但落后T696，保留容量折中；若refined108更好仍须同时列11旧损失。若各候选新起姿均差，这仍是有价值的覆盖缺口证据，不用再筛“好”的起姿重算。

即使正面，也只支持冻结模型在预注册同几何起姿分布上的有限结果，不证明连续安全、未知地图泛化、容量最优或算法原创性。结果公开后这批起姿转为曝光证据；任何据此再调模型都需要另一个独立测试协议，不能重命名为同一盲测。当前不自动晋升、不追加学习。
