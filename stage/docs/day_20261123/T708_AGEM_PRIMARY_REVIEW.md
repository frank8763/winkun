## 建议及这次问题的变化

建议只做一次另立预算的两臂固定步数比较：同一原 refined108、冻结隐藏层、同一 218 个末层参数，两臂均学习七源 ID 均衡平方动作损失，分别用**当前旧 403 ID 平均损失梯度**和**当前最坏旧 ID 损失梯度**作为 A-GEM 半空间投影的参考。两臂均从原始 B0 开始、固定 128 步、同一由源 Hessian 决定的步长，最终第 128 步是唯一部署候选。没有原生结果选断点、步长搜索、追加步数或换求解器。

这不再求解 T706/T707 的「最小旧损失且七源有限损失逐一不增」约束问题：**本轮目标是学七源，旧损失只提供当前一阶方向约束**。不保留前两轮的七个有限源约束、旧损失目标和 ridge 后又称同一个优化问题。T706 `NumericalError` 和 T707 completed-square `AlmostSolved` 拒绝说明既定求解证书未过，不证明数学不可行，也不证明 A-GEM 有效。T707 [最终账本](t707/FINAL_REPORT.json)记录 18 solver iterations、0 新 Actor、0 Adam/RL；[结果](t707/FINDINGS.md)中旧403/224闭环均未执行，不能补写成失败率。`AlmostSolved` 是主任务本轮提供的原 fit 状态，本研究没有解压原 fit 日志重算。

这次改为一阶基线有清楚的信息增益：去掉大型边界锥求解的数值依赖后，检验已有梯度保护方法能否给出更好的旧403保持—曝光224迁移折中。最坏参考臂只是 Group-DRO-inspired reference adaptation，不是完整 Group DRO 优化器、新算法或论文优越性证据。

## 唯一数据、两个参考与固定更新

本地输入合同来自 [T706 审查](T706_TASKWISE_REPLAY_PRIMARY_REVIEW.md)、[T707 协议](t707/PLAN.md)及既有 [`fit.py`](../../experiments/t706_taskwise_replay/fit.py)：旧 403 条成功轨迹共 81956 决策，七条源成功轨迹 1737 决策，共 83693；原 owncarry、184 维输入、归一化、父链和 108 个 tanh 特征保持。旧目标仍是相对 T694 父链的零 raw 残差，源目标仍是实际动作减父链 raw location，不改为保持 B0 已有错误输出。曝光224只用于最终回归，不新增其标签到 fit。

为消除平方损失及 Hessian 的二倍歧义，锁定以下与既有 Gram 定义一致的表示：

```text
z_it = [tanh(W1 x_it+b1), 1] ∈ R^109
B ∈ R^(109×2), 共218标量；B0 = 原T701 refined108末层
ℓ_i(B) = (1/(2 T_i)) Σ_t ||z_it B-y_it||²
G_i = Z_iᵀ Z_i/(2 T_i), H_i = Z_iᵀ Y_i/(2 T_i)
c_i = ||Y_i||²_F/(2 T_i)
ℓ_i(B) = tr(Bᵀ G_i B)-2 tr(Bᵀ H_i)+c_i
∇ℓ_i(B) = 2(G_i B-H_i)

N(B) = (1/7) Σ_source ℓ_j(B)
G_N = (1/7) Σ_source G_j, H_N 同理
O_mean(B) = (1/403) Σ_old ℓ_i(B)
O_max(B) = max_old ℓ_i(B)
L_N = 2 λ_max(G_N), η = 1/L_N > 0
```

这里每条轨迹先对自身决策与两个输出取均值，再对 ID 均衡；不是将81956旧决策直接混池均值，也不是让长轨迹得到更高权重。`G_N` 应以同一个固定浮点顺序构造并对称化后求最大特征值，两臂共用同一个结果；没有按 arm 或中期损失再调 η。先验检查有限值、对称/PSD舍入误差及 `L_N>0`；不以截断真实负特征值、添加 ridge 或换归一化救实际数据失败。浮点求出的最大特征值与理论真实特征值有舍入差异，须报告特征分解残差和实际逐步二次上界误差，不能把机器计算直接叫严格实数证明。

第 k 步均在**该臂当前 B_k**重算 `g_N=∇N(B_k)` 与参考：

```text
mean参考臂：g_R = ∇O_mean(B_k)
worst参考臂：i* = argmax_old ℓ_i(B_k)，g_R = ∇ℓ_i*(B_k)
              精确相同浮点loss时，按预锁升序ID取首个
s = <g_N,g_R>_F, r = ||g_R||²_F
if r == 0 or s >= 0: d = g_N
else:                d = g_N - (s/r) g_R
B_(k+1) = B_k - η d
```

不冻结 B0 参考梯度；不使用 loss-EMA、新旧加权和、动量、Adam、随机 minibatch、逐源轮换或源损失硬回退。参考精确为零时半空间是全集；非零但很小仍要按原公式处理，不用 `r<epsilon` 的弱阈值跳过，也不把分母改成 `r+epsilon`。实际实现应检查除法和投影残差有限，数值异常保留失败；可以预锁数学等价的稳定范数算法，但不能事后改变规则。两臂都执行128个确定性 full-batch plain-SGD式赋值，严格说是 projected gradient descent，没有本轮随机梯度采样。

最坏臂每步需扫描全部403个**标量损失**以选择 ID，再只求该 ID 的一个参考梯度；不能先算403个梯度却记成一个。标量损失扫描、Gram构造、特征构造、eigendecomposition及审计重算的工作量、时间和RAM另实记。记忆池相同不等于两臂每步实际 FLOPs 完全相同。

## 能保证什么，不能保证什么

下列是固定二次式的实数代数结论。把两列 B 展平，Frobenius内积就是普通欧式内积。无投影时 `d=g_N`；冲突投影时代入公式可得 `g_N·d=||d||²`，且 `g_R·d=0`。非冲突时 `g_R·d>=0`。因此由 L-smooth 上界，

```text
N(B-ηd) ≤ N(B)-η <g_N,d>+(L_N η²/2)||d||²
        = N(B)-(1/(2L_N))||d||²，η=1/L_N。
```

所以固定源**平均**目标理论上不增，`d≠0` 时严格下降；这不保证七个源各自不增或各自原生成功，也不保证128步达到源无约束最优解。`d=0` 可因冲突恰好相反而停滞，不能当新任务已经学好。不得把普通 GD 的全局最优收敛率直接移植到这个随 B 变化的投影半空间迭代。

对于光滑旧参考目标 Q，本轮只约束 `-η g_R·d<=0` 的一阶项。实际二次变化是

```text
Q(B-ηd)-Q(B) = -η <g_R,d> + η² tr(dᵀ G_Q d)。
```

投影边界上一阶项为零而曲率项通常正，所以有限一步旧损失仍能增加；重复128步可累积。旧平均臂也允许个别 ID 一阶退化。参考梯度恰为零时合法跳过保护，而二次旧损失仍能增长；零梯度不是遗忘安全证书。源平均下降同样不能替代闭环导航，策略会改变以后访问的状态。

最坏旧 ID 在唯一活跃时，其梯度就是 `O_max` 的梯度；平局时，选一个活跃梯度仅给出 max 的一个合法次梯度。对活跃集合 A，沿实际方向 `-d` 的 max 方向导数为 `max_{i∈A} <-∇ℓ_i,d>`。**约束所选 ID 不等于约束所有平局 ID**，因此连 max 的一阶非增也不能普遍宣称。预锁 ID 平局规则保障可重复性，不修复该保证缺口；不临时扩大为多约束 GEM 或按结果改 tie tolerance。近乎平局也可能换最坏 ID，引起参考切换；报告 ID 切换、精确平局和投影次数。

最坏平方动作误差 ID 未必是闭环最危险或当前丢失 ID；高误差容易任务可能长期主导参考。整套特征不变也可能根本无法同时表达更多源能力和旧行为。正反结果只适用于这组历史监督、容量、初始化与128步规则，不能据此否定一般 A-GEM、Group DRO、BC 或端到端 RL。
