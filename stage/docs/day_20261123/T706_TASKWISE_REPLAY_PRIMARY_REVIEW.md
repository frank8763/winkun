# T706：逐任务源约束与最坏旧任务回放的一手审查

2026-11-23，Stage only。本文仅阅读既有文本结果、协议、源码及一手论文/作者代码；没有加载模型、生成特征、拟合、原生积分、创建run或修改实验代码。T698仍为保留模型。本建议须另立有界协议，不能续用已结束T705的预算或截止时间。

## 建议

**选两臂：共同保护原七源各自的损失上界，对照最小化旧403任务均值，候选最小化旧403任务最大损失。** 两臂冻结同一原始refined108特征、同一父链及数据，仅替换同218个末层参数，均为161584B新增部署张量。这是已知Group DRO目标在固定读出上的适配及一个精确约束消融；不是新算法，也不能由此宣布优于已发表导航方法。

两臂能够回答一个清楚的问题：当源任务不再互相抵消时，把旧任务损失从平均改为最坏ID，是否改善闭环保持—迁移折中？其中逐源均值臂与T705已有aggregate约束解构成历史对照，但两者的差异只能描述，不能把新两臂的全部收益归因于两个因素各自。此次无需加入弱实现的GEM、额外EWC权重搜索或新特征训练。

## 唯一数据、初始模型与数学目标

沿用原数据契约：403条旧成功轨迹81956决策、7条源成功轨迹1737决策；全83693决策，历史owncarry特征。旧目标为相对T694父链的零raw残差，源目标为既有实际动作减父链raw location；不改成拟合原refined108的旧输出，不新增224测试标签。定义

```text
z_gt = [tanh(W1 x_gt+b1), 1] ∈ R^109
B ∈ R^(109×2), B0 = 原T701 refined108末层（不是T705任何一臂）
L_g(B) = (1/(2 T_g)) Σ_t ||z_gt B-y_gt||²
O = 原403旧ID，N = 原7源ID
c_j = L_j(B0), j∈N
rho = 1e-10 trace(G_old_mean)/109（与T705同规则）
R(B) = rho ||B-B0||²_F

对照：min_B (1/403)Σ[g∈O] L_g(B) + R(B)
候选：min_B max[g∈O] L_g(B) + R(B)
共同约束：L_j(B) ≤ c_j，全部7个j分别成立
```

`B0`在数学上必可行，不应被宣布为真实冲突导致不可行。七上界必须由同一个原始B0重算，不取T705更低均值再分摊，也不放宽到能通过才停。候选的等价凸epigraph形式为`min t+R(B)`，加403条`L_g(B)≤t`和相同七源约束。`rho>0`给出参数的严格凸正则目标，须在两臂一致，并承认最优性针对**含该稳定项**的目标。单次平均旧MSE甚至可在max臂变差，这正是需要真实测量的取舍。

候选只最小化最坏**轨迹平均**动作误差；不是最坏时间步、碰撞概率或真实回报。全403ID预先包括，不只选T705丢失的12个，不按结果重新归一化每ID损失或加分位数调参。若少数高损失且本来容易的轨迹主导最大值，最坏损失仍可能与闭环失败无关；这是该假设的重要反证，不应再改分组挽救。

全部184维输入构造、父链、108个tanh特征、归一化、执行clamp/float32、重置/owncarry、终止/奖励均固定。任务ID只用于离线损失分组，不输入部署Actor。容量要报告完整161584B加共同父链2621976B，不能只报1744B可修改末层；缓存/求解器/RSS/部署延迟另计。

## 确定性凸求解与独立证书

建议锁定一个float64锥实现：Clarabel+SciPy sparse，仅依赖独立安装目录，固定wheel版本及SHA后才launch。官方[Python接口](https://clarabel.org/stable/python/getting_started_py/)支持PSD二次目标与复合锥，官方[settings](https://clarabel.org/stable/api_settings/)有`max_iter/time_limit`及原始/对偶可行性和gap容差。它不是SciPy通用局部优化器的“success即全局”替代说法。

每个任务将`r_g(B)=vec((Z_g B-Y_g)/sqrt(2T_g))`写成仿射函数。源约束为`||r_j(B)||≤sqrt(c_j)`；候选旧epigraph可用标准SOC恒等式`||[2 r_g(B),t-1]||≤t+1`表达`||r_g(B)||²≤t`。需要控制锥尺寸时，可用预定QR压缩每ID的增广`[Z,Y]`，保留残差常数；不能丢小奇异方向、临时加ridge或把负舍入常数截断后冒称原问题完全相同。所有压缩结果须与全数据损失重算一致。采用何种压缩在真实数据求解前锁定。

保存并独立重建两臂：全逐ID损失及七源上界、primal/dual残差、乘子、互补、stationarity及primal-dual gap；检验完整模型只有末层改变。均值臂KKT为`∇L_old_mean+2rho(B-B0)+Σ_j λ_j∇L_j=0`。max臂另有旧ID权重`α_g≥0, Σα=1`，stationarity将`∇L_old_mean`替为`Σα_g∇L_g`，且`α_g(L_g-t)=0`。七源均需`λ_j≥0, λ_j(L_j-c_j)=0`。用同一Lagrangian的二次最小值算对偶下界；只看solver状态、参数差小或loss下降不够。

建议预锁float64缩放后的原始损失容差`1e-10+1e-8*c_j`、目标gap `≤1e-9+1e-6*|primal objective|`及有单位说明的stationarity残差，并用toy检查可实现性；数值误差与实际允许的源退化分开报告。严格边界可无Slater条件；预算内未获证书是数值失败，不增加容差、迭代或源上界救。若验证了B0却solver宣称不可行，应判工程/数值拒绝，不能判这项科学问题无解。

## 显式新预算，不能藏在“一次构造”中

旧campaign的Actor账本已4089/4096、剩7（来自主任务的当前账本报告；本次未重算全账）。**这7不能支付迭代QCQP。** 两个新读出文件各导出一次不等于只做两次优化。应冻结旧账本，在新T706协议中明写额外求解预算及授权来源，不能把新增迭代偷偷并入旧cap或称没有优化。

可用明确上限：每臂每次求解最多256个interior-point迭代；live、shadow、independent各两臂，共最多1536个科学solver迭代，6次solver调用。预检toy最多4次×64迭代=256另计，最高总1792；所有失败、被拒绝和中断的实际迭代仍计。额外线性分解、equilibration、iterative-refinement及证书重算用固定设置与工作量/墙钟账记录，不能称其免费。精确字节重建若依赖固定包、线程及顺序须预检；无法逐位重建则预先规定可检验的数值+证书合同，不能事后改审计标准。主任务如选择更紧预算，应在真实拟合前锁定。

两臂享有相同上限、环境和输入；达到数值证书就结束，不故意补无效迭代以凑实际compute相等。报告两臂实际迭代、分解/solve数、时间和峰值RAM。fit/audit/deployment测量都留预算；不得用“只改218参数”掩盖训练成本。当前环境缺失依赖的安装只是工程准备，若失败便拒绝launch，不在学习中换solver反复尝试。

## 两臂、2×2及发表方法基线的取舍

完整2×2为`mean/max old × aggregate/per-source`；T705已有mean+aggregate的实际解，但还缺max+aggregate的新解。四格若均新跑known431+224会显著增加物理验收（主任务估计最坏约8h），虽然能估交互作用，却超出本轮最集中的问题。**推荐只新跑上述两臂（主任务拟约4.5h），T705数字按历史对照引用，明确没有完整交互消融。** 若将来要断言每个因素贡献，另立完整2×2而不是在本轮结果后补最有利那格。

Group DRO是这里最有根据的公开目标基线，候选本身就是其受约束适配，无需凭空另起一个“我们的方法”来胜过它。GEM/A-GEM的忠实梯度版本还需要新学习率、步数、记忆抽样和任务顺序，当前固定小型凸问题加入它们会混合优化误差及目标差异，不能用简陋版本制造论文胜利。EWC以参数重要性二次惩罚保护旧知识，需Fisher/强度及概率模型合同；[原论文](https://doi.org/10.1073/pnas.1611835114)。LwF用新任务数据上的旧输出蒸馏，原设定不需旧训练数据；[作者论文](https://arxiv.org/abs/1606.09282)。当前已有完整旧数据，且目标是修复B0遗忘；把B0输出作为旧教师会保护已有误差。两者可作后续匹配基线，此次不优先。此处仅采用上述原理范围，未声称阅读两者完整作者实现。

## 物理验收与失败门槛

两臂拟合证书合格后均完整测known431及已曝光224，使用与T705同初态SHA、顺序合同、owncarry、执行路径和固定exact repeats；不得让任何一臂因先丢旧ID而只测有利子集。完整资源准入不足则拒绝整个launch，不删减比较对象。与T705逐ID报告old403丢失/恢复、新224gain/loss及source7、core407、supplement24；related starts不当独立地图，不做伪独立显著性声明。

预注册主要比较为max臂对mean臂，另列原refined108和T705历史结果。合理遗忘已被用户接受，因此不以零旧丢失作为实验准入条件。一个清楚的操作进步门是：max臂相对新mean臂**严格减少旧403丢失且224成功不低**，或**旧丢失不增且224严格增加**；同时如实列source7物理变化。另报告是否超过T705的12丢失/100成功折中。只在一个指标变好、另一指标变坏时报告折中，不另配权重宣称赢家；无法支配也不抹去真实局部改善。

源七MSE皆不增却仍源6/7，或max旧MSE下降但旧闭环丢失不降，都是本假设的重要负结果。固定历史监督没有覆盖新策略访问的状态，顺序动作会改变未来观测，这一点已有一手分析，[Ross等2011正文](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)；本文不把这个一般事实当Stage具体失败因果证明。无论结果如何，不按物理结果改ID、rho、上界、特征或求解精度，不加seed救。证书合格而闭环失败，只否定此固定读出/分组/数据上的具体提议，不证明BC、Group DRO或端到端RL普遍无效。

即使两臂出现有限成功，也仍是已曝光数据与同图回归上的操作进步；正式保留T698的412成功合同与本轮修复的403集合不同，不能自动替换。若要声称超过现有论文，需要另行设计匹配信息/容量/数据/计算的直接方法比较与未曝光场景证据。本轮只完成一个能明确支持或推翻的下一步，不讨论期刊、不虚构创新。
