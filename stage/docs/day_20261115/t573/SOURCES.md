# T573：真实失败前缀上的恢复资格检查

2026-11-15；本次查阅论文正文及作者仓库 README，未运行作者代码，未检查 Stage 代码、runs 或 Phase。下述 T573 设计来自本轮任务简报，尚非实验结果。

- **DAgger 的依据与边界。** Ross、Gordon、Bagnell（2011）§3 / Algorithm 3.1 在当前策略访问的状态上取得专家动作，聚合数据后再训练；§4 的结论有损失、学习器及采样条件。它支持关注学习者自身造成的状态分布，但“只在成功教师轨迹上动作拟合得很近”不能替代闭环检验。T573 为零学习资格检查，未做迭代聚合训练，不称完整 DAgger，也不继承其理论保证。[论文正文](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)
- **DART 的依据与边界。** Laskey 等（2017）§1、§4 / Algorithm 1 在教师控制流中注入噪声，并利用学习者误差迭代优化噪声分布，使示范覆盖纠错状态；作者实现区分 `test_dart.py` 的迭代噪声优化与固定各向同性/随机协方差对照。T573 使用 A 自身真实失败前缀上的一个固定分支，不新增噪声分布优化，因此只借鉴“检查纠错覆盖”的动机，不称 DART 复现或新 DART 方法。[论文正文](https://proceedings.mlr.press/v78/laskey17a/laskey17a.pdf)，[作者实现说明](https://github.com/BerkeleyAutomation/DART)

**本轮设计推论。** 同初态 T550 已知成功轨迹只用于预先确定参照：固定在 A 相对该轨迹首次达到 3 cm 或 3° 偏离之前的一个早期决策点，不根据恢复结果寻找更好的点。A 的实际完整失败重放提供其自身原生状态、真实观测/动作历史和 qfull/GRU 前缀；不能将 T550 教师的隐状态或历史拼接给 A。训练侧既有 T544 反应式反馈须在该真实分支读取当时可用输入并实际闭环续行，才有资格谈该点可恢复；单步标签接近、有限点动作界或教师原轨迹成功均不足以证明这一点。以上是项目实验设计判断，论文没有直接验证该 GRU/教师组合。

**解释口径。** 零学习诊断中的教师仅检验实际恢复资格，不构成部署时教师切换、规划器、地图或路点；即使该固定分支成功，也只支持该分支恢复，不代表 A 已学会、全场泛化或可以晋升。若失败，保留失败；不据此自动追加点位、噪声、训练预算或承诺后续学习成功。
