# T574 — sources and limited diagnostic use

Read 2026-11-15. Stage only. This note supports a frozen, training-time neural-teacher qualification test; it does not authorize learning or extra runs.

## Primary literature

**Ross, Gordon & Bagnell (AISTATS 2011), _A Reduction of Imitation Learning and Structured Prediction to No-Regret Online Learning_.** [Proceedings PDF](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf), §3 / Algorithm 3.1, pp. 629–630. DAgger collects trajectories under the current learner/expert mixture, queries the expert on visited states, aggregates labels, and retrains. Thus successful expert demonstrations from the expert's own state distribution do not replace querying the states the learner actually reaches. **T574 inference:** test T550 on the actual T572A prefix before treating its outputs as useful recovery supervision. T574 has zero retraining and is not a complete DAgger implementation. The paper provides no guarantee that this particular neural teacher can recover this state; its no-regret bounds are not claimed here.

**Kapturowski et al. (ICLR 2019), _Recurrent Experience Replay in Distributed Reinforcement Learning_ (R2D2).** [OpenReview PDF](https://openreview.net/pdf?id=r1lyTjAqYX) ([indexed PDF](https://openreview.net/pdf/387fb2fcee8f74c53cf707a9856f40c458f33933.pdf)), §3, pp. 3–5. The authors distinguish initial recurrent-state mismatch from stored-state staleness caused by parameter/representation changes. Burn-in unrolls a prefix to produce a recurrent state while excluding that prefix from learning updates; their reported mitigation is empirical. **T574 inference:** reconstruct each frozen network's own hidden state from episode-start zero by feeding the complete actual observation prefix, then maintain its own continuous carry. A hidden state from another policy or an unrelated historical teacher trajectory is not substituted. This full-prefix reconstruction is a local causal-history contract, not R2D2 training or a transferred Atari/DMLab result. With frozen parameters, parameter-lag staleness is not asserted as the observed failure cause.

## Existing Stage contract and bounded interpretation

The implementation precedent is [T525 runtime](../../../experiments/t525_student_state_recovery/t525_runtime.py): `RecoverySession` advances the teacher on actual observations; `check_prefix` compares student-prefix arrays; `audit_recovery` rebuilds both recurrent histories; the full-teacher qualification gates a fixed 20-decision / 4-second correction and student return. T574 reuses that contract with its separately registered models, fixed 17.8-second handoff, full arrays and exact replay, and **zero optimizer/learning updates**. It is not a new RL algorithm.

T550's prior same-task success from the original start is historical evidence, not recovery qualification from T572A's different state/history. First test the full teacher continuation from the unchanged actual student prefix. Only if that reaches native safe GOAL may the fixed 4-second intervention followed by student return run. Preserve both networks' own carry throughout the actual mixed observations, the original episode clock and simulator state. A mixed trajectory reaching GOAL is intervention evidence, not autonomous student improvement or generalization. A failed teacher continuation rejects this teacher for this recovery state; it does not establish task impossibility.
