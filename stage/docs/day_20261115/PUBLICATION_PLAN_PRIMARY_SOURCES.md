# 日间计划的一手依据与发表边界

2026-11-15。本次仅阅读与检索：0模拟器、0训练、0优化器，不注册或启动T553。范围仅Stage。项目事实依据为[T552今晨核验](T552_MORNING_RESULTS.md)与[跨场地研究草案](../day_20261114/CROSS_SITE_RESEARCH_PLAN.md)。以下是短核查，不是穷尽综述、新颖性认证或录用预测。

## 四项可用结论

1. **CAGrad适合作为梯度冲突对照，不能作为导航安全或旧任务保持保证。** 原方法在平均梯度附近选择改善最差局部一阶变化的方向；Theorem 3.2在光滑性、步长等条件下，对`0≤c<1`给出平均损失的平稳性结论。摘要中的“minimum”不宜被扩写为非凸网络全局最优。尤其，mini-batch损失、Adam最终参数变化、长期闭环安全成功是不同对象；Stage应记录梯度内积及实际参数步，并用冻结闭环逐ID检验。只加CAGrad不是原创贡献。[NeurIPS 2021原文，§3.1、Theorem 3.2](https://proceedings.neurips.cc/paper_files/paper/2021/file/9d27fdf2477ffbff837d73ef7ae23db9-Paper.pdf)

2. **TaSIL支持研究局部响应匹配，但有限采样不等于覆盖整个恢复邻域。** 原文通过Taylor项匹配缓解策略分布偏移；Proposition 3.1要求专家闭环具有局部增量输入状态稳定性，并要求轨迹管内的最坏策略误差受界。少量动作扰动/有限差分通过，不能直接证明其连续邻域条件，亦不能直接套用于尚未验证稳定性的Stage教师、GRU因果历史与接触动力学。若只实现有限扰动响应项，应称“受TaSIL启发的有限邻域基线”，并另测未消费的真实偏离家族。[NeurIPS 2022原文，§3、Proposition 3.1、Theorem 3.2](https://proceedings.neurips.cc/paper_files/paper/2022/file/7f10c3d66c3b7863a9cda255dcac5bb7-Paper-Conference.pdf)

3. **旧经验回放和蒸馏保持已有CLEAR先例，不保证所有旧ID永不失守。** CLEAR在新经验上学习，并在回放上做off-policy学习、历史策略KL与价值输出克隆，以缓解遗忘；其§6亦讨论适用限制。Stage采用真实RL加历史动作保持时，应承认方法近邻；若没有V-trace及价值克隆等原合同，不称完整CLEAR复现。T552的“修复5项、丢3项”说明平均收益与逐任务保持必须分别报告，损失保持不能取代闭环验收。[NeurIPS 2019原文，§3、§6](https://proceedings.neurips.cc/paper_files/paper/2019/file/fa7cdfad1a5aaf8370ebeda47a1ff1c3-Paper.pdf)

4. **泛化评价必须主动改变条件；其他机器人领域的结果不能充作Stage导航证据。** COLOSSEUM将机器人操作策略放在系统环境扰动下评估，并另做相应实机实验；这支持把开发集、扰动评估和实机证据分开。其操作任务、视觉扰动和数值结论不能直接移植到激光雷达车辆导航。Stage仍须整布局留出、合法物理扰动、独立实体场地验证；零样本与有限适应分别报告。[RSS 2024作者项目页及摘要](https://robot-colosseum.github.io/)

## 对日间计划的直接约束（项目建议）

- 先完成T553的协议、独立预检及零物理机制核查；T552没有试过CAGrad或累计命令漂移约束，不能把草案当已运行结果。用同一父策略、数据、容量与预算比较普通联合学习、CAGrad，以及累计漂移项；先隔离变量，再考虑组合。
- 首个pilot回答“在修复旧失败时，是否减少同候选旧成功ID丢失，并扩大未消费扰动恢复范围”。保留T550与全部拒绝候选；以完整逐ID成功/碰撞/超时、参数步及动作漂移为主要证据。若仅训练损失变好或总成功数上涨，机制尚未成立。
- 跨场地与实体实验是后续证据阶段，不由单场地pilot通过自动推出。方法形成后还需全文新颖性核查、预算匹配的标准基线与消融、独立训练重复及跨布局不确定性报告；不能凭“单Actor+RL+回放+局部约束”宣称新算法。
- **不得把“100%成功”或“固定几个训练种子”写成机器人顶刊的普遍规定。** 本文未核验具体目标期刊的投稿规则，不声称存在这种统一硬门槛。逐ID零退化、pilot放行、种子数和置信区间精度均应明确为项目自行预注册的门槛；正式数量由待验证主张、独立单位、方差和可用预算决定。确定性精确重放不增加独立样本数。
