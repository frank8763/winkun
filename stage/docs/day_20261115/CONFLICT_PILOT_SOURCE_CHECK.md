# 恢复／保持冲突 pilot：原文、作者实现与可证伪条件

2026-11-15；Stage only。本文只读来源与已有诊断，未训练、未启动原生、未修改科学代码。读取 CAGrad 正文 §3.1–3.2、作者实际实现；仅为核对约束替代方案补读 GEM §3 与作者投影代码，不作宽泛综述或原创性判断。项目起点见[日间计划](DAYTIME_AND_PUBLICATION_PLAN.md)、[T552结果](T552_MORNING_RESULTS.md)。

**结论：梯度冲突值得有界机制检验，但不应按原样启动未归一化 `c=.5`。** 新诊断表明该球约束在已保存 behavior/candidate 上根本不能提供保持损失的一阶非增方向；运行它最多检验“减少损害”，不能公平检验“冲突协调能否保持旧能力”。下一步先做同状态、同成熟 Adam 的方向与步长诊断，再只选一个通过数值门槛的机制进入原生 pilot。累计漂移项应后置，否则两种解释混在一起。

## 1. 作者实际做了什么

CAGrad 对下降向量 `d` 解 `max min_i <g_i,d>`，约束 `||d-g0||≤c||g0||`，`g0` 为平均梯度；权重在 simplex 上解 `min_w <gw,g0>+c||g0||||gw||`。这优化局部最差改善，**不是所有损失非增硬约束**。Theorem 3.2 在光滑、有限下界与指定固定步长条件下，对 `0≤c<1` 给平均损失的平稳性结论；不覆盖 Stage 的 top-k/PPO 非光滑代理、Adam 最终位移或接触闭环安全。[CAGrad 原文，Eq.3、Algorithm 1、Theorem 3.2](https://proceedings.neurips.cc/paper_files/paper/2021/file/9d27fdf2477ffbff837d73ef7ae23db9-Paper.pdf)

作者仓库核定 commit `dc3d48152b6196945cfd56144879b9d42353b095`，根许可证为 MIT；不同实验实现**并非同一个数值合同**：

| 实际阅读的作者代码 | 求解与缩放 |
|---|---|
| [toy.py L299–327](https://github.com/Cranial-XIX/CAGrad/blob/dc3d48152b6196945cfd56144879b9d42353b095/toy.py#L299) | 两任务，SciPy `minimize_scalar(method='bounded')`；多处 `1e-4` 稳定项；最后除 `1+c`。 |
| [nyuv2/utils.py L377–425](https://github.com/Cranial-XIX/CAGrad/blob/dc3d48152b6196945cfd56144879b9d42353b095/nyuv2/utils.py#L377) | 三任务 simplex SciPy `minimize`；`1e-8` 稳定项；默认除 `1+c²`，写回时乘任务数3，以匹配 sum loss；随后 optimizer.step。 |
| [mtrl/mtrl_files/cagrad.py L217–278](https://github.com/Cranial-XIX/CAGrad/blob/dc3d48152b6196945cfd56144879b9d42353b095/mtrl/mtrl_files/cagrad.py#L217) | `cagrad` 先缩放 Gram，再用20次 SGD 优化 softmax 权重、取21次目标中的最好值，最后除 `1+c²`；`cagrad_exact` 则梯度除100、SciPy simplex 求解、最后除 `1+lambda` 并乘100。 |

因此 Stage 草案 `2*(g0+lambda*gw)/(1+c²)`可称 NYUv2 风格 sum-loss 缩放的**两目标 CAGrad 改写**；不可称逐字复现 toy 或作者多任务RL。作者代码及其常数都不是本任务选 `c=.5` 的有效性证据。[作者 LICENSE](https://github.com/Cranial-XIX/CAGrad/blob/dc3d48152b6196945cfd56144879b9d42353b095/LICENSE)

## 2. 当前草案的精确含义与必要求解核验

[t553_learning.py](../../experiments/t553_conflict_drift_relay/t553_learning.py) 的两组是：BC时 `L_R=L_restore`、`L_K=L_keep+L_neighbor`；RL时把 PPO 加到 `L_R`，保持 `L_K`。三类历史仍各自按轨迹数平均、每轨迹半均值加半 top20%；没有新增容量或可训练骨干。组内的 restore/PPO、keep/neighbor 及不同ID之间冲突没有独立保护。T552基线是上述损失直接相加，实际协议是32 BC及最多4 PPO更新、KL早停，不应把上限写成必定4步。[T552实际损失与Adam](../../experiments/t552_joint_robust_night/t552_actor.py)

固定一维求解可以无 SciPy：令 `A=||g_R||²,B=<g_R,g_K>,C=||g_K||²`，

```
q(w) = w² A + 2w(1-w)B + (1-w)² C
F(w) = [w(A+B)+(1-w)(B+C)]/2 + c ||g0|| sqrt(q(w))
g0 = (g_R+g_K)/2;  gw = w g_R+(1-w)g_K
d_sum = 2 [g0 + c ||g0|| gw/||gw||] / (1+c²),  w∈[0,1]
```

这是由原文二目标 dual 作的代数展开。草案使用64次 golden-section 加两个端点，`sqrt(max(q,0)+1e-16)`及最终 `||gw||+1e-8`，而 `||g0||` 不加 epsilon；应锁定为自己的数值近似。原生前独立检查：float64 Gram/PSD误差、零梯度/同向/反向/尺度悬殊、`c=0`与原 sum 更新一致、端点/区间最优性、原始未缩放球约束与真实最小内积；不得只检查 loss finite。极小 `g0/gw` 必须显式分支并记录；单位化不得放大数值零。原始球约束针对未乘缩放常数的 `d`，不能直接拿 `d_sum` 验球。[公式来源](https://proceedings.neurips.cc/paper_files/paper/2021/file/9d27fdf2477ffbff837d73ef7ae23db9-Paper.pdf)

## 3. 新诊断已排除原样 c=.5 的保持可行性

只读父任务生成的 [T554 diagnostic.json](../../runs/t554_day_conflict_probe/diagnostic.json)，本次读到 SHA256 `ef928f66932898b427ef63303647ab43a3bd2454067fc7f20efeba862a3cd1f6`。其中梯度用同一已保存 behavior 数据计算；candidate处不是新鲜 on-policy 证据。下表阈值由已存范数与余弦直接算出，不是新梯度或优化器实验。

| 已存位置 | `||g_R||/||g_K||` | `cos(g_R,g_K)` | 保持可行所需最低c |
|---|---:|---:|---:|
| 32 BC后 behavior，`R=restore+PPO` | 377.44 | −0.59835 | 0.5966406 |
| 4 PPO后 candidate，同saved behavior数据 | 312.13 | −0.72454 | 0.7230153 |

推导：球内可达到的最大保持内积是 `<g_K,g0>+c||g_K||||g0||`。其为负时，**每个允许下降方向都使保持代理一阶上升**；故必要条件 `c≥max(0,−cos(g_K,g0))`。正的最终标量缩放不能改变符号。`c=.5`在两处均不满足。这比“余弦为负”更直接：负任务余弦本身并不必然意味着联合步损害任一任务。

behavior处 `g_K·Δθ_actual=+2.26225e−7`，真实保持代理从 `1.03276e−6` 增至 `1.30054e−6`；一致支持本段更新存在代理冲突，却不能单凭此证明三项场地失守完全由此造成。初始保持梯度仅 `3.79e−17`，其余弦没有实质解释力；零误差MSE的首阶梯度不能保护其二阶增长。

## 4. 只选一个可解释的后续机制，不堆叠

以下是依据几何与现有实现提出的项目设计，**不是来源已证明在Stage有效**：

1. **若仍检验 CAGrad：** 先按已观测几何确定并预注册一个 `c<1`，通过同状态实际Adam位移检查后才付原生预算；不能把 `.5` 换成一串网格。更大的c只解除球的可行性障碍，仍不保证优化结果、Adam位移或闭环保持。每一步都记录可行性阈值，门槛失败即按协议停止，而非自动扩大c。
2. **若检验尺度失衡：** 两个目标按预声明规则重加权，并以同样重加权的普通 sum 为对照。尤其对两个非零梯度各自单位化后，它们等范数；`w=.5`是对称最优解，CAGrad方向与单位梯度平均方向相同，仅差标量。因此“unit-normalized CAGrad优于原sum”不能归因为特殊方向协调。动态归一化也已改变原平均目标；近零保持梯度需固定阈值，不能把初始浮点噪声放大。
3. **若问题是实际步损害保持，优先先做单保持半空间诊断：** 从同θ、同成熟Adam状态生成普通提案 `u=θ_proposed−θ`，对非零 `g_K` 取 `u_proj=u−max(0,g_K·u)/||g_K||² * g_K`。它是距离原提案最近、满足 `g_K·u_proj≤0`的位移。此公式是项目对 GEM 投影思想的单约束、**Adam之后**改写；不是原GEM复现，也不保证每个ID或有限步真实损失保持。若后续采用，必须预注册Adam矩状态处理与原子拒绝回退，再检查实际非线性损失；不能投影后再交给Adam变换一次。

GEM原文把旧记忆损失的局部线性非增写成梯度内积约束，投影到满足约束的最近梯度；作者代码 `project2cone2` 使用 quadprog，且 optimizer 是 **SGD**。所以直接将其原始梯度投影放到Adam前不获得同样的实际位移约束。[GEM原文 §3、Eq.7–8](https://arxiv.org/pdf/1706.08840)；[作者代码 L65–104、L181–195，commit 34c6b8e9a0607db7567301c48b727430d20bee7e](https://github.com/facebookresearch/GradientEpisodicMemory/blob/34c6b8e9a0607db7567301c48b727430d20bee7e/model/gem.py#L65)

## 5. 区分方向收益与小步收益的最少控制

- **普通sum、机制候选、实际位移等范数普通sum**三者。先在相同θ、完整Adam矩/step、数据与clip条件下制作丢弃克隆；设普通位移 `u0`、机制位移 `uM`，等范数控制为 `u0*||uM||/||u0||`。零范数明确处理；只缩梯度不足以匹配Adam位移。该控制不沿机制方向、无需搜学习率，可直接比较两个损失的有限步变化。它先是离线方向诊断，不能当作在线效果。
- 若进入多步原生pilot，预注册各臂独立Adam状态与逐步位移匹配规则，报告累计路径长度、最终位移、KL、实际动作RMS/最大/累计漂移。仅最终位移等长不能排除中间路径不同；仅参数范数相同也不等于函数变化相同。固定规则用诊断得出，不能看原生结果后调步长。
- 保留相同T550、5986读出、初始化、历史与权重、BC/PPO上限、clip/early-stop、真实交互与教师预算。每个不同新behavior自行采集PPO数据；历史T552只能在全部合同匹配时复用作已完成基线，不能冒充新policy数据或新增独立样本。原样基线无需重复物理支付。
- 为单独定位PPO冲突，可先固定相同32 BC behavior，只改之后有界PPO更新规则；若同时协调BC与PPO，结论只能归于整条联合更新管线。保存BC结束及PPO结束分项损失/梯度/候选；逐历史检查可揭示两个聚合目标掩盖的ID退化。
- 原生只在数值门槛过后，用同一38项逐ID新增/丢失与精确重放验收；通过才进入完整407。D加累计漂移E在第一轮不能替代等步控制。若预算不含原生等步对照，只能报告工程候选收益，不能宣称方向协调是因果机制。

## 6. 什么结果会否定什么

| 观测 | 可否定或削弱的解释；不能推出的结论 |
|---|---|
| 合法非零梯度处普通实际位移已对两代理非增，仍有同ID失守 | “当前两聚合代理的一阶冲突足以解释失守”被削弱；仍可能是曲率、组内冲突或历史覆盖外漂移。 |
| 原始梯度内积改善，但实际Adam位移仍损害保持 | 当前梯度协调位置/优化器接口失败；不能称已经解决优化冲突。 |
| 等范数普通控制同样保留并恢复，机制没有额外收益 | 方向改善解释未获支持，步长/保守性足以解释；不宣布普遍CAGrad无效。 |
| 代理保持通过但同旧ID照样丢失，或keep整体改善而单ID恶化 | 两个聚合历史代理不足以保护闭环；优先覆盖/逐ID/曲率诊断，不继续同机制无限加轮。 |
| 不丢旧ID但无新增恢复，或步长趋零 | 只实现保守停滞，未取得可保留进步。 |
| 只有加累计项后才改善，或只在已消费开发ID改善 | 不能把收益归因于CAGrad；不能称未见布局泛化或实体车验证。 |
