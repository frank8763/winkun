# T575之后：修新损旧的解决路线（一手来源复核）

**建议把下一机制改为：完整历史的学生自分布数据聚合，联合旧行为保留，先查表达能力，再用自主闭环决定接受。** 继续只在旧成功轨迹加权、改ridge系数或收紧静态误差上限，不能解决已出现的分布偏移与闭环敏感性；也不能据当前结果断言整个神经Actor容量不足。

## 项目事实与待证解释

[T575原报告](FINAL_REPORT.json)为COMPLETE，但候选拒绝：当前旧22项复习加一条实际成功的完整神经教师恢复，最后32项自主20成功；sector2_offset2恢复，dev_task6_13、sector1_offset1、sector1_offset2丢失。旧轨迹location RMS约0.0021—0.0127仍发生失败。冻结GRU/骨干和32个tanh特征，仅更新33×2=66个线性系数；一次task-balanced ridge数值解合格，不能说明闭环保留合格。T572R更紧静态约束也未保住旧闭环，见[当前研究状态](../../RESEARCH_STATUS.md)。这些结果支持“旧分布拟合误差不是可靠闭环成功代理”；尚未分别证实是特征冲突、覆盖不足或稳定裕度不足主导。

新增[只读诊断](POSTHOC_INTERFERENCE.json)：4839×33旧特征矩阵按Torch默认容差秩33、最小奇异值4.8383、条件数54.76，零空间维数0；只有末层weight/bias变化。三条丢失旧历史的实际命令最大变化约0.03661、0.01035、0.05170，提示平均RMS会掩盖峰值。T550历史参考成功集合为23项，T572A当前为22项，T575为20项，比较必须保留各自集合；不能混模型拼成绩。

## 五个最相关方法及适用边界

| 原始来源 | 可借鉴的机制 | 在本项目不能宣称的结论 |
|---|---|---|
| [DAgger，Ross等，AISTATS 2011，§3/Theorems 3.1–3.2](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf) | 当前学生执行、专家给访问状态标注，累积全部轮次数据再学；直接针对仅专家轨迹训练后的分布偏移。 | 理论有专家可标注、策略类误差和无悔学习等条件；是自分布期望损失/任务代价结果，不是每轮旧任务零退化。连续控制location MSE没有自动成为碰撞损失上界；恢复专家代价敏感性也需验证。 |
| [DART，Laskey等，CoRL 2017，§3–4](https://proceedings.mlr.press/v78/laskey17a/laskey17a.pdf) | 对专家动作注入与学生误差匹配的扰动，使专家示范纠错，补单条轨迹周围恢复覆盖。 | 仍是扰动专家分布近似学生分布；噪声大小/方向不匹配、专家不能恢复时会失效。不能把随机加噪当作鲁棒性保证，更不能代替当前学生真实失败前缀。 |
| [CLEAR，Rolnick等，NeurIPS 2019，§3–4/§6](https://proceedings.neurips.cc/paper_files/paper/2019/file/fa7cdfad1a5aaf8370ebeda47a1ff1c3-Paper.pdf) | 新经验保持可塑性，旧经验回放与旧策略分布KL蒸馏保持行为；无需部署任务ID。论文特别区分同时训练时的任务干扰与顺序覆盖造成的遗忘。 | 原方法含新/旧经验RL、V-trace及价值蒸馏；本项目只借监督回放不能称完整CLEAR。已有旧轨迹回放后仍损旧，意味着还须检查覆盖/表示冲突；KL保留也是分布上的软约束。 |
| [Policy Consolidation，Kaplanis等，ICML 2019，§3.2](https://proceedings.mlr.press/v97/kaplanis19a/kaplanis19a.pdf) | 用多个时间尺度的历史策略在函数空间约束当前策略，比只保护参数位移更贴近行为；历史网络只服务训练。 | KL在所采状态分布计算，不能保护未访问的旧状态邻域，也没有闭环稳定保证；当前已经做旧函数保留，因此单加更多历史网络不是优先变量。 |

## 下一协议应解决什么

1. **先做可塑性受控对照，避免重跑T571。** T571已有21条自身成功history＋2恢复源＋5986参数残差512BC，仍修新损旧；T575已有22条自身history＋1完整合格恢复。下一容量pilot应固定T575的数据、初始函数、冻结骨干及监督目标，对照“只训练66个末层参数”与“允许同一平滑残差的非线性隐藏层一起训练”，单独检验固定特征限制；优化方法/预算差异须明示，不能宣称纯参数量因果。用每任务误差、峰值和自主旧成功ID保留判断，不能只看总体平均。不是泛称“再加回放/更大残差”。
2. **随后做真正的新旧自分布聚合。** 固定候选自主跑共同32项新旧任务，将本轮真实偏离前缀、合格恢复与以往轮次数据联合保留。采样保持新旧任务均衡，同时报告最差任务/局部峰值；不能只修最新丢失项而丢弃以前数据。训练任务分组元数据可以用于采样，不能进入Actor输入或部署路由。这是DAgger启发的改写，不是当前已执行的标准DAgger。
3. **监督标签必须对应真实历史。** 在学生实际访问前缀上查询/接管教师，学生和教师均用各自网络从该前缀重算carry，保持原时钟、执行器与观测；不拼接教师原成功轨迹hidden，不把教师接管后的成功当学生成功。对作为“恢复示范”的后缀，要实际无接触GOAL才合格；单个接管点合格不能证明专家可标注所有学生访问状态，因此当前一条T574恢复还不满足DAgger通用专家假设。
4. **接受标准继续看完整自主闭环。** 每个候选同时满足旧成功ID全保留与新目标恢复才算本轮改善，失败则回退；离线MSE/KL、KKT证书只作诊断。另有未消费起态/扰动和保存重载测试，才能谈局部鲁棒或泛化。固定一次有界pilot、停止条件及预算后另立项；本说明不追加T575、T572R预算，也不把这套机制称作新算法。

## 保证的界线

DAgger解决自分布训练问题，CLEAR/函数蒸馏减轻遗忘，容量分离帮助判别压缩瓶颈；三者均不能独立保证“不再修新损旧”。若确定性系统、初态、预处理及carry均完全相同，并且候选在每条旧历史逐步输出**完全相同的实际执行动作**，可用逐步归纳保证这些有限旧轨迹重现；RMS很小或有限行近似约束不能替代该条件。要把非零误差推广成邻域/所有任务保证，还需动态稳定性、足够恢复裕度及覆盖等额外证据，目前没有。项目能落实的是严格的有限任务接受与回退、逐轮扩大真实覆盖，以及独立留出验证。

当前线性模型还有一个已满足前提的限制：每个输出`delta_location = Phi_old delta_w`，满列秩33使精确保留所有旧行只能取`delta_w=0`。因此把静态约束收得无限紧会封死此末层的学习。这不证明旧成功与新成功无法共存：成功允许某些动作变化，换可训练表示也会改变可行方向；更不证明64维GRU或神经导航不可行。新增容量同样不能保证闭环改善。
