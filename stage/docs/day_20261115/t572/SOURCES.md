# T572：固定特征线性修复与有限记忆函数约束的一手来源

2026-11-15。仅为新两臂机制提供文献与数学依据；本文件不报告训练、求解器安装或原生运行完成。Stage 独立，不涉及外部规划器。协议、预算、截止时间与真实结果以本轮其他注册文件为准。

## 一手来源与区别

1. **OGD，AISTATS 2020**：Farajtabar、Azizan、Mott、Li，[论文全文](https://proceedings.mlr.press/v108/farajtabar20a/farajtabar20a.pdf)，§3、式(7)–(9)。方法保护旧样本的网络输出梯度空间，旧梯度作为当前梯度的局部代理；论文明确讨论局部近似及大步长违反局部假设。对一般非线性网络，`J_old Δθ=0` 不能直接推出有限步输出完全不变。下文固定特征线性头没有这一泰勒余项，但只覆盖所列历史。

2. **GPM，ICLR 2021**：Saha、Garg、Roy，[论文全文](https://arxiv.org/pdf/2103.09762)，§4–5、§7、式(5)–(11)。用旧激活矩阵的 SVD 选择重要子空间并投影梯度；保留阈值控制干扰与可塑性的权衡。其线性层分析已经使用 `ΔW x=0` 时该层输出不变的关系。**会议信息应写 ICLR 2021，非 CVPR 2021。** 因此固定线性头加旧特征约束是标准方法的直接应用，不能据此声称算法原创。

3. **OSQP 官方求解器文档**：[问题、残差与 polishing](https://osqp.org/docs/solver/index.html)。支持 `min ½xᵀPx+qᵀx, l≤Ax≤u`，要求 `P` 半正定。停止取决于原始/对偶残差容差；polishing 尝试提高精度，并非每次成功。下文是此标准凸 QP 的特例。

   补充其[官方状态文档](https://osqp.org/docs/interfaces/status_values.html)：`solved inaccurate` 对应比所设容差宽十倍的条件。不能只凭返回字符串声称满足 `.002`；须用实际保存头和全部旧特征独立重算约束与目标。当前环境没有 scipy/osqp/cvxpy，本轮不安装；引用 OSQP 仅说明标准 QP 形式，**本轮自写 ADMM 不是 OSQP 包或 OSQP 复现**。

4. **标准 ADMM**：Boyd、Parikh、Chu、Peleato、Eckstein，[作者官方页面](https://web.stanford.edu/~boyd/papers/admm_distr_stats.html)、[正文](https://web.stanford.edu/~boyd/papers/pdf/admm_distr_stats.pdf)，§3.1–3.3、§4.2、§5.2。支持把凸二次目标与集合指示函数分裂：引入 `z=H_old W`，`z∈[−.002,.002]`；W 步解小型正定线性系统，z 步逐项 clip，随后更新对偶。渐近收敛论述不保证固定 5000 次内达到本项目验收精度，须独立核验原始可行性、对偶符号、stationarity 与 complementarity。

已核读上述论文相关正文和官方文档；未将摘要当全文，未运行作者实现，也不称完整 OGD/GPM/OSQP 复现。

## 本轮可成立的精确关系（本项目的代数推导）

令冻结父策略的 location 为 `ℓ₀(h)`，`h` 表示完整因果历史。冻结 backbone、归一化、固定 tanh 特征的所有参数，构造行向量 `φ(h)∈Rᵈ`（需要偏置时把常数 1 纳入特征），仅训练新残差线性头 `W∈R^(d×2)`：

`ℓ_W(h)=ℓ₀(h)+φ(h)W`。

于是对同一历史，任意有限更新都有 **`ℓ_(W+ΔW)(h)−ℓ_W(h)=φ(h)ΔW`**，是恒等式，无一阶近似。将全部被保护旧历史逐状态特征堆成 `H_old`，则逐坐标约束

`−.002 ≤ H_old (W−W_ref) ≤ .002`

精确限制这些历史上的 location 变化；以新残差零头为参照时 `W_ref=0`，零头始终可行。若实际训练的是原有非零头，则可行基准应为 `W=W_ref`，不能误写绝对头 `W=0`。固定特征中的 tanh 在 `W` 之前；若头之后另有 tanh，上式只精确描述该非线性之前的量，不能混称最终动作或车辆位置的精确线性关系。

对每个固定任务 `t`，用同一 `H_t` 和相对父 location 的修复目标 `R_t`，两臂共用任务均衡目标，例如：

`J(W)=Σ_t [α_t/n_t · ||H_t W−R_t||²_F] + λ||W||²_F`，`α_t≥0, λ>0`。

旧任务的保持目标为零；修复目标来自已核验的既有示范。任务权重、样本、特征和 ridge 事先固定。向量化后 Hessian 半正定，正 ridge 使其正定，故有唯一正则化最优解。A 用无约束 ridge 闭式解；B 只增加上述全部旧状态线性不等式，用固定参数、最多 5000 次的有界自写 ADMM，不扫 rho、参数或网格；证书与实际全旧特征漂移不通过则不执行 B 原生验收。这里 ridge 惩罚修正大小；不能把它误称为在任意其他拟合目标下都精确最小范数的解。

特征初始化可复用 T571 被拒候选已学到的第一隐藏层，但它仅作为冻结特征来源，两臂完全相同；新最后一层清零，使本轮初始部署函数严格回到 T562。复用被拒候选的冻结表示不等于晋升其策略，也不是声称 T571 已通过旧能力门。

## 可检验的机制与边界

- 软复习把旧误差放入目标，允许为修复目标交换旧误差；任务均衡平均误差没有逐旧状态最大变化界。B 把这一有限集合最大界直接写成约束，可和同目标 A 比较；无需将 T555 的 Adam 半空间或 T566 的非线性一阶投影重复包装。
- 全部旧特征约束避免子空间截断丢行；仍须冻结实际特征计算、逐历史/逐坐标检查、保存浮点实现的最大越界量与求解残差。精确代数不等于无限精度数值计算。若零头可行而求解器报原始不可行，应先查装配/数值问题，不把它当任务不可解证明。
- 容量有限。零容差时每个输出可用自由度至多 `d−rank(H_old)`；若旧特征满列秩，只能零修正。`.002` 放宽了可行域，但不保证目标可拟合、修复成功或新增能力。A/B 的差异也可能显示此稳定性与可塑性冲突。
- 约束仅覆盖已保存旧因果历史的 **策略 location 输出**。新策略闭环会改变后续状态、观测与 hidden，未知历史不在有限矩阵中。即使所有记忆点通过，也不推出旧任务闭环必成功、车辆位置误差界、安全、未知场景泛化或终身无遗忘。必须另报同一冻结候选的真实自主验收；不能用示范接管成功代替学生成功。

本轮适合检验“冻结表示下，直接控制全部旧记忆点的有限函数漂移，是否比同目标软复习更能保持旧成功并修复已知失败”。这是有界机制试验，不是通用证明或原创算法结论。
