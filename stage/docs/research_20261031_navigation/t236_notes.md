# T236：闭环误差审计，非新训练

2026-10-31检索并读取一手来源：[DAgger](https://proceedings.mlr.press/v15/ross11a.html)、[Kickstarting](https://arxiv.org/abs/1803.03835)、[Autoregressive Policies](https://arxiv.org/abs/1903.11524)。DAgger说明监督误差与策略诱导状态分布之间的关系；本项目只采用这一诊断动机，不调用外部专家、不宣称实施DAgger。Kickstarting说明已有策略可辅助RL，但不证明本项目合并后应稳定。AR文献将相关探索作为明确的历史条件策略，后续使用时必须验证行为密度，不能将T230占位logp当训练数据。

当前两个失败起点已有T221确定性安全成功。T236锁定两个T231失败起点，各独立生成两次并与原始T231十数组/最终积分哈希核验，保留完整失败轨迹。只离线在学生诱导状态和成功来源状态分别查询两网络，记录动作差、最早1cm/5cm位置偏离与接触时刻。时间对齐的差异不能证明充分必要因果，不是路径规划/策略路由或新导航成功。零优化器、最多93336物理步/4命令/180秒/1MiB，总newruns仍1GiB。
