# T250：实际舵机状态增强的单网络真实RL pilot

一手来源：[Ni等可观测性研究](https://proceedings.mlr.press/v162/ni22a.html)、[PPO](https://arxiv.org/abs/1707.06347)、[ARP](https://arxiv.org/abs/1903.11524)、[PCGrad](https://arxiv.org/abs/2001.06782)。本实验不声称上述算法完整复现或加入状态就必定有效。

T247自身成功策略在4/10/18/24s学生诱导状态全部不能恢复，故没有用其查询标签继续训练；T2485→10Hz筛查11/12，终止而不扫频率。转向可观测性：原观测已经有车体速度/上一次命令，但无真实舵角与舵角速度，不能以命令替代执行机构实测状态。T249零步工程维度错误保留，T251以真实首层800维恢复，并在零初始化融合下保持T239函数与全部211轨迹位一致后才可进入训练。

增加左右舵角/舵角速度四个当前encoder输入，归一后clip±3；没有世界坐标/地图/路点/任务id/教师控制。首层4→800额外3200权重初始化0，原113线性独立计算，单神经Actor仍直接输出原生油门/转向。所有原Actor与新融合权重都通过新鲜环境MC回报梯度更新；不做成功行为监督回归。当前仿真encoder输入需要实体车真实编码器，不能冒充已完成真机验证。

使用T245相同四临界reset、四轮16新回合、每条精确重生、PCGrad、条件AR密度和守卫；更换一个预给新seed，保留锚点为T239210安全轨迹的原113观测+T251实际4encoder量，不虚构零encoder上下文。没有同seed sensor-off对照，因此是单独工程研究pilot，不能将任何提升因果归于encoder或作统计优越性结论。已有T239210/211是保留候选，不挑中间点替换失败。

合成动作条件梯度/投影检查必须通过，encoder新分支梯度>0并逐步记录，live与shadow参数/Adam/随机投影顺序严格一致。初始4临界原十BASE数组/积分位一致；新117观测哈希单列。每轮旧八中心任一失败就停训练；最终预算Actor全部211有效开发通过才64尚未见导航留出。64位置只做过物理有效性预检，从未产生导航标签。

最多464命令/10.826976M所有物理步/1800秒末650秒验收/10MiBown/global1GiB/free40GiB，原100步动作保持/2ms物理/目标半径/总时限均不变。零自动追加轮数/seed/功能/超参搜索。用户看新117输入、原100步控制的新MuJoCo后才决定长距离；未通过门槛则没有稳定视频。
