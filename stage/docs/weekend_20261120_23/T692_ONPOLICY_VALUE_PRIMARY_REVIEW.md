## Primary sources and limits of their support

[Jiang–Li, ICML2016 published PDF](https://proceedings.mlr.press/v48/jiang16.pdf), §§3–4: action value conditions return on initial state/action and specifies the continuation policy. DR combines a value prediction with policy-ratio residual corrections; it does not turn arbitrary mixed-policy return regression into target-policy Q. The evaluation samples must be independent of the fitted policy/value predictor for their unbiased estimator claim. Their confidence calculation counts trajectories, not correlated decisions. Here no DR estimator is proposed; same-policy suffixes need no off-policy correction. Unbiased observed return labels do not eliminate function approximation error, feature aliasing or finite-sample uncertainty. Read these definitions, estimators, independence discussion and confidence discussion; not every proof or experiment. No author code audited.

[Le–Voloshin–Yue, ICML2019 published PDF](https://proceedings.mlr.press/v97/le19a/le19a.pdf), Algorithm3 and §4: FQE repeatedly regresses Bellman targets evaluated under a specified target policy; it is not full-return Monte Carlo regression. Their bounds expose distribution coverage/concentrability and function-class approximation error; the deterministic combination-lock counterexample illustrates severe support requirements. These assumptions have not been established here. A Gaussian's mathematical support is not adequate finite coverage at sigma.05. Read Algorithm3, Assumption1, Theorem4.2 and accompanying discussion; not full appendices. No author code audited.

[Fujimoto–van Hoof–Meger, ICML2018 published PDF](https://proceedings.mlr.press/v80/fujimoto18a/fujimoto18a.pdf), introduction/§2: function approximation error can mislead continuous actor-critic optimization, including local overestimation. This motivates withholding Actor guidance; it does not justify importing TD3, minimum double-Q or a safety guarantee into this pilot. Read introductory mechanism discussion, not a reproduction or author-code audit. Sutton–Barto's author-hosted book PDF fetch timed out during this bounded review; do not claim it was read. Published PMLR PDFs above were inspected directly; no exhaustive literature coverage, full historical-chat reading, source-code licensing review or copied external implementation is claimed.
