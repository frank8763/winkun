## What exact execution preservation proves

Let `C_theta(H)` be the command actually sent to native integration: the canonical batch1 Actor inference with its own reset/carry, followed by the original clipping and float32 conversion. Let `H_j,t` be every recorded complete causal history of original successful nominal start j, for all384 starts. If `C_theta(H_j,t)` is bitwise identical to the original command for every such decision, the deterministic physical transition and observation/history construction are identical at the next decision. Starting with identical complete native initial state, goal, history initialization, hold schedule and reset, induction therefore reproduces the entire original trajectory and terminal event.

This is a sufficient condition for those384 deterministic starts on the same canonical simulator/runtime. It proves neither stochastic retention nor disturbance robustness nor new-start generalization. Merely feeding the old states while copying another policy's hidden state does not establish the premise. Frozen recurrent weights do allow reconstructing identical own carry along an identical history. Batch `M.location` agreement within1e-10 with `sequence` is still not bitwise execution agreement: operation ordering can move a value across a float32 rounding boundary. Export/reload and the actual `step` path matter.

The induction is also already explicit in [T546's source review](../day_20261114/T546_FUNCTIONAL_COMPATIBILITY_SOURCES.md); it is not a new theorem from this review.

## The existing architecture and the one constructive invariant

[T671 make](../../experiments/t671_joint_outcome_feasibility/t671_learning.py) freezes the body and trains both adapters,11906 parameters in total. [T501 Actor](../../experiments/t501_joint_command_repair/t501_learning.py) combines the frozen GRU64 state with normalized120 observations to obtain184 features, and adds two separate `184→32→1` tanh residuals to the frozen logits. [T665 features](../../experiments/t665_remaining_verification/t665_learning.py) caches these frozen causal features; [T654 location](../../experiments/t654_verified_deviation_recovery/t654_learning.py) exposes the nested tanh formula. The adapters do not alter recurrent state construction. By contrast, [T687 runtime](../../experiments/t687_full_actor_gradient_contract/t687_runtime.py) differentiates complete `q.sequence` histories when all64772 existing parameters are trainable. Its successful semantics and rejected fixed first-Adam KL do not validate another full-scope learning step.

Consider freezing each adapter's final32→1 weights/bias as well. Augment each feature with1 and stack **every decision of all384 complete histories** into `X` with185 columns. For a first-layer augmented weight matrix `A` of shape32×185, restricting its represented change `D` to `X D^T=0` preserves every old hidden preactivation algebraically. Subsequent fixed nonlinear layers then preserve the old neural output. A fixed nullspace basis would make this a finite invariant, rather than a small-step approximation to the output Jacobian.

However, if `rank(X)=185`, this particular invariant forces `D=0`. Even when the nullspace is nonempty, a new feature `z` can respond only through its component outside the old row span. If every relevant new feature lies in that span, all such first-layer updates leave the new functions unchanged too. A nonempty nullspace alone is not useful plasticity. Small numerical singular values are not exact annihilators; changing their cutoff would change the mechanism's retention claim. An Adam implementation must constrain the **actual represented displacement after adaptive coordinate scaling**, not merely project the raw gradient. Otherwise coordinatewise preconditioning can leave the subspace. Any rejected step requires complete parameter and moment/step rollback.

The input-invariant construction is established continual-learning machinery. [Wang et al., CVPR2021, §§3–4.1, Lemma2/Condition1](https://arxiv.org/pdf/2103.07113) gives layer-input nullspace conditions for preservation and explicitly changes to an **approximate** nullspace because exact nullspaces can be absent. Its practical smallest-singular-value selection is not an exact command guarantee. [Zeng et al., OWM, revised preprint v3, Methods and capacity discussion](https://arxiv.org/html/1810.01256v3) uses input-space weight modification; spare projector capacity and the stability/plasticity tradeoff remain material. Its context-processing module is not proposed here.

By comparison, [Farajtabar et al., AISTATS2020, §3](https://proceedings.mlr.press/v108/farajtabar20a/farajtabar20a.pdf) protects old output-gradient directions locally and invokes a slowly changing Jacobian near the old solution. [Bennani, Doan and Sugiyama, v4, §§3.3,5.1,6](https://arxiv.org/html/2006.11942v4) derives no-forgetting under its overparameterized/linearized NTK model and memory assumptions; those conditions cannot be silently transferred to finite32-wide tanh adapters. These papers justify the distinction, not Stage feasibility.

## Float32 command cells do not resolve feasibility

For each old output, preserving its float32 command permits a rounding cell, enlarged by clipping at saturation. This is more permissive than preserving its real-valued neural output. For a finite collection strictly inside their cells, continuity gives some real-parameter neighborhood with identical commands. At midpoint/tie boundaries, that interior argument needs qualification. The represented parameter lattice and actual inference arithmetic impose additional constraints.

Therefore even a full-rank latent-output Jacobian would **not** prove that the quantized feasible set contains only the original parameters. Conversely, the existence of tiny command-invariant perturbations does not show that they can substantially change the needed new-task function. Turning these cells into hinge penalties, smaller proximal limits, a projected tangent step or repeated shrink-to-fit does not supply that missing constructive plasticity. No useful size, connected path or new-task improvement is established here. It would be unjustified both to declare impossibility and to launch training solely because quantization creates cells.

**Fixed-architecture disposition:** no pilot. Exact-input nullspace preservation is a substantive algebraic operator if a useful subspace exists, but the available evidence supplies no supported new-task component and contains a close negative precedent. Exact-command checking alone would be an unestablished tightening of previous response constraints. This rejection does not demand advance proof of navigation improvement; it requires a learning variable with a supported nontrivial action on the new data.
