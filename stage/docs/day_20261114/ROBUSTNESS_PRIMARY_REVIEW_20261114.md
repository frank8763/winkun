# Stage：鲁棒恢复、旧能力保持与论文新颖性的一手短审查

2026-11-14；仅文献与现有文字证据审阅。0仿真、0优化器、0模型改动；不是下一实验注册或启动授权。

## 判断

可行方向是：**物理有效的偏离恢复邻域 + 旧成功家族的函数保持 + 新策略真实在线采样的RL**，部署仍是一个120维因果输入GRU Actor，无地图、规划器、路点、教师或任务ID路由。这是值得检验的研究路线，尚不是已证创新。仅把这些已有组件组合并提升成功率，不足以承诺有说服力的期刊方法贡献。

本地依据：`T550_RESULTS.md`与`T550_REGRESSION_FINDINGS_AND_NEXT.md`。T550是紧支撑读出监督插值，新增RL/Adam为0；实际保护直接父的21条成功轨迹并新增2条，不能推导邻域恢复。T507至T550旧275净245→249含+10/-6，且中间有多次模型改变；不能把6项损失归因于下午单轮。有限轨迹相同与全状态函数相同是不同命题。

## 最近邻与贡献边界

| 一手来源 | 已有内容与本项目必须面对的边界 |
|---|---|
| [DAgger，Ross等，2011](https://proceedings.mlr.press/v15/ross11a.html) | 研究策略诱导的分布偏移及在线学习归约；“在学生访问状态上学纠正”不是新思想。 |
| [DART，Laskey等，2017](https://proceedings.mlr.press/v78/laskey17a.html) | 在教师动作加入与学生误差相适应的噪声，获得偏离与恢复数据。直接对旧轨迹加噪声、再学习恢复已有明确近邻。教师在新状态是否能恢复必须另验。 |
| [TaSIL，Pfrommer等，2022](https://arxiv.org/abs/2205.14812) | 不仅匹配轨迹动作，还匹配策略Taylor项；理论依赖专家的增量输入状态稳定性等条件。局部导数保持不是原创，也不能把该定理直接用于未经验证的Stage专家、部分观测历史或接触动力学。 |
| [Domain Randomization，Tobin等，2017](https://arxiv.org/abs/1703.06907)；[RARL，Pinto等，2017](https://proceedings.mlr.press/v70/pinto17a.html) | 前者原论文是渲染随机化的视觉定位迁移，不能冒称已证明Stage动力学导航；后者直接训练对抗外力扰动下的RL策略。随机化和最坏扰动训练本身均已有先例。 |
| [CLEAR，Rolnick等，2019](https://arxiv.org/abs/1811.11682)；[CIDER，Li等，2026预印本](https://arxiv.org/abs/2608.21899) | CLEAR用历史回放、行为克隆及新旧策略学习缓解遗忘；CIDER已明确提出冻结历史教师、交替蒸馏保持、梯度路由，并用单共享Actor学习真实机器人任务。“单Actor+RL+旧策略保持”不能单独作为新颖点。 |
| [CPO，Achiam等，2017](https://proceedings.mlr.press/v70/achiam17a.html) | 约束策略优化及基于平均策略散度的性能界已有理论。有限旧history上的KL/动作约束不自动变成闭环任务保持或零碰撞保证。 |
| [Distributionally Robust and Safe IL，Aboudonia与Hovakimyan，2026预印本](https://arxiv.org/abs/2607.13436) | 已将TaSIL与分布鲁棒自适应控制结合，分别处理策略诱导和不确定性诱导偏移。若主张同时处理两类偏移，必须进一步比较；其控制架构也不能直接视为满足本项目单Actor部署约束的基线实现。 |

## 一个可检验的机制假设

证据须分五层：**保持**是已学任务不丢失；**图内鲁棒性**是同布局下起终点与扰动变化；**跨布局泛化**是未消费的障碍布局/真实场地；**零样本sim2real**是在目标真机场地不训练直接部署；**适应**是在明确允许的目标场地数据和物理预算后改善。适应后的成绩不能称零样本泛化，同地图新起点也不能称换场地成功。最终其他物理场地的目标必须有独立场地和真实传感/执行链路证据，当前布局全通过只能作为第一道开发门。

研究对象应从“保持若干轨迹点”改为“扩大可恢复的因果历史邻域，同时保持旧成功家族”。从真实动作扰动/合法初态变化产生连续物理rollout；完整重建观测history、动作history与GRU隐状态，禁止独立扰动120个特征后把不可能的输入当真实状态。训练期教师只对实际完成安全恢复的状态序列提供监督；失败、不可恢复与未观测均保留，不能冒充正确标签。

候选机制可以让**实测偏离及其后续误差增长**同时决定恢复数据的选择和旧函数约束的位置，随后在这些物理邻域中采集当前Actor的真实on-policy轨迹，以奖励改善恢复；受控教师动作不是当前策略采样，不能直接混入PPO策略梯度并沿用伪造的on-policy密度。旧数据可作为独立监督/保持项。GRU隐状态的因果重建与新策略采样合同必须一致。

潜在贡献只能落在这里的**具体耦合规则**：为何比DART式噪声恢复、普通域随机化、TaSIL式局部匹配和CLEAR/CIDER式保持更有效地扩大恢复区域，并减少旧家族损失。此规则尚未形成算法、界或可复现优势；“恢复邻域+保持+RL”本身不是新机制。若只是换采样权重或加一个loss，应先按工程集成定位。

## 五个可证伪测试（仅建议，均未执行）

1. **邻域真实恢复**：以整条来源轨迹/初态家族划分训练与留出，预先固定扰动范围和强度分层。留出状态必须物理合法且因果history完整；统一统计安全GOAL、碰撞、超时和未执行。若仅零扰动/已见邻域提升，则否定“恢复区域扩大”。
2. **RL的必要性**：匹配Actor容量、数据、真实物理步及调参预算，对比当前插值、恢复监督、常规on-policy RL+旧回放保持、候选完整方法，并去掉候选RL项。若无RL同样有效，不能把贡献归于新的强化学习机制。
3. **保持的覆盖与因果性**：比较中心轨迹保持、均匀旧家族保持、候选机制；同一父模型逐ID配对，报告旧成功集合丢失、新增及碰撞。若总分改善靠牺牲旧成功，或保护history合格而留出旧家族仍退化，则否定所声称的闭环保持范围。
4. **最近邻机制消融**：与预算相同的DART式有效噪声恢复、随机化、适用的TaSIL式局部项、CLEAR/CIDER式保持原则对照；单独去掉“偏离增长指导”的采样/约束耦合。若普通方法同样好，就不支持该机制的新贡献。先核验教师和可微性合同，不能冒称完整复现不适用的方法。
5. **泛化层级与部署**：先用完全未消费的同地图起终点/扰动，再独立布局与传感/动力学变化；报告多训练种子及不确定性，真机验证支撑真实部署主张。记录部署每步只调用同一Actor及因果隐状态；若依赖教师切换或几何真值泄漏，则不满足目标。旧275/已反复选择的场地24属于开发证据，不能改名测试集。

## 实际阅读与限制

本次新打开并阅读上表全部一手论文的作者摘要/正式会议摘要页面及书目信息；未完整阅读PDF、证明、作者代码或补充材料，未复现任何方法。另读Stage仓库规则、兼容迁移/进展说明和上述T550文字报告；未读取全部历史聊天。首次合并读取发生输出截断，结论仅依据随后明确可见的段落，不声称完整读完这些长文件。2026两项为预印本，其摘要声称的优势未独立验证。本短审查识别了明显已有邻居，不能证明截至今日不存在同类机制；形成明确算法后仍须做面向该规则的全文与引用链新颖性审计。

有说服力的期刊故事需要一个明确且经最近邻排除的机制、匹配预算的强基线、闭环及留出证据、边界清楚的理论或机理解释，并视投稿定位提供多布局/真机结果。解决Stage工程鲁棒性会增加研究价值，但不自动获得算法原创性或期刊录用保证。
