# 修复一个任务时损伤另一个：持续学习与元学习的选择

2026-11-16；Stage only。本文是文献核读与下一研究决策说明，**不是新实验协议或启动授权**。只新增本文件；不改运行源、T579协议、模型、旧证据或runs，不启动仿真/训练。T579三冻结模型、六任务归因由既有driver负责；本文不接管或重复它。

**建议先完成初始化归因，再比较等预算的多任务联合保持与真实当前学生状态覆盖；普通MAML不作为第一修复。** 元学习中MER更贴近“更新怎样少伤旧知识”，但它只能作为覆盖诊断之后的单因素候选。现有证据不支持承诺零遗忘。

## 项目证据究竟说明什么

[T578逐ID复盘](t578/FINDINGS_AND_NEXT.md)核验T550与T577全部407个job、原生初态、场景及目标相同：保留T550为339成功，T577研究学生为232成功；前者成功集合中115项丢失、另新增8项。小集合旧8中心＋场地24仍保住原23个成功ID，证明这个32项门不能代表407项保持。T576初始化未测完整407，故115项差距包含初始化迁移和后续学习两阶段的可能贡献，不能全部称T577学习造成的遗忘。T579六任务能补局部归因，不能补成完整407初始化测量。

当前22条静态成功history与合格T574恢复、fresh PPO、冻结骨干/5986参数头不是“完全没有回放”。关键待检验的是**回放支撑哪些任务、哪些当前访问序列，以及代理误差是否对应真实闭环成功**。[T578来源复核](t578/PRIMARY_SOURCES.md)已说明昨夜6次新教师恢复均不合格，没有广泛新增合格纠错数据。冻结骨干固定递推函数，不固定动作变化后产生的下一观测和GRU访问状态。此前PCGrad、投影、函数漂移约束已有失败，不能再以“加个投影/EWC/回放/网络”当成尚未尝试的答案。

## 能具体怎样防止反复修补

以下为**待另注册、有界、可证伪的方案**，不修改T579或沿用昨夜额度。全部方法保留单120维因果观测、64维真实GRU carry Actor；无运行时教师、地图、规划器、路点或任务路由。任务分层仅用于训练采样和评估，不送入Actor。

1. **先确定共同起点。** 依据T579分开“初始化已丢失”与“本轮新增损伤”。若主要缺陷在T576，先研究T550→学生迁移覆盖；不能从已弱化初始化出发宣称守住T550全部能力。任何后续两臂都用同一明确hash的初始函数与相同可训练参数，保留T550作为冻结参照；六任务结论不外推到407。
2. **把修补改为固定任务混合训练。** 先锁定old275、six54、eight54、field24中已消费任务的分层开发集合，包含原成功与已失守ID，按任务/家族均衡而非按长轨迹决策数主导。旧任务既然仍可访问，就在同一轮交错采样，避免只优化最后失败任务。所有新鲜RL仍来自该臂真实行为策略，旧监督独立计账。
3. **只检验“当前访问覆盖”这一变量。** 对照臂保持等量静态旧history；实验臂用预定份额替换成当前学生访问序列上的合格恢复监督，跨轮累积并保留旧支撑。两臂匹配新RL物理预算、保持样本数/序列长度、优化器调用、模型、奖励和接受规则。教师资格采集也计入总预算；对照臂如不使用其标签，仍记录等额采集成本。更新后两臂各自访问会分化，应如实报告。
4. **回放的单位要保留因果序列。** 从本回合真实前缀重算各自carry，不能把教师hidden复制给学生，或把孤立观测配上来自另一轨迹的hidden。训练教师从同一物理前缀、原时钟/目标/执行器状态接管，达到原期限内无接触GOAL才成为合格恢复数据。资格失败不补挑点/seed直到成功；教师到达不计学生到达。[DAgger方法](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)提供访问分布思路，具体资格要求来自本项目合同。
5. **用自主闭环决定保留。** 每个候选先核对原23成功ID，再在预锁定扩展开发集合逐ID报告成功→失败、失败→成功、碰撞和超时。保留必须满足该集合预先声明的不退化规则并有新能力收益；未过则保留旧模型及失败证据。完整407按另注册预算作更大范围验收。有限门只能保证已测条件，不能保证所有未见状态。开发集反复消费后，另锁未见起态/布局、训练seed和原生重载测试，真机再另做验证；不能把407或小32称未知环境泛化。

这比“再加回放”的区别是：先控制迁移起点，匹配成本，再**实测当前访问覆盖与逐ID闭环保持**。若扩展覆盖后仍同样互损，或合格恢复标签缺失，就停止该覆盖假说，不以增加监督轮数替代反证。若相同因果历史确需互斥动作，须进一步检验可观测性/目标兼容性；有限头部或优化约束也可能限制可塑性，当前尚未证明唯一原因。

## MER何时值得试

仅在上述覆盖基线获得合格数据、仍显示学习造成的旧任务损伤后，另立**相同回放、相同SGD内步预算**的普通经验回放 vs MER式顺序更新/参数插值对照。先限定为监督保持/恢复子问题，PPO部分保持共同合同；明确这是受MER启发的连续控制适配，并非Algorithm 8复现。若同时把Adam换SGD、换网络、加数据和改奖励，就不能归因元学习。全部内步、shadow/audit与物理采样均预记，禁止用更多梯度或交互包装优势。

如果未来研究目标明确改为“允许新环境先探索数回合再适应”，MAML/元RL才成为独立路线：需定义训练/测试任务分布、支持/查询分离、部署可得奖励和适应成本，并同时比较第一回合冻结表现与适应后表现。它不自动解决当前单Actor旧能力保持，也不保证训练分布外环境或真实机器人成功。[MAML Algorithm 3](https://proceedings.mlr.press/v70/finn17a/finn17a.pdf)和[RL² trial定义](https://arxiv.org/pdf/1611.02779)决定了这些额外条件。
