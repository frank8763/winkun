# T578 下一机制：覆盖、保持与超时的一手来源复核

**建议先分类保存轨迹中的超时，再做有界、任务分层的真实学生分布覆盖对照；暂不以加大速度、延长时限、换记忆网络或整套CPO替代诊断。** 后续仍部署同一个120维因果观测、真实GRU carry的神经Actor；教师仅在训练数据资格验证中使用，无运行时地图、规划器、路点、教师或任务路由。以下是可证伪草案，不是效果承诺或新算法主张。

## 已知事实与不能推出的解释

[T577最终报告](../../overnight_20261115/FINAL_REPORT.json)中，5986参数可训练非线性残差、冻结骨干的保留模型，完整同一policy的407项为232成功、19碰撞、156超时：old275为211/6/58，six54为2/3/49，eight54为4/5/45，field24为15/5/4（各列成功/碰撞/超时）。小开发集仍old8=8/8、field24=15/24、原23成功ID全保留；不能把23/32当全场地保持。[T550同一最终Actor](../../day_20261114/T550_RESULTS.md)为339/407、53碰撞、15超时。两模型终端计数变化说明速度/进度值得查，**不能单凭碰撞减少、超时增加认定T577“更安全但太慢”**：绕圈、接近后驶离、失去恢复行为、跨起态分布偏移均可超时。需逐ID配对，两个总成功数之差不是精确损失ID数。

“冻结骨干”只固定观测到隐状态的递推函数；策略动作变化会改变下一观测，所以闭环中访问的GRU状态仍会变。静态22条成功历史约束只覆盖有限序列，不提供其他旧275/six/eight起态、其学生偏离邻域或整场地的保持证书。T577恢复23项也不能反证这些覆盖缺口。

## 四种“时间/记忆”不能混为一谈

1. **保持样本容量**：存多少旧任务、哪些邻域。CLEAR解决的主要是经验与行为保留；22条历史无论每条多长，仍是22条有限闭环支撑。
2. **Actor记忆**：[Cho等，2014，§2.3 Eq.5–8](https://arxiv.org/pdf/1406.1078)的GRU通过门控递推保留/丢弃旧信息，64维状态不是固定64步时间窗。持续carry不证明任务相关远期信息仍可读，也不能从超时推出记忆不足。当前骨干冻结，头部RL不能学习新的GRU编码。
3. **学习视野**：PPO采样段、BPTT截断、折扣与优势估计分别影响数据/梯度/信用分配；即使从完整历史重算carry，短梯度路径仍可能不同。应在源码合同中分别记真实秒、carry重置点、训练可追溯长度、终止mask；本文未断言Stage有相应bug。
4. **任务时限**：[Pardo等，ICML 2018，§2 Eq.4与§3 Eq.6](https://proceedings.mlr.press/v80/pardo18a/pardo18a.pdf)区分真实有限时限任务与无限任务的采样截断：前者到期真实终止，并需剩余时间或可推断时间；后者截断应续接bootstrap。Stage原生GOAL时限是验收合同，不能为消除超时改成非终止或延长。另有行政删失必须保留；当前120维是否已经含充分时间信息须核读，不能直接添加第121维或宣称缺时钟。

## 最小可证伪的下一步

**先做零物理、零更新的保存证据分类。** 在T550与T577共同任务上列交叉结果ID；对有完整轨迹的同ID，报告首个显著行为偏离、实际速度/命令、净目标进度、累计路程、最小/最终距离、近目标后驶离、转向饱和、carry重置/终止mask。只有汇总记录的任务标为“无法由现存证据分类”，不把缺失当慢速。阈值须在查看结果前统一写定并做敏感性说明；距离/隐状态近邻偏离只能是支持度指标，不是因果证明。

- **慢速假说**预测：主要损失发生在近似旧成功路径上，单位时间净进度下降，原期限末仍沿正确方向接近；若广泛出现早期转错、循环或接近后远离，该解释受反证。单看低平均速度不够，障碍处正确恢复也可能需要慢行。
- **分布覆盖假说**预测：小32外的T550成功ID更易丢失，偏离发生在已保持历史支撑之外；若新旧相似访问区同样失败，需检查函数约束、表示/动作冲突和目标，而非只补覆盖。时间先后与近邻距离不足以证明哪一个主因。

**若支持覆盖缺口，下一有界pilot只改变保持数据的访问分布。** 从同一T577模型、同5986头/冻结骨干、奖励、动作密度合同和优化预算出发，先固定分层任务小集合，覆盖old275/six/eight/field中的旧成功及当前失败，按任务均衡而非按长轨迹步数均衡。共同采集候选真实前缀；对照臂仍用等量旧静态保持样本，实验臂把固定份额替换为这些新访问状态上的合格旧行为/恢复标签，累计保存历轮，不只修最后丢失项。两臂新RL采样预算、保持样本数和优化器调用上限匹配；回放/教师标签只进入保持/监督项，RL项仅用各臂有合法行为密度的新采集数据。各臂更新后下一轮各自产生数据，这是机制差异，应报告而非称逐样本相同。

教师需从**同一真实学生前缀**因果重算自己的carry；接管必须在原时钟/执行器状态、不重置目标与期限的条件下实际无接触GOAL才成为恢复监督。资格失败原样保留，不补挑点/教师/seed直到成功；教师成功不计学生成功。若没有覆盖失守区的合格标签，这个pilot前提不成立，应停止而非将自我复制失败动作当专家纠错。

预先锁定一次预算与停止条件，不追加T577、不扫保持权重。先要求两臂原23成功ID逐项保留；同时在上述扩展已消费任务上比较新增成功、碰撞与超时，并完整记录损失ID。若覆盖替换没有改善旧损失ID或带来更多保持失败，则本次机制被反证，不能只报告均值MSE下降。完整407只能在新协议预算允许且资格通过后测，分别报告对T550成功集合与T577成功集合的保留/丢失；净总数增加也不能证明不遗忘。所有反复消费任务均为开发集，fresh16、独立起态/布局与重载验证另列，未执行为null。

若证据主要支持慢速/目标权衡，另立单因素奖励或期望成本对照，明确终点成功、碰撞与超时各项，再考虑CPO类方法；不在覆盖pilot同时修改惩罚、折扣、carry或时限。DAgger式覆盖、CLEAR式保持、PPO与有界接受的组合已有明确标准近邻，当前可检验的是项目机制与失败边界，不能据组合本身称原创、普遍不遗忘或部署安全。
