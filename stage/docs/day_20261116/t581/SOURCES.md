# T581来源与反证，检索2026-11-16

核读[Alakuijala et al., Residual Reinforcement Learning from Demonstrations, 2021](https://arxiv.org/html/2106.08050v1)全文HTML的I/II/III及实验配置，和[作者项目页](https://sites.google.com/view/rrlfd/)。采用冻结学习基策略＋神经残差的参数化原则；其UR5/Adroit操作、视觉+本体、DMPO与本线车体LiDAR120/GRU/PPO不同，不称复制其方法/真实导航收益。此次作者页/搜索未取得可核验的该论文官方完整实现，未移植外部代码；使用仓库已核查的CAPG密度和物理时间PPO。不是穷尽全网。

论文同时指出BC的覆盖缺口和误差累积；冻结基函数不保证残差执行后保旧。因此必须同初始化原生复现、逐ID保旧及真实自主验收，不能把基础权重未动当安全证书。T550本来已有神经残差，本轮新变量是直接保留强基策略原函数再真实RL，非第一次加入残差，更非声称原创。

[MER](https://arxiv.org/pdf/1810.11910)仅作已完成T580反证：同数据固定银行下未优于小步长ER，不能据此宣称所有元学习无效。本轮不追加MER或改gamma。

[PPO原论文](https://arxiv.org/abs/1707.06347)采用裁剪策略梯度而非保证约束；所用物理时间同行回报baseline是本项目既有实现，不声称原始PPO完整复现、整体无偏或普遍降方差。实际time-limit属于注册任务终止，行政预算截断不得当成功或正常失败训练。

三项可证伪假设顺序：1)弱学生初始化损失能力——零残差若不能精确T550，先拒绝工程接口；2)静态示范覆盖不足——只用新鲜自身闭环数据学习，看49自主新增；3)共享参数干扰——即使T550权重冻结也可能损成功，逐ID验收若有丢失就拒绝。一次小pilot不能区分所有因果或建立论文创新。
