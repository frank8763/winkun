## 2. 三臂共同合同和必须先查的判别

先给B做共同已保存历史上的三层差异表：basis/修正差、preclip location差、**实际执行命令逐位差**，按旧ID和决策数列出。既有几何报告的189个交叠中心不是189个改变命令的旧状态；抵消、clip及float32量化都可消除命令差。反过来，即使命令改变，也不能先宣判闭环失败。新中心处A/B仍具有相同分离和系数，应核验源命令相同；这只是构造实现检查。[既有几何事实及边界](../weekend_20261120_23/INCREMENTAL_VALUE_AUDIT_20261122.md)

## 3. 回放MLP怎样避免成为弱对照

以下为本次审查的协议建议，不是文献已经证明的最佳超参：

1. **锁loss而不只锁“BC”名称。** 旧样本以零残差保持父location，新样本以实际源命令减父location，与A使用同一目标。明确旧、新组权重及每ID/每决策平均顺序。按组平均和把81956旧点与1737新点直接混平均是不同目标；不能在看到最终native后交换。记录未裁剪残差拟合及执行命令误差，避免只报clip后MSE隐藏内部漂移。
2. **给有限但有用的拟合机会。** 预先锁定有限学习率/旧新权重选择集、初始化与步数/墙钟上限，记录训练曲线与每源误差；不要把历史64步的一次失败当强BC。零输出层可从父函数起步，但不要将全部MLP权重同时置零而阻断有效学习。开发成本、失败配置、checkpoint选择和native选择成本全部入账。历史A经历的多轮开发也不能藏成“0训练成本”；历史复用成本与本夜新增成本分列。
3. **开发选择不能使用待宣称的最终测试。** 若只能在旧407及已曝光邻域上选型，称为有限pilot/回归集结论；不要再把同一407当盲测。整条episode或来源家族留出，不能随机拆相邻决策，后者会把同轨迹相近状态泄漏到验证。对只有七个新源的pilot，留一源可诊断泛化，却也可能改变实际学习任务，须明确最终全量重拟合还是单纯诊断，不悄悄增加配置次数。
4. **容量匹配不等于优化难度匹配。** `184→H→2`含bias共有`187H+2`个参数；A的N中心含中心坐标、半径、两系数，共`187N`个float64。取`H=N−1`时相差1480B，N=1737即H=1736，与已有方案一致。这只匹配持久头部张量bytes，不匹配函数类、有效自由度、FLOPs、Adam/RAM或训练难度。[已有成本口径](../weekend_20261120_23/INCREMENTAL_VALUE_AUDIT_20261122.md)

## 4. 容量曲线必须写明在改变哪件事

**仅删除中心并保留原半径/系数，回答的是已构造模型的删除敏感性；不是每个预算下最佳可达到的压缩或重新拟合能力。** 原半径被全1737点的最近邻限制，删除邻点后仍保持很小。被删除时刻常无法再由原命令带精确承接，源reset失败不证明任何较小模型都做不到。

一种干净的有界方案是：先锁一个与结果无关、覆盖七源的确定性嵌套顺序及最多几个N，A/B使用同一子集。按每源的预定时间分层排序可以避免只截取文件前缀；hash顺序也须公布规则与SHA。不能根据已知失败时刻、误差峰值或native成功贪心挑中心，然后把曲线称为没有选择偏差。固定选择算法给出的只是该算法的一条曲线，不是中心数下界。

在协议中二选一，不能事后混用更好的点：

- **删除曲线：** 所选中心复制各臂全模型保存的半径和系数；明确删除敏感性。A各层旧点零响应继续成立，但源精确复现不再有完整保证。
- **重构曲线：** 对每个子集重新计算最近“保留中心”距离；A仍使用完整403条旧保护点，B只用保留中心，`.49`不变；残差系数仍为被保留点的相同目标减父location。重新验证源子矩阵、保护点和实际命令。半径变大可能覆盖被删除点，但不保证其标签正确，也不保证闭环成功。该曲线评估固定子集重构规则，仍不是最优压缩。

如果资源只够其中一种，推荐使用重构曲线并诚实命名；不要为追求容量结论追加另一条无限候选链。每个N的C若声称“同预算三臂容量曲线”，应按相同bytes缩放H，仍可访问完整同一训练监督；A/B也接触完整监督但选择只部署子集。不给C同数据或只在full-N训练C，就只能报告RBF曲线加一个MLP参考点。各预算是否分别拟合、是否warm start及各自预算必须锁定。

共同T694父链含历史中心，所有曲线同时列**新增层bytes**和**总部署bytes**；N=0就是共同父模型。A/B需在部署保留的center/radius/coeff都计入；保护集若仅供构建则计入训练/持续学习存储，不强加进部署。C可在部署丢弃replay，但若要继续增量训练就仍需报告回放保存成本。报告batch1 warm延迟的中位与尾部、加载时间、峰值RAM、训练/审计墙钟，同硬件同线程边界。当前稠密距离实现的紧支撑不会自动跳过所有远中心。[T694/T696实际forward](../../experiments/t696_existing_success_compatibility/t696_actor.py)

## 5. 闭环、独立起点及统计判读

本夜最小主表按同一固定reset成对列：403历史逐ID保留、新七源复现、核心407、既有邻域24；明确集合重叠，不将它们直接相加成一个假分母。A/B/C即使未过精确命令门，也完成预注册的科学评估并报告碰撞、超时、越界和未执行；不要用A的构造门提前筛掉B/C，再把缺测记为失败。工程损坏或硬预算中断另列，原失败原样保留。[历史评价曝光范围](../weekend_20261120_23/PAPER_PATH_RETROSPECTIVE_20261122.md)

有限确定性保证是：完整初态、runtime、carry初始化、时钟及每一步执行命令一致时，归纳重现被保护的轨迹。轨迹级native复核验证这些前提的工程实现；源命令带成功本身不能证明新起点纠偏。DAgger也说明了为何教师分布上的拟合不等于学习者自己访问分布上的表现，但当前比较无需引入额外教师或新在线采样方法。[DAgger §3与Algorithm3.1](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)

若要支持保证外的实用收益，另设真正未用于选择中心、半径、训练配置及论文方向的起点清单，事先封存任务工厂/初态SHA和无效reset规则，在所有最终模型冻结后同表一次评估。既有±1cm24点只能叫已曝光邻域回归；新位置扰动首先是固定场景的未见reset，不自动等于新地图OOD。新地图/障碍分布与更远距离要各自标识，不能混为同一泛化数字。没有这部分时，本夜仍可完成有意义的有限回归对照，只需删去独立泛化主张。

主统计优先报告成对改善数、退步数、共同成功/失败数、各家族结果和绝对成功比例差。固定407全量描述不需要伪造置信区间；对独立随机抽样起点的总体推断，按实际抽样家族进行配对重采样，而非重采样单步或精确重放。多独立来源/顺序和C初始化的方差是后续不同问题。本夜若只有一次C初始化，就称单配置pilot。精确重放增加审计可信度，不增加独立N。rliable默认的run重采样在单个确定性run时不会创造训练不确定性，其现成独立样本改进概率也不应替代本次配对二元比较。[rliable作者代码的输入轴与采样语义](https://raw.githubusercontent.com/google-research/rliable/master/rliable/library.py)、[独立样本指标实现](https://raw.githubusercontent.com/google-research/rliable/master/rliable/metrics.py)

## 6. 哪些结果能改变论文论点

| 实际观察 | 可写结论 | 仍不能写 |
|---|---|---|
| A/B执行命令与闭环均相同 | 本次保护规则对测得执行与任务结果没有额外收益；若仅basis不同也应如实说明 | “所有保护方法无用”，或仍宣称规则优势 |
| A比B少旧损失，源复现相同 | 在该共同父/数据上，old距离项改善有限非干扰；结合具体命令差说明机制 | 相对全部普通RBF更优、全状态安全、全新学习算法 |
| A/C相同任务收益，C更省延迟/训练/持续存储 | 该配置下RBF扩容的相应资源优势未成立；展示各成本轴 | BC家族普遍胜出；未看其他成本就断言唯一赢家 |
| A保留更强，但C在独立新起点更好 | 具体保留—适应—成本折中，按约束报告Pareto结果 | 以一个总分隐去退步，或以精确旧命令代替部署价值判断 |
| 较小N已达到full-N相同范围结果 | 固定选择规则下可以降低此层成本；给出实测范围 | 最小必要中心数或最优压缩已找到 |
| 只有完整源命令带成功，独立起点无收益或未测 | 构造性有限兼容性和记忆成本实证 | 泛化优越、导航算法新颖性或“容量值得”已证明 |

“值得”需要部署约束：例如允许的总模型bytes、尾部决策延迟及可以接受的旧任务退步。没有约束时只报告Pareto关系，不临时发明阈值。比较A与未扩展父模型回答新增记忆买到什么；比较A与同bytes C才回答这种参数化是否划算，不能混用两个分母。
