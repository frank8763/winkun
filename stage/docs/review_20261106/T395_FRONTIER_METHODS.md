**开始任何更新前，先执行并保存父 Actor 的 56 s 同前缀无噪声 mode 基线。** T394 的带噪声成功、精确重复或离线均值不能代填。初始 mode 若已安全，是既有条件能力；若未安全，后续同条件 mode 改善才有前后比较。此基线及其所需核验计入正式命令／物理／墙钟预算。其余未测初始 frontier 记 null，不为补齐比较另开全级网格。

每轮只有同时满足 **实际保留更新＋本批至少 2/4 安全探索＋更新后同级同前缀 mode 安全到达**，才前移一秒；数值拒绝不算保留。未满足则留级并消耗原六轮额度，52 s 之后不自动加 51 s／新 seed／噪声／轮数。2/4 是调度启发式，不是成功概率或安全认证；新数据最多 24 条，精确重复不增加独立样本。初始及更新后 mode、随机探索和所有缺测分别报告。

## 2. 固定真实历史、奖励和部署语义

每条从原 episode zero 真实执行既有成功参考前缀；原 native clock、执行器、传感 history、真实 previous-action 全保留。当前 Actor 参数从 episode zero 重算循环 hidden；前缀中 previous-action 是实际参考动作，不能输入未执行的 Actor mode，不能接旧模型／教师 hidden 或在接管处清零。更新时依完整因果序列重算当前参数 hidden；前缀不伪造 on-policy score，随机后缀才进入 PG／PPO，示范辅助独立标识。[既有循环／mask 方法](T393_INITIALIZATION_METHODS.md#2-示范辅助用于支撑真实-on-policy-学习)、[T394 接管合同](T394_TAKEOVER_METHODS.md#2-真实执行前缀保留当前模型对完整历史的编码)

原 80 s 时限不重新计时，56／55／54／53／52 s 分别余 24／25／26／27／28 s；goal、0.2 m 成功半径、碰撞、奖励／折扣／终止势函数及执行域 iid 分布沿父协议不变。**保留所有既有奖励原值和失败证据，不回写旧奖励、不新加终距罚项。** T197／T280 已有距离代价负结果，不以“回报需要变化”为由换名重复。[T393 信号核查与历史反证](T393_FINDINGS.md#学习信号卡点再次复现已知目标性质)

必须分开报告两类实测：①成功参考**强制前缀**后的当前 Actor 自主后缀；②从原起点、全程使用自身动作与自身到达状态的 mode rollout。前者即使 52 s 安全，也只通过该条件恢复段；不能把参考前缀拼接成原起点单 Actor 六米成功。学习后原起点左右中心、旧能力与独立模型读回按正式验收门执行，未执行的 54／275／16／78 均记 null。部署是单因果 Actor，无运行时教师切换、规划器、路点或路由。

## 3. 全成功也可能有信号，但须看真正梯度

当前奖励中，同起态、同事件、同终止 clock 的完整回报可相同；T393 和 T394 的 52 s 全超时已复现这一性质。反之，T394 的 **56 s 四条全 GOAL** 仍有回报 spread `0.00979809`、最大 LOO `0.00665800`，对应到达 clock 59.216–59.804 s；不必先出现成功／失败混合才可能有时序排序。若四条全 GOAL 且回报也相同，同样会退化。跨 frontier 的起态／剩余时间不同，不能混算一个批次优势或把跨级回报提高当能力收益。[T394 原结果](T394_FINDINGS.md)

DAPG 将新策略 PG 与示范辅助梯度相加，使用 NPG 和衰减示范 score 权重；它支持继续利用示范，未保证固定 `.1*MSE` 对本任务有效，也明确 BC 会受示范状态与自身状态的分布差异影响。本项目保留父协议的示范项，不称 DAPG 精确复现。[DAPG v2 §IV-C，Eq(5)–(6)](https://arxiv.org/pdf/1709.10087)

PPO 的 clipped surrogate 由 likelihood ratio 与优势共同构成；clip 不会替相同回报生成任务排序。对既定后缀更新记录 ratio／clip 与 KL 检查，不能只以有 Adam 步数证明有效 PG。[PPO v2 §2.1／§3，Eq(1)／(7)](https://arxiv.org/pdf/1707.06347)

正式实现应在原有梯度／更新预算内保存下列诊断，本文不执行额外反向或拟合：

| 层次 | 每轮必须区分的证据 |
|---|---|
| 任务信号 | 四条的 safe／contact／真 timeout／invalid／censored、到达原 clock、完整 G、spread、LOO 绝对量级；浮点级优势不称可用 PG。 |
| 梯度 | 同一参数点的 `g_pg`、加权后的 `g_demo` 与总梯度范数，PG／demo 夹角及循环 body／输出头分项；零范数时夹角 null，记录数值精度／归约方法。MSE 或 PG loss 大小不能替代梯度。 |
| 实际更新 | 提案／拒绝原因、参数位移、Actor＋Adam 回退／shadow 核验、实际保留数、更新后同前缀 mode。梯度范数与夹角只是描述，Adam 的非线性与历史矩不允许据此精确分配因果贡献；未做隔离反事实就不声称 PG-only 收益。 |
| 学习范围 | 初始 56 s mode 与后续同条件结果、到达过的最早预注册 frontier、最终自身状态原起点结果分别列出；较早级无初始化对照时只说“本轮测得”，不宣称新增能力归因。 |

据此至少区分：已有探索覆盖但 mode 仍失败；数值／信赖拒绝导致零保留；同条件全超时无回报排序；有 PG／示范梯度和保留但恢复仍未前移。失败只否定本次固定组合在有限预算内的目标，不否定所有逆课程／PG／循环策略或场景可达性。
