当前最有证据支持的解释是：**五米已掌握分布之外的目标条件控制没有泛化；左侧缺少完整绕障成功覆盖，右侧速度/转向协调不足；现有训练还存在信号辨别弱与更新受拒绝、或接受后伤害旧任务的问题。** 场景使这些缺口显现，但尚无证据证明左六米几何不可达，也不能说“纯DRL理论上不行”。灾难性遗忘是真实的部分现象，不是最初六米失败的充分原因。

历史完整开发最好仍是T299：six10/54=18.52%，LEFT0/27、RIGHT10/27，old274/275，不能晋升。safeT255历史old275/275、six0/54；“五米100%”只对应这套固定场景/任务及小扰动验收，不代表任意目标或全地图100%。新鲜16留出、78独立模型重载未因本审计执行。

## 3. 训练信号及“真的学了多少”存在两个瓶颈

原奖励逐步/闭式复核全部通过，无本批计时/奖励符号错误。固定初态、固定cap、同超时事件时，势函数终点项抵消，完整回报不区分最终距离。本次safe RIGHT6m（余0.600252m）与两条人工LEFT6m（余0.752339/0.775122m）初距同6m、同56秒超时，完整回报均约-0.0530330780661132。左右场景/轨迹不同，这个等式只说明目标的回报性质，不能比较其动作可迁移性。

原始轨迹仍有reward-to-go/状态差异，不等于任何RL梯度严格为零；但反复同结局、少正例时，完整回报对改进方向辨别不足。T197/T280的距离罚项已有负结果，不能换名重复或把简单奖励加项称原创。

## 4. 当前示范拟合目标不能替代闭环能力

T322验证平均steer MSE0.365541→0.162082，下降55.66%；但验证7个变化点0.083828→0.099520，上升18.72%。273/280验证行保持前一steer，复制前动作的平均MSE仅0.026892而变化点MSE1.075671。低平均误差可以掩盖转向时机错误；复制器本身没有执行导航，不能叫它更好策略。

两条40秒边界，人工steer为+0.711/+0.731，safe输出-0.11555/-0.07611；T322为+0.63968/+0.43278，确实在这些记录状态更接近人工动作。可是T322真实old20仅8成功、six54仍0成功。**在记录状态像人，不等于在自己引起的新状态下会安全导航。** 单条训练/同起态第二条验证也不足以代表未见地图。

这与DAgger讨论的策略诱导状态分布偏移相符，但本项目尚未单因素证明它是唯一原因。下一步纠正标签应来自策略实际访问、将要失控的真实状态，而不是继续只堆两条固定失败轨迹的监督步数。
