# 长距离端到端导航：方法审阅稿

日期：2026-11-03。状态：**仅供用户审阅，未注册实验、未启动训练/仿真、未创建自动化**。不因本稿自动续任何已结束目录或扩大旧预算。Stage与Phase全部隔离；正式执行仍须独立协议、实际容量、零步合同、源输入SHA、本地提交和GitHub精确源同步。

## 结论与建议

长距离无地图端到端导航在已有研究中可行，但当前Stage还没有获得可扩距的策略，不能用其他机器人论文的成绩作为本项目保证。下一步优先验证**短动作序列对比价值 → 单动作价值蒸馏 → 单Actor闭环学习**，同时补足实际目标条件的数据覆盖。第一项只选择一个固定短序列，不同时添加新记忆、TD、奖励或新规划器。

这项选择直接针对T308的“动作输入没有带来可靠的额外未来信息”：动作头与盲头NCE近乎相同，真实动作排序LEFT61.11%、RIGHT47.22%。并非因为论文用了序列就假定三步一定能解决六米；若新的单动作价值仍不能通过真实控制检查，停止该机制。

## 项目证据与原因边界

- 安全T255：旧275/275，原六米0/54。失败在新训练之前已存在，遗忘不能解释全部。
- 最好研究T299：六米10/54=18.52%，LEFT0/27，RIGHT10/27；旧274/275，有一项左五米接触，不能晋升。右侧成功都在54.034–55.792秒，接近原56秒时限。
- T269同Actor、同完整初态的五/六米右中心，前10秒驱动明显不同。目标/时限条件从第一步就改变反馈行为，六米不是“原五米路线后多走一米”。该对照没有单独隔离目标距离与剩余时间。
- T278同一六米终点的近1米起态亦失败，不能把问题只归为长程探索；末段目标控制也需要学习。
- T255确实训练过carry-memory/reset四臂。s2_reset开发211/211，s2_memory210/211；没有证明加GRU或保持hidden本身有益，更没有证明记忆是六米唯一根因。
- T304三步原回报小回归头、T308单动作对比值头均失败。二者不是完整动作序列CRL+DQC的复现，负结果也不能被跳过：新的方法仍须证明控制效果。

因此，最强工作判断是**目标条件泛化/任务覆盖、动作价值可用性与闭环旧技能保持共同存在缺口**。场景交互确实困难，但没有场景不可达的证明，也不能宣布SAC或整个深度RL无效。

## 拟定方法

### 1. 学会更多真实目标，而非只拟合两条长路线

保留旧3–5米任务；另预注册一小组不同距离/方位的实际目标，先覆盖局部可控区间与5–6米边界。具体合法任务由零物理几何/完整reset合同锁定，不在看到结果后挑容易目标。实际新目标从回合开始至结束保持不变，所有当前/历史目标字段须有真实历史位姿支持；这属于独立训练任务，**不是把一条六米路线拆成运行时路点**。

不能把T308只有8条拟合轨迹当充分的数据覆盖；也不能只反复复制旧成功或使用当前32条失败轨迹训练新的大头。先复用可核验的既有自身经验，再以固定数量补充当前策略的实际目标数据；保留真实失败。回报、接触、半径与各距离时限先保持，避免把改目标分布、网络与奖励一起改后强作单因素结论。

### 2. 训练固定短序列价值，与单动作/盲对照匹配

候选从固定H=3开始，即三次原生决策、名义0.6秒。这个选择是有限试验点，不是最优长度声明，不做H网格。

`f3(x_t, a_t, a_(t+1), a_(t+2), query_goal)`学习真实动作序列与未来位置关系；同批数据上有单动作对照和动作盲对照，匹配输入维度/参数、batch与更新预算。有效比较不能只增加输入及训练量后与更弱旧头比较。

未来目标按明确的物理折扣占用法则采样，终止前不足三步/短hold单列，不跨回合拼接；CONTACT优先token、真实GOAL、真cap与行政中断分开。后续动作依赖真实后续观测，观测到的序列条件价值**不自动等于指定该序列的开环因果Q**。

### 3. 用DQC提取单动作价值，再学单Actor

按照论文的expectile蒸馏思路，把序列编码器的值蒸馏到`f1(x_t, a_t, query_goal)`。序列/goal编码器在蒸馏目标中stop-gradient；只训练单动作编码器，不把简单平均后续动作或平均logit称为推导正确的单动作Q。expectile和采样分布在正式协议里一次锁定。

推理仍为`120维因果输入 + 最终目标 → 一个Actor → 驱动/转向`，每0.2秒真实反馈。价值头/蒸馏头仅训练期使用，不在运行时搜索动作或查询地图；没有教师、子目标、模型路由或外部规划器。初期保持hidden-reset，以免同时改记忆和价值机制。

蒸馏是近似价值转移，特别是expectile目标偏向较好续行，不应冒称精确当前策略MC价值、安全概率或无偏估计。现有goal-dependent行为120上下文到新query策略的迁移也是未解决假设，须通过原生验证，不能靠公式名称掩盖。

### 4. 必须完成真正的策略交互学习

只有表示/单动作控制检查过后，才进入有界Actor更新与新鲜原生交互。离线对比头或蒸馏头训练不是“六米导航RL已训练”。Actor须看到训练中的新状态、失败与成功，不能只在同一小批数据上做一次提案就期待自动学会长路线。固定总回合/更新数、旧任务比例、原生接受/回退和提前停止规则，禁止失败后自动扩预算。

五米安全模型单独保存为基线，不覆盖。训练时混合旧/新任务与保持项，最后仍需真实旧275验收；正则小或动作误差小不是安全保证。

## 可行性试验和停止标准

1. **数据/语义先过。** full120、历史目标、实际hold、序列切片、终止/censor、原始密度、模型/Adam保存重载均按新协议核验。无需新模拟即可做的合同先做。
2. **值头须提供额外动作信息。** 同数据同资源的单动作/动作盲对照、整家族验证，不能只看训练loss下降。新的验证家族须采集前锁定；T308 reset01已经消费，不能再当未见数据。
3. **真实控制须过。** 验证query/任务目标在采集前锁定，不从待测中心轨迹事后挑容易位置。相同完整初态下用多个配对噪声续行复核候选首动作的效果，按起态/噪声家族聚合不确定性，不把相关pair当独立重复。用原生实际GOAL/CONTACT/超时/目标量作证；同事件下只推迟碰撞不能算安全收益。无足够可区分控制样本则判“不足以验证”，而非降低阈值。
4. **研究进展与稳定分开。** 早期必须出现多个预注册左侧原六米开发起态的可重复确定性新增成功，同时旧能力保持；一个随机探索成功不算学会。若有改善但未满门槛，仍留在六米，不能进入七/八米。数值、场景数和统计阈值正式注册前锁定，本稿不伪称已有PASS。
5. **扩距门槛不变。** 同候选old275+原六米54全部安全GOAL→16fresh→78独立原生重载精确→独立审计/全原始备份，才独立七米协议，再八米。十米与全图另设未见起终点/布局及基于物理可行时间的新协议；两条固定路线通过不代表全图。早期T255八米冻结诊断失败不等于进入过逐级八米训练。

## 资源与执行边界

建议正式pilot按一次有限预算设计，例如最多64条新增训练轨迹，全部采集/控制/重生/旧回归/完整验收合计不超过1200命令、33.6M物理步、4小时；这是待核算的草案上限，**不是已批准上线的锁定protocol**。正式实现若最坏成本超过它，注册前重拟方案，不启动后改预算。首轮只验证机制，不能由单seed pilot推出顶刊统计结论；多seed/跨布局消融须另行设计，不自动开网格。

64回合按每回合最多280决策仅约17,920个新训练决策上界，原生2ms物理步不能冒充独立策略样本；评估/重生也不能增加此训练量。因此这是筛选可行性的预算，不是已足够收敛的承诺。若出现可重复真实收益，再另设计足量学习曲线和统计复验；没有收益则不靠无限续训解释失败。

完整模型/Adam、头、训练证据与完整验收预计需约40MiB own上限；须实际序列化计算才可确定。当前runs逻辑1,049,336,058B，距1GiB只余24,405,766B≈23.28MiB，**现状不能直接预留40MiB**。须先真正无损冷编码/完整远端核验，额外释放约16.72MiB以上并保留余量，或在注册前缩减完整试验；不得删除唯一证据/模型/视频、移动目录或放宽global1GiB/free40GiB。GitHub今晨401，正式源码/原始备份上传前须恢复认证；本审阅稿不触发登录流程。

## 论文创新应落在哪里

短动作序列、DQC、TD InfoNCE、GRU/SRU及课程已有近邻。把这些拼在一起不构成充分的顶刊创新。值得研究的问题是：**如何在目标依赖历史、有限时限与接触终止下，把较长期动作的价值信息转为能改善安全到达的单动作策略，同时保持旧目标能力。**

要成为算法贡献，需要提出区别现有工作的价值目标/转移或更新机制，解释何时有效和何时失效，并证明相对匹配基线的增益，而非仅补齐工程合同。最终证据至少含控制检验、消融、多训练seed、跨目标/布局/距离、碰撞与超时分解以及保存重载；真机和更长距离如未做须明确。当前没有此新算法有效性或顶刊完成保证。
