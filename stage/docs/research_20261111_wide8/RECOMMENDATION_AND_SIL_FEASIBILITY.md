# 八米改进：论文筛选、现有证据与下一步

2026-11-11。此文是研究与下一轮草案，不是新实验注册或启动记录。T478运行中的科学代码、协议、种子、预算均不改；Stage与Phase完全隔离。部署继续为单个120输入、真实GRU记忆Actor直接输出动作，无运行时地图、规划器、路点、教师或左右策略路由。

## 结论

优先顺序是：**补齐并均衡保持完整成功经验 → 在匹配对照中检验成功经验自模仿SIL → 只有当前PPO梯度证据支持时再检验CAGrad。** DreamerV3为较长期备选，当前不直接替换训练体系。论文中可用方法不等于已经在本项目有效，更不等于方法组合本身原创。

当前真正保留模型为T477 longcredit：八米8/54（左5右3），六米53/54，旧274/275。T478首候选的八米组19/54（左1右18），六米34/54；完整旧回归在检索时尚未结束，不能当最终选中模型。当前所有335成功必须保留且增加八米成功才接受。

查阅实际reference_provenance发现：T478八米保持来源只有两条右侧成功历史，另有六米左右中心，没有左八米成功保持历史。它是可观察的覆盖缺口，不足以单独证明退化根因。T455已做过冻结encoder/core仅训练130参数head，最终六米47/54、旧198/275；不能将其重新包装成未经尝试的解决方案。T447旧BC梯度对LEFT5局部有利，也不能从当前左右损伤直接推定梯度负内积。

## 为什么SIL值得单独检验

现有学习包含两件事：用新鲜轨迹做PPO；让模型在少量旧历史上接近初始输出。第二件事不会自动把一次成功探索中有用的随机转向学成稳定动作。

SIL原文的核心是：

`A_plus = max(G_t - V(history_t), 0)`

`L_actor_sil = -stop_gradient(A_plus) * log pi(executed_action | full_history)`

`L_value_sil = 0.5 * A_plus^2`

它明确是离策略辅助目标，不是假装历史数据是当前PPO样本。对于本项目，回报必须按真实native步数折扣并保留真实终止语义；策略概率使用已有裁剪高斯的内部密度/边界原子，不能把裁剪后动作当普通高斯密度。完整真实历史从h0重算当前GRU，不能直接使用旧策略隐藏状态。Actor权重停止梯度，Value损失单独更新已有Value网络。

初步适配只考虑完整、无接触GOAL的自身**随机探索**轨迹。相较原SIL，这是额外的成功过滤和左右分层采样，需明确称适配而非完整复现。确定性成功轨迹用于保持已有策略分布；它们不能伪装成带探索密度的PPO数据。成功噪声动作也可能在新闭环中失效，必须做原生验收。

## 下一轮有限对照草案（未注册，未启动）

1. 等T478结束、审计和原始备份后，从实际保留模型出发。先固定收集其已验证8个八米成功ID（当前左5右3）的完整原生历史并精确重生，不搜索新种子；用于补齐保持数据，物理重复全部计账。
2. A为原PPO加完整左右等权成功保持；B使用完全相同数据、初值、优化器状态、更新次数，额外加入成功自模仿项。新鲜on-policy PPO批与旧离策略SIL批分开标记；左右总权重相等，不能因右成功更多而压过左侧。系数与上限在新协议锁定，不扫权重网格、不根据结果追加轮数。
3. 保存左右PPO梯度、保持梯度、SIL梯度与实际Adam更新的有限方向诊断；此阶段不把诊断变成中途改算法的开关。只有覆盖匹配后仍有可重复破坏性方向，另做CAGrad对照。
4. 所有候选维持当前335成功ID并新增八米成功才接受；完整383检查，模型/Value/两个Adam整轮回退。新独立留出和保存重载需另做预算，开发集通过不等于全图/实体机通过。

两臂同时改变均衡覆盖与加入SIL会混淆归因，因此A也必须有完全相同覆盖。若资源仅够一臂，先做覆盖修正，SIL保持草案，不能将两者合并后的成绩单独归因SIL。

## 论文创新边界

PPO、CLEAR、SIL、CAGrad、Dreamer均为已有方法。可研究的问题是：非完整约束车辆在绕障切入和末端转向的少数关键状态上，如何同时保持旧成功和扩展新成功；任何关键状态选择/更新约束都须与均匀回放、纯SIL、已有梯度方法做匹配消融，验证跨地图、扰动、未见目标与实体机。当前仅有候选研究问题，没有创新成立或顶刊保证。
