## Two traps remain after coverage improves

For a fixed observed sequence x, define fθ(x) by recomputing the current GRU from its actual initial state throughout the sequence. If `Lret = mean ||fθ(x) − fθ0(x)||²`, then at θ0 its gradient is zero. KL between identical reference/current distributions also has zero first derivative. Thus treating retention as another CAGrad task supplies no initial opposing gradient. The nonzero local object is curvature: approximately `Lret(θ0+Δ) = mean ||Jx Δ||²`. Linearizing the scalar zero-gradient loss gives no useful first-step protection. These are mathematical deductions, not empirical root-cause findings.

From [Adam Algorithm1](https://arxiv.org/pdf/1412.6980), the realized update is `Δ = −α mhat/(sqrt(vhat)+ε)`. A raw gradient satisfying `gi·d ≥ 0` does not imply `gi·Δ ≤ 0` after existing moments and preconditioning. Diagnose the actual complete displacement and finite loss change; preserve both models and both Adam states for any future clone/rollback. Resetting moments or projecting the displacement is another intervention. This caveat does not show that Adam caused T479's outcome.

For a future functional constraint, use complete-sequence Jacobian products or finite recomputed functions, per-history limits rather than only one average, and the realized proposal. Even these constrain saved histories, not the changed closed-loop observation distribution. Δ=0 is always feasible but supplies no new capability. T285 prevents treating algebraic feasibility as a navigation result. CPO's expected-cost theory cannot be relabelled a certificate for these finite-history limits.

## Falsifiable next diagnostic and one conditional intervention

The immediate test is B's already registered full383 assessment: enumerate exact gained and lost IDs relative to the same335 retained successes, including side/distance, using the locked acceptance rule. Aggregate eight gains cannot compensate for old losses. A better average fixed-history RMSE also cannot substitute for this test.

If B qualifies, retain only through its existing audit/selection procedure; this note supplies no reason to add another optimizer intervention. If B also fails, use **one bounded old-task replay eligibility and direction diagnostic before any new training**:

1. Inventory the actual archived old-task trajectories: complete causal observations/reset masks, executed stochastic actions, original behavior distributions/densities, rewards, native counts, and true terminal/truncation semantics. Deterministic successful evaluation histories are function references; a Gaussian evaluated at their mean is not the sampling law that generated them. Missing old-task replay support is a documented failure of eligibility, not permission to invent log probabilities.
2. On the fixed eligible batch, recompute candidate recurrent histories and corrected returns. Report per-task density-ratio support/clipping, return/advantage signals and loss changes under the saved initial-to-proposal displacement. A separately bounded zero-step gradient diagnostic may compare fresh LEFT/RIGHT and old replay gradients against that displacement; this note performs none. A final multi-epoch displacement is only an aggregate diagnostic, not evidence about every unavailable intermediate Adam step.
3. Falsifiable prediction: old RL rehearsal is a plausible next module only if these own old-task episodes supply usable, nondegenerate corrective signals where retention is lost. If behavior support is absent or weights/targets degenerate, the proposed replay module fails its preflight. Favorable gradients with continued native regression would reject the narrow first-order-conflict account; it would not isolate capacity, dynamics or estimator error.

**The single intervention to consider after a failed B and a passed eligibility diagnostic is a fixed old-task recurrent RL replay auxiliary, CLEAR-inspired, alongside unchanged fresh PPO and existing function retention.** It supplies actual old-task return/action learning instead of merely another copy of initial means. Use original behavior densities and V-trace-style correction for historical stochastic episodes; reconstruct current hidden states from actual histories, with the existing bounded-action probability contract and physical-time discounting. Preserve failures as well as successes rather than silently treating success-filtered episodes as an unbiased old-policy state distribution. If existing data fail eligibility, a future separately registered bounded old-task stochastic collection must precede this test; none is authorized or launched by this note.

The matched control should see the same collected data and total update schedule while omitting only this replay auxiliary. Fix old-task/side weighting, normalization and coefficients before launch; do not also add CAGrad, reset Adam, change architecture, tune a projection, or substitute a new critic family. This is an adaptation, not full CLEAR replication. If replay fails, retain the failure; it does not automatically justify a second live mechanism. CAGrad requires its own actual-loss evidence, and dense functional constraints require a separate feasibility diagnosis.

Acceptance remains preservation of the exact retained success IDs plus a new eight success under complete locked development assessment and whole-state rollback. Such development acceptance is an empirical filter, not unseen-state safety, generalization, originality, or proof that the dominant root cause has been found.
