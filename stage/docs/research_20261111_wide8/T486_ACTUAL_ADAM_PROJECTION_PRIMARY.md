# T486: remembered-trajectory halfspaces on the actual Adam displacement

2026-11-11. Fresh-context delegated primary-source review, Stage only. Research note, not a registered protocol or launch. No simulation, backward pass, optimization, model edit, or existing evidence edit was performed. The T486 design below is the parent's proposal, not an observed result.

## Primary evidence and naming

**GEM is a direct precedent for separate remembered-loss halfspaces.** Lopez-Paz and Ranzato's [GEM paper, §3, equations (6)–(8), Algorithm 1](https://papers.nips.cc/paper/7225-gradient-episodic-memory-for-continual-learning.pdf) constrains each remembered task separately. It projects a descent gradient to the closest Euclidean feasible gradient, then applies an SGD step. Its interpretation explicitly assumes local linearity and representative memory. The [author implementation, `project2cone2`, optimizer construction, and `observe`](https://raw.githubusercontent.com/facebookresearch/GradientEpisodicMemory/master/model/gem.py) uses SGD, gradient replacement, a regularized dual Gram matrix and a configurable margin. T486's unregularized zero-margin displacement QP with individual trajectory losses would therefore be a GEM-like adaptation, not an exact task-based reproduction.

**A-GEM pools past tasks into one constraint.** Chaudhry et al.'s [A-GEM paper, §4, equations (9)–(11)](https://arxiv.org/html/1812.00420v2#S4) uses a random episodic-memory batch to estimate the average reference gradient. With descent gradients, it requires `g_refᵀ g_tilde ≥ 0`; when violated, its closed-form solution is `g_tilde = g − (gᵀg_ref / ||g_ref||²) g_ref`. Eight simultaneous taskwise constraints are GEM-style; averaging the eight first can hide one task's deterioration. The paper's experiments and [official implementation](https://github.com/facebookresearch/agem) concern supervised continual-learning benchmarks. Neither paper supplies a navigation-contact or terminal-success guarantee.

## Why the realized displacement is the right local object

The following is a mathematical application of the papers, not a result they report for Stage. Let `L_k(θ)` be a specified old-task surrogate and `a_k = ∇θ L_k(θ)` evaluated at the **current, pre-update Actor**. For a realized parameter displacement `δ`,

`L_k(θ + δ) = L_k(θ) + a_kᵀδ + O(||δ||²)`.

Thus the first-order condition is `a_kᵀδ ≤ 0`. GEM's opposite inequality uses a descent gradient because its displacement is `−α g_tilde`.

[Adam Algorithm 1](https://arxiv.org/pdf/1412.6980) updates first and second gradient moments and applies `δ_Adam = −α m_hat / (sqrt(v_hat) + ε)`. Existing moments and coordinate scaling mean `δ_Adam` is generally not a negative scalar multiple of today's gradient. Projecting today's raw gradient before mature Adam therefore does not establish the displacement condition. Even without momentum, take `a=(1,1)`, `g=(2,−1)`, and positive diagonal scaling `D=diag(1,10)`: `aᵀg=1≥0`, but `aᵀ(−Dg)=8>0`. This is an algebraic counterexample, not a measured Stage failure or proof that Adam caused prior regressions.

For the proposed pilot, first let the unchanged joint PPO + old-RL + function-keep Actor loss and mature Actor Adam propose **the full actual displacement** `d=θ_proposal−θ`. Then solve

`δ* = argmin_δ ½||δ−d||²  subject to Aδ ≤ 0`,

where row `k` of `A` is `a_kᵀ`, for eight individual old-LEFT5 episode reference losses in the refined proposal. Apply `θ←θ+δ*`. Keep the moment state generated by the original loss step, as proposed. This is a **projected Adam proposal with unprojected moment updates**; it is neither ordinary Adam nor GEM's SGD algorithm. The moments need not encode the applied displacement. Every subsequent step needs its own current gradients and projection. Whole-trial rejection must restore both models and both mature optimizer states according to the locked protocol; changing only Actor parameters would not restore the original starting condition.

## Eight-row solver: exact target versus numerical implementation

This is a derivation for the proposed QP. Its KKT conditions are

`δ=d−Aᵀλ`, `λ≥0`, `Aδ≤0`, and `λ_k(Aδ)_k=0`.

Writing `K=AAᵀ` and `b=Ad`, the dual minimizes `½λᵀKλ−bᵀλ` over `λ≥0`. With eight rows, exhaustive enumeration has at most `2⁸=256` active subsets, including the empty subset. This only needs tiny CPU double-precision linear systems; no SciPy dependency is required. For an independent active subset `S`, solve `K_SS λ_S=b_S`, set other multipliers to zero, form `δ`, and check **all** inequalities, multiplier signs, stationarity and complementarity. Select the valid candidate with smallest primal distance. In exact arithmetic, an independent generating subset suffices even when some rows are redundant. A pseudoinverse on every singular subset alone is not a substitute for valid KKT checks: a particular minimum-norm multiplier can have negative components although another representation exists.

Zero displacement is always feasible, so contradictory rows cannot make this homogeneous problem infeasible. They can remove all useful movement. A zero fallback is not evidence that the Euclidean optimum was found. Normalize nonzero rows only by a positive factor if needed; record exact-zero rows as vacuous and do not silently delete small nonzero gradients. Adding Gram damping or positive margins changes the target QP. Lock numerical tolerances and failure behavior before the pilot; verify constraints on the **actual stored-precision applied displacement**, since casting can change a float64 feasibility result. Log raw/projection norms, row norms, all eight raw and applied inner products, active subset, KKT residuals, and finite recomputed surrogate changes. A finite loss increase remains possible despite first-order feasibility.

## Application boundary for the proposed T486

The supplied design keeps the 120-input GRU single Actor and Value architecture, the fixed sixteen fresh-eight-metre historical episodes and exact initial state, and the existing Value update path. The refined replay has fifteen histories: seven historical old-task centers plus eight old-LEFT5 episodes from eight distinct prelocked lost IDs. Auxiliary weighting is family-balanced: each other family gets `1/8`, and the old-LEFT5 family's `1/8` is divided across its eight episodes. **The projection rows are the eight individual LEFT5 episode gradients, not eight family means.** The other seven families enter the V-trace auxiliary and existing old211/own8 anchors; this projection supplies no separate nonincrease constraint for them. Individual LEFT5 reference gradients should be recomputed at each current Actor from complete recurrent histories, with explicitly frozen/detached return or advantage targets for each local gradient calculation. The scalar surrogate and its gradient must agree; changing targets while interpreting a finite loss difference changes what is being compared.

An identical initial Actor hash is necessary evidence for reuse of initially on-policy data, but it is not sufficient by itself: the full sampling law, recurrent initial state/reset masks, action-density contract and preprocessing must match. Once the Actor changes, the data are historical PPO data under the saved behavior policy. Old V-trace actor surrogates are estimated replay objectives, not exact gradients of unseen old-task navigation success. If Actor and Value share any parameters, Value-induced changes to those parameters must be included in the full projected displacement; an independent Value optimizer must not modify the Actor after feasibility is checked.

The engineering question is whether this one bounded adaptation can constrain the eight chosen local trajectory surrogates while retaining useful eight-metre progress under the complete locked native383 assessment. Sparse remembered histories, nonlinear finite steps, changed closed-loop observations, stochastic gradient estimates, and a surrogate-to-success gap all remain. Neither nonlinear loss nonincrease nor retention of the other old families follows. Preserve exact retained-success IDs and require the existing complete acceptance/audit/rollback rule. This single pilot cannot isolate projection as a causal remedy without a matched control, establish novelty over GEM/projected optimizers, or certify safety/generalization. No expansion, second candidate, simulation, or optimization is authorized by this note.
