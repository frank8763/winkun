# 当前学生偏离状态的恢复监督：原始方法与最小诊断

2026-11-07，Stage only。本次仅阅读原论文、少量作者源码与Stage文档，未导入模拟器、未执行仿真/训练/教师查询、未修改研究状态或历史证据。T402R已结束；这里是决策依据，**不是已注册或已启动的T403协议**。不涉及Phase聊天、模型、实验、规划研究或自动化。

## 判断

优先检查**当前T402R最终Actor从原起点实际到访的早期偏离状态，教师能否在原任务剩余预算内完整恢复**，而不是继续增加52秒晚期课程的轮数。需要改正一项方法解释：**“冻结学生在有限教师纠正后已经能够GOAL”不是DAgger的标签准入条件。** 可以保留它作为独立的交回诊断，但不宜把它作为所有恢复监督的必要前提。否则，凡是学生尚不会完成的恢复段，可能恰好都无法进入学习。

这并不表示放宽自主验收：完整教师恢复只证明一条训练轨迹可行；更新后的学生仍须从原起点纯自主运行，再检查旧任务。不存在教师GOAL自动转化为学生GOAL的保证。下列论文也没有给本任务六米通过、泛化或论文创新作保证。

## 四项最接近的方法

### 1. DAgger：在学习器实际访问的输入上查询专家，然后迭代聚合

Ross、Gordon、Bagnell，AISTATS 2011。[正式论文PDF](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)，实际核对§2.2、§3 Algorithm 3.1与§3–4保证条件。

Algorithm 3.1使用当前学习器/专家混合策略采集状态，为访问状态查询专家动作，并在累计数据上训练。它不要求学习器先成功，也不按“这条学习器轨迹最终是否成功”筛选专家标签。理论依赖学习问题、无悔/损失等条件；由模仿损失转任务代价还涉及专家续行下的代价放大项u。论文明确讨论u最坏可随时域增长。因此，“两轮、小神经网络、单条成功恢复”不能直接继承其性能界。

对本项目的含义：应重新访问**更新后**的学生分布；一轮BC后的新偏离不由前代学生的数据自动覆盖。这里支持有限迭代聚合，不支持保证成功或无限收集。

### 2. DART：让专家演示纠偏，但扰动分布必须有意义

Laskey等，CoRL 2017。[正式论文PDF](https://proceedings.mlr.press/v78/laskey17a/laskey17a.pdf)，实际核对§3、§4–4.2、Algorithm 1/Proposition 4.1。

DART在专家控制流中注入噪声，迭代调整噪声以近似学习器的误差，并聚合纠偏示范。论文§4明确指出，任意噪声参数不会自动最小化分布偏移；理论讨论亦指出专家若被噪声改变，其假设可能不成立。该方法不是“把原成功轨迹动作随意加噪后就能覆盖当前碰撞状态”的定理，也不保证特定窄通道可恢复。

作者公开[实验代码](https://github.com/BerkeleyAutomation/DART/blob/master/experiments/test_dart.py)的`update_noise`与`run_iters`已只读核对：实际更新协方差、由带噪专家采集、累积数据。未安装或运行。当前已存在真实学生偏离，优先直接验证该状态，比立即增加一个噪声机制更有针对性。

### 3. HG-DAgger：连续专家恢复后交回，交回标准不是后缀GOAL

Kelly等，ICRA 2019，[原论文v2 PDF](https://arxiv.org/pdf/1810.02890v2)，实际核对§I、§II、§V。

HG-DAgger让人类在需要时取得连续独占控制，并在其判断进入安全稳定区域后交回；恢复段的专家动作加入数据集。论文指出频繁切换、反馈延迟和控制权变化可损害标签质量；即使两个控制器分别稳定，切换也可能带来问题。它没有规定固定1/2/4秒恢复，更没有要求当前冻结学生在交回后直接完成整个任务，才允许收集恢复标签。

因此T396的`NO_VERIFIED_SHORT_BRIDGE`是一项**项目更强的工程门**，不是该论文或DAgger的必要条件。T397的4秒交回成功仍是有用实例，但只覆盖那个晚期状态。本文也不授权本项目部署混合控制器、风险gate或教师路由。

### 4. TaSIL：动作拟合很小仍未必闭环稳定，保证有明确前提

Pfrommer、Zhang、Tu、Matni，NeurIPS 2022，[原论文v2 PDF](https://arxiv.org/pdf/2205.14812v2)，实际核对§2、§3 Assumptions 3.1/3.2、Theorems 3.1/3.2与§4。

TaSIL匹配专家与学习器的动作及相应高阶导数，把模仿误差与闭环误差联系起来。结果要求专家的增量输入到状态稳定性，以及相应光滑性、足够小的误差；快速统计界还有可实现性等条件。一条原生GOAL轨迹没有证明这些前提，平均动作MSE也不等于关键位置误差受到控制。

作者[BC入口](https://github.com/unstable-zeros/TaSIL/blob/main/imitation_learning/bc.py)及[聚合入口](https://github.com/unstable-zeros/TaSIL/blob/main/imitation_learning/dagger.py)已只读查看，未核完整工程/固定commit或运行。此处用作解释边界，**不建议当前加入导数损失或宣称已经证明稳定性**。

## 标签质量与交回能力必须分开

下面是结合上述方法与本项目记录的工程判断，不是论文对本车的保证。

| 检查 | 通过后实际证明 | 仍未证明 |
|---|---|---|
| 从当前学生实际状态出发，教师完整原生安全GOAL且精确重放 | 这一物理状态、clock和真实历史下，选定控制序列存在成功续行；可作为有来源的恢复示范 | 动作逐步最优、任意邻域可恢复、教师是全局一致专家、单Actor一定可学 |
| 同教师只纠正有限时段后交回当前学生GOAL | 该冻结学生对这个交回状态已有续行能力 | 纠正段可被学会、时长越长越好、原起点自主成功 |
| 更新后从原起点纯学生GOAL，并保留旧八 | 当前候选新增原起点中心能力与旧八兼容 | 完整旧275、主54、fresh16、reload78或未见场景泛化 |

建议：把完整教师GOAL与原生重放作为本项目的**经验标签质量门**，把有限交回作为可选诊断或更新后指标。完整成功本身也比DAgger的逐状态专家标签设定更强，不能称为其原始要求。仅保留成功恢复还会选择性排除难状态，故所有失败查询和未覆盖状态应保留并报告。

标签必须是`该实际观测/因果历史 -> 该时刻专家动作`。不能把成功参考在相同时钟的未来动作，直接贴到已经偏离的学生观测上。实际恢复起点的首标签属于学生到访分布；教师连续接管之后的输入主要来自教师恢复分布。它们仍有训练价值，但**整条教师成功后缀不是整条纯学生状态上的DAgger查询**。若下一次更新改变了学生路径，就需要有限地重新采集当前策略偏离，而不是只加固定示范的拟合步数。

## 循环历史的合同

以下来自循环策略语义与本项目已有合同，不能归因于上述论文已核验本车实现。

- 物理snapshot相同不代表循环策略输入相同。恢复必须保留原clock、完整120输入构造历史、previous-action、执行器状态及RNG等注册项；不能只恢复XY、朝向和距离。
- 同一冻结候选的交回：教师执行期间仍以**真实观测与实际执行动作历史**推进学生hidden；交回不能替换为成功参考/教师的hidden，也不能在交回清零。
- 更新后的学生：用当前参数从episode zero重算完整因果history和hidden。旧学生或教师存储的hidden可以作证据核对，不能当新参数下正确的隐状态。参数改变后，新hidden和旧hidden数值不同本来就可能合理。
- 若自动教师自身是循环策略，也必须说明其从真实历史重建自身hidden的方法；不能给它成功参考的未来历史。若教师是训练期搜索出的有限控制序列，应如实称“该snapshot的一条已验证序列”，不能称任意状态闭环专家。
- 监督前缀中的学生动作不冒充专家标签：动作loss可mask，观测/动作历史不能删掉。教师标签不算新学生on-policy PG数据，教师回报也不赋给学生轨迹。

## 训练前最小有界诊断草案

本节只提出要回答的问题，不授权launch或替代root制定的数值预算。

1. 优先只读比较当前原起点LEFT失败轨迹与已验证成功参考：查看碰撞前首次可复现的动作/位置/速度/朝向偏离；相同时钟差异只用于定位，不能直接作标签，也不能证明唯一因果。若现有文件缺早期输入，另外注册一次冻结重建；不重跑旧完整网格。
2. 固定**一个当前学生早期实际状态**，不把53秒参考状态或前代B的2.4秒状态冒充它。固定选择规则后锁native、完整history、学生参数与hidden来源。先要求原学生从该状态续行与历史失败一致；现有精确证据可明确复用。
3. 在单独注册的固定教师候选/物理/墙钟/存储上限内，验证该状态是否存在完整原生GOAL续行。找到后只做约定的一次精确重复；失败就停止此问题，不自动扩时窗、噪声、seed或预算。这里不要求未经训练的学生先能短桥交回GOAL，亦不在本诊断中训练Actor。
4. 若有成功源，再检查标签/历史契约与旧八保持数据的当前参数重建是否完备；下一学习协议可最多两轮“当前策略采集→验证恢复→有限获取→独立巩固→原起点纯学生及旧八验收”。这是有限工程假设，不能借DAgger名义宣称充分性。每轮没有当前有效标签、原生不匹配、容量不足或旧能力门失败就按注册方案回退/停止。

最小诊断真正区分的是：**当前失败之前是否已有可验证恢复源，还是连训练数据支持都缺失。** 诊断通过后仍需分别面对动作拟合精度、长序列教师分布偏移、循环表示/优化及旧任务干扰。没有一条来源支持仅凭该诊断就承诺六米成功或期刊贡献。
