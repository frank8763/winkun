# T407 bounded exact byte reserve

This Stage-only storage operation imports no simulator, NumPy or Torch and performs zero physics or optimizer steps. It scans only real NPZ files of at least 20,000 bytes under T166–T219, excludes models, demonstrations, videos and every current T406 input or source-protocol input, and keeps the lexicographically smallest canonical file for each exact SHA256. Size-descending selection fixes the smallest number of duplicate files reaching 8 MiB; the registered records never expand.

`prepare` first checks T406 COMPLETE, independent audit PASS, final driver COMPLETE_AUDITED_REMOTE_VERIFIED and absence of every recorded launch/driver/main/worker PID. It freezes the exact records in the two identical protocol files. Every selected original and canonical is then included in a deterministic RAM-only archive, published to the existing Stage repository Release and fully read back with archive equality and every member SHA256 verified. Exact asset name, size and GitHub digest are checked before any upload or reuse. Originals remain untouched in this phase.

After the root agent commits the registered source and verifies the exact remote root tree, `run` acquires the Stage writer lock. It rechecks every protected input and selected pair, creates T290-compatible explicit reference JSON, durably records each in-flight item, then removes only the duplicate payload. The original bytes remain in the unchanged local canonical and full remote archive. No canonical file, model, original failure content, demonstration or video is removed. No symbolic links or hard links are used.

The bound is 180 seconds for encoding, 256 KiB total task metadata including references, global runs below 1 GiB, and at least 40 GiB filesystem free. Preparation separately verifies that encoding plus this full metadata allowance and the next 15 MiB experiment fits the global bound. No binary temporary archive is written to disk. The fixed run is never automatically retried after partial encoding; errors preserve the registered protocol and durable ledger.

Run commands from the repository are `PYTHONDONTWRITEBYTECODE=1 python stage/experiments/t407_cold_exact_reserve/cold.py prepare`, then `run` only after commit/sync, and finally `audit` in a separate process. Historical original paths use `stage/experiments/t290_exact_duplicate_store/store.py resolve`. Its `restore` checks complete global capacity (`used + payload + 65536 < 1 GiB`) and free space (`free - payload >= 40 GiB`) before exact-byte restoration. Keep this guard intact.
