## Objective and why a literal clamp is insufficient

For each output coordinate let `c` be the stored executed float32 target lifted exactly to float64, and `m=parent_mu+head(x)` be the unbounded float64 full mean. Define

```text
c == +1: loss = max(1-m, 0)^2     target set [1,+infinity)
c == -1: loss = max(m+1, 0)^2     target set (-infinity,-1]
otherwise: loss = (m-c)^2         target set {c}
```

Average both coordinates, time within each trajectory, trajectories within each group, then the fixed `.50/.25/.25` mixture. Do not clamp `m` inside this training loss, detach it, substitute the residual for the full mean, or apply the bound test to the parent rather than the target. Preserve the existing command computation for deployment.

This is squared distance to a target interval/half-line. Our algebra: for `c=+1,m=-2`, the proposed loss is9 and derivative−6, so descent moves toward the correct side; for `c=+1,m=+2`, both are0. In contrast `(clip(m,-1,1)-c)^2` has nonzero error but zero derivative when `m=-2,c=+1`. Interior targets have the same clamp dead zone if the prediction is outside either bound. The proposed objective is continuously differentiable in `m` at±1, with changing second derivative; the tanh head still makes the parameter problem nonconvex. No convergence guarantee follows for finite LBFGS.

Important numerical qualification: if deployment computes `float32(clip(m,-1,1))` under usual round-to-nearest/even, a command of+1 can already occur at `m=1-2^-25`;−1 has the symmetric threshold `-1+2^-25`. Thus `[1,+infinity)` is a slightly conservative continuous surrogate for the float32+1 equivalence cell. Unsaturated float32 commands also have rounding cells, whereas the proposed interior target is a point. A raw mean that reproduces the command exactly may still incur a tiny loss. Do not claim this is exact float32-command equivalence, zero self loss/gradient, a likelihood, or recovery of a unique latent teacher mean. These statements are mathematical analysis, not measurements of the current tensors.

## What the primary sources support—and do not support

**Clipped execution equivalence.** Fujita and Maeda, *Clipped Action Policy Gradient*, ICML2018, §3/equations4–5 and10–12, explicitly distinguish raw actions from bounded execution. Their estimator uses tail probability scores at the bounds; its unbiasedness/variance result is for stochastic policy gradients under the stated clipped-transition/reward assumptions. It motivates respecting execution equivalence, but gives no theorem for deterministic BC squared hinge, retention, closed-loop success or finite LBFGS. [Paper](https://proceedings.mlr.press/v80/fujita18a/fujita18a.pdf). The authors' `ClippedGaussian.log_prob` uses Gaussian CDF/survival probabilities for clipped boundary observations; their wrapper clips actions explicitly. This is not the proposed BC objective, and no CAPG code is imported here. [Author distribution code](https://github.com/pfnet-research/capg/blob/master/clipped_gaussian.py), [wrapper](https://github.com/pfnet-research/capg/blob/master/clip_action.py).

**Established interval-regression surrogate.** Hocking, Rigaill, Vert and Bach, ICML2013, §3.3/equations14–17, use sums of squared hinge terms to relax interval-target regression. Their author implementation evaluates both interval sides and supplies the corresponding gradient; setting margin0 yields squared distance outside the interval. This supports the construction as an established surrogate, not novelty or a navigation result. The paper's linear-model convexity and regularized optimization claims do not transfer to the nonlinear T715 head. [Paper](https://proceedings.mlr.press/v28/hocking13.pdf), [author implementation, `squared.hinge`, `calc.loss`, `calc.grad`](https://github.com/tdhock/penaltyLearning/blob/master/R/IntervalRegression.R).

**Censored regression is not one universal loss.** Dănăilă and Buiu2024 distinguish censored-distance objectives and Tobit likelihoods. Their §3.1/equations10–13 and AppendixA equation44 use a clipped prediction for CMSE, which is not the proposed target-conditioned half-line loss and has the clamp-gradient limitation derived above. Their §3.2 tail likelihood terms require a noise model and scale. This is a useful counterexample to claiming “the censored loss” is automatically the proposed hinge. The inspected work evaluates regression datasets, not autonomous navigation or this Stage policy. [Primary article](https://link.springer.com/article/10.1007/s10044-024-01216-9).

**A low hinge score can be weak evidence.** Qi et al., ICML2023, §3.2, explain how a one-sided censoring metric can be optimistically low when predictions extend beyond the censoring boundary. That result concerns survival MAE, not this control experiment. The relevant inference here is narrower: training hinge reduction alone cannot establish useful control. Unlike unknown event times, command overshoot really can be execution-equivalent at a fixed state; however, unconstrained overshoot can still alter behavior at nearby states and consume shared head capacity. Closed-loop panels must decide. [Paper](https://proceedings.mlr.press/v202/qi23b/qi23b.pdf).

**Bounded author-code search for action-clipped BC.** The targeted search did not establish an author implementation of this exact clipped-action BC hinge. The inspected TD3+BC author source uses a tanh-bounded actor and ordinary `mse_loss(pi,action)` in an RL-plus-BC objective; it does not implement the proposed censoring treatment. It is a standard BC reference/counterpoint, not a T715 reproduction. [Author repository](https://github.com/sfujim/TD3_BC), [actor and loss source](https://github.com/sfujim/TD3_BC/blob/main/TD3_BC.py). Absence from this limited search is not evidence of novelty or absence from all literature.
