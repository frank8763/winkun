# T712 narrow primary review — 2026-11-24

This is a bounded scientific-design review, not registration, execution or an audit PASS. It reads repository instructions, current research status, migration context, the paper execution decision, T703 construction, T701/T710 optimization source and completed T711 findings. It performs no model forward, fitting, geometry computation or native rollout. T698 remains retained; original failures and consumed budgets remain unchanged. Only this Markdown file is added.

The proposed study is defensible as **one finite compact-support ablation plus a prespecified ordinary-replay retention tradeoff**. Three new replay arms start from exact B0, train the same complete 108-hidden/20,198-parameter head at old-task weights .50/.80/.95, and receive the same finite optimization allowance. Compact plain support changes only the old-history separation term of T703, if that intervention is non-vacuous. This answers the [paper plan](PAPER_EXECUTION_PLAN.md) more directly than another recovery-qualification queue. It does not establish best possible replay, new-map transfer or novel control theory.

## Required clarifications before registration

1. **Specify loss normalization, not just alpha.** A clear objective is `alpha * mean_403(mean_time(mean_2outputs(square_error))) + (1-alpha) * mean_7(mean_time(mean_2outputs(square_error)))`. Per-row scalar weights are therefore `alpha/(2*403*T_id)` and `(1-alpha)/(2*7*T_id)`, with the two squared output coordinates summed. At alpha=.5 this matches [T701 refine](../../experiments/t701_compact_retention/fit.py). [T710](../../experiments/t710_whole_head_replay/fit.py) instead doubles those data weights and adds a final-layer anchor penalty. Copying T710 without declaring its scale and rho would change more than the old/source tradeoff. Fixed LBFGS stopping tolerances make global loss scale operationally relevant. Keep frozen input features, label semantics, all 403/7 IDs, per-ID lengths and chunk reduction order explicit.

2. **Use the new alpha=.5 arm as the matched extra-training control.** The final proposed grid is .50/.80/.95, each starting from exact B0, with80 gradient closures/64 attempts and no ridge penalty. This resolves the initial proposal’s extra-training confound among the three new arms. The reused historical B0 checkpoint remains an unrefitted reference, not that matched control. The new .5 arm differs from T701 (which starts from T699) and consumed T710 (160 closures plus rho); record these distinctions and do not restart those jobs. B0 already trained its entire head; this is not first-time unfreezing. Historical finite fits do not certify convergence or BC impossibility. [T701 source](../../experiments/t701_compact_retention/fit.py), [next-decision corrections](../overnight_20261123_24/NEXT_DECISION_20261124.md).

3. **Freeze model-selection rules and missing-result behavior.** Thresholds 4/12/20 old losses correspond to floor(1/3/5% of403). For each threshold, maximize audited safe outcomes on exposed local78, using a fixed tie-break (for example fewer old losses, then fixed arm order). Declare whether historical B0 and compact models are eligible or references only. If none qualifies, report none. If an arm is incomplete, selection among available arms is explicitly incomplete; do not imply the full grid was compared. Seven-source loss and collisions must remain visible even if not part of the selector. No zero-forgetting or source-success screen may suppress native evaluation of a numerically valid completed arm.

4. **Local78 is development selection data.** Selecting on it makes the selected score a development maximum, not an unbiased transfer estimate. Its starts and all known431 outcomes are exposed same-map evidence. Freeze any later untouched test before obtaining its outcomes, and do not reuse T711 as blind. Related starts are not independent maps or training repetitions. The DAgger primary paper explicitly motivates the policy-dependent visitation distribution; it does not provide Stage's static nominal-output matching with a control guarantee. [DAgger abstract](https://proceedings.mlr.press/v15/ross11a.html), [T711 findings](../overnight_20261123_24/t711/FINDINGS.md).

5. **Preserve completed optimizer states.** A closure budget can be reached during a line search. Export the last fully completed optimizer-step state after restoring both head and optimizer on an interrupted attempt; report completed and charged/partial closures separately. The existing T701/T710 code already rolls back its explicit EvaluationBudget exception, but a deadline/guard exception is a different path. Export each live candidate before shadow work and mark it provisional until exact independent reconstruction passes. The final loss and gradient, if reported as final-state quantities, must be evaluated at the exported state; a last trial closure can describe a rejected line-search point. No additional uncapped gradient call should be hidden as reporting. [T701 refine](../../experiments/t701_compact_retention/fit.py), [T710 optimize](../../experiments/t710_whole_head_replay/fit.py).

## Compact plain-support intervention

Use the exact T703 parent, projection, centers, source coefficients, radius storage dtype and deployment arithmetic. Protected radii are `float32(.49 * min(distance_to_old, distance_to_other_source))`; plain radii are `float32(.49 * distance_to_other_source)`. Recompute source separation with the same order and diagonal exclusion; do not tune the .49 factor. Report stored-radius changes and changes attached to nonzero coefficient rows. If all effective radii are identical, the ablation is vacuous and receives no duplicate native evaluation. Radius changes alone are not evidence that the registered finite initial-state suite encounters a changed action. [T703 construction and Actor](../../experiments/t703_projected_local/t703_actor.py).

The plain candidate deliberately permits old-history response. Remove the old basis-zero and old-command-equality **admission** requirements; measure those differences instead. Keep finite-positive radii, unchanged tensors, source K=I, exact source executed commands, owncarry reconstruction, export/reload and independent arithmetic checks. Do not silently reuse T703's combined old403+source7 equality gate in its [fit path](../../experiments/t703_projected_local/fit.py), which would reject the intended comparator before evaluation.

For this fixed .49 other-source separation, distinct source supports remain disjoint in exact arithmetic; nevertheless actual stored/promoted radii and source commands must be checked. This is a local derivation, not a cited general positive-definiteness theorem. Larger plain support may affect old states, but need not worsen task success; zero old loss must not be assumed. Projection-space locality also does not imply locality in physical state or along the projection nullspace. See the original [T703 primary review](../day_20261123/T703_SUPPORT_PRIMARY_REVIEW.md) for assumptions and limited publisher reading scope.

## Fairness, cost and interpretation

All replay candidates add161,584 tensor bytes; the compact comparator adds157,684, with the same2,621,976-byte common parent accounted separately. This is comparable additional deployment memory, not equal functional capacity or a whole158KB policy. Include serialization, latency, RSS, fit/reconstruction/audit wall time, gradient closures and actual native steps. Reused historical controls have historical costs and are not new independent repeats. Three new alpha arms constitute an explicit tuning allowance; report all points and the previously spent method-development effort instead of portraying one selected point as a single untuned run. [Paper evidence table](PAPER_EXECUTION_PLAN.md), [T703 protocol](../day_20261123/t703/PLAN.md).

Use measured complete-path admission and absolute deadlines sufficient for the maximum admitted arms, exact repeats and audits. A nominal per-arm cap is not evidence that the root worst case fits. If geometry is vacuous, the skipped branch must be recorded rather than reallocating its budget to more replay weights. Partial or unaudited native results remain missing/provisional, never zero successes. Independent audit eligibility and execution failure do not erase the corresponding consumed work or raw evidence.

Existing-method context is deliberately narrow. Progressive Neural Networks already studies retention with added architecture; its abstract does not make this fixed single-Actor compact construction novel. Dark Experience Replay supplies a primary example of a strong simple rehearsal/output-matching baseline, but its classification evidence does not establish navigation safety. Only their primary abstract pages were read in this review, along with the DAgger abstract; no exhaustive search or author-code reproduction is claimed. One additional guessed NeurIPS page was inaccessible and supplies no evidence. [Progressive Neural Networks](https://arxiv.org/abs/1606.04671), [Dark Experience Replay](https://proceedings.neurips.cc/paper/2020/hash/b704ea2c39778f07c617f6b7ce480e9e-Abstract.html).

The admissible conclusion is a finite retention/transfer/cost comparison on these declared histories and exposed same-map starts. A non-vacuous support ablation can identify the effect of its fixed protection term within the common compact construction. The replay grid can show a prespecified feasible development tradeoff and compare its two new old-weighted arms to the new matched .5 extra-training control; historical B0 remains a separate reference. Neither result establishes universal retention, optimal memory, independently replicated superiority or journal readiness. This review creates no follow-on queue.
