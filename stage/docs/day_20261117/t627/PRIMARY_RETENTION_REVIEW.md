# T627 一手文献：怎样检验“新增两项、丢掉两项”

2026-11-17；仅文献与既有 Stage 证据研究，0 native、0 optimizer、0 launch。未读取或使用 Phase。下面是机制判断和下一试验建议，不是实验授权或保持保证。

## 已知问题与机制边界

[T626 原报告](../t626/FINAL_REPORT.json)的候选仍为34/49：新增 sector1offset2、8m LEFT00，丢失 sector4offset2、8m LEFT13，因此拒绝并回到T608。8次Actor更新全部通过采样历史的每任务平均KL门，最大0.00163239<0.01。不能把总成功数相同解释为保留旧能力。

[实际实现](../../../experiments/t626_multitask_closed_loop/t626_learning.py)中，33条旧成功历史的保持项为当前父函数平方误差；初始化误差和梯度都为零。这是代数性质，不是实现失效证据。它在参数移动后提供恢复力，但首步没有独立旧任务回报方向；调大系数不能修补未覆盖的状态分布。另须明确：KL硬门实际计算于8个采样任务的32条历史，并非全部33条保持历史；平均KL也不是逐时刻最大动作误差。

8m LEFT13本就包含在T626真实探索/PG任务中，仍然丢失。因此“加入旧任务在线样本就一定保持”已不成立；sector4offset2缺少本轮真实PG覆盖是另一个可检验缺口。[T614](../t614/FINDINGS_AND_NEXT.md)也表明三个恢复历史上输出约束可行、真实接管成功，仍不能保住这两个原起点任务。[T625R](../t625r/FINDINGS.md)的Critic训练拟合改善但跨任务门失败，不宜为本次保持试验再引入未经认证的Critic。

## 对CAGrad方案的独立判断

[CAGrad原论文，§3/定理3.2](https://proceedings.neurips.cc/paper/2021/file/9d27fdf2477ffbff837d73ef7ae23db9-Paper.pdf)寻找平均梯度附近、最坏局部改善尽量好的方向；在光滑性、步长等假设下讨论平均目标的stationarity。**它没有承诺每任务每步下降，更没有34个旧任务的闭环保留保证。**例如标量梯度g1=1、g2=-0.9，平均g0=0.05；c=0.4时可行方向仍全为正，故g2·d<0，第二任务的一阶损失仍可增大。这是本笔记的反例推导，不是论文实验结果。

所以，复用T626原始T608行为8×4条数据，新增遗漏旧任务sector4offset2的4fresh+4exact，然后同9任务比较普通SGD和固定CAGrad，是有意义但范围很窄的**梯度组合消融**。共同新增数据让两臂可比较；相对T626的变化还包含覆盖与Adam→SGD，不能全归因CAGrad。固定旧batch仅在初始T608处为对应行为数据，后续多步是clipped历史代理目标，不能称每步重新on-policy。

[作者实现](https://github.com/Cranial-XIX/CAGrad)各任务脚本缩放方式须逐函数固定；例如[官方toy函数](https://raw.githubusercontent.com/Cranial-XIX/CAGrad/main/toy.py)使用除以(1+c)，并且实验本身使用Adam。使用SGD是便于解释实际方向的工程选择，不是“官方CAGrad必须禁Adam”。`rescale=1`应在协议写清精确公式、源码位置/commit；不要只锁名字。

## 建议的有界判别顺序

1. **先零native检查8个已有真实PG梯度。**记录Gram、范数、平均方向及固定CAGrad方向的各任务g_i·d、方向差与实际预计步长，重点检查已失守8m LEFT13。若只剩缩放差、没有可分辨方向差，双臂完整49验收的机制信息有限；应在协议中预先定义有意义差异门，避免看结果再改门。
2. 若该方向问题值得试，再独立注册上述共享9任务两臂，每臂至多8次更新、单一c=0.4、无lambda/seed/步长网格、无Critic。两臂相同33历史保持、信赖门、梯度裁剪及完整49+4关键exact；检查组合后再加保持梯度/裁剪产生的**实际**位移及g_i·d。普通SGD沿用Adam数值lr可能几乎不动：应预先锁定步长依据并报告参数位移、输出漂移和代理改善；极小更新的阴性结果不能否定方法。
3. 原34逐ID全部保持且至少新增1个原起点safeGOAL才研究保留。分别报告两个已失守与两个新增任务，缺测为null；同一固定开发集重复使用不是泛化。任一臂失败按原界限停止，不追加同机制扫参。该试验即使成功，也只支持这个batch/初值/预算下的组合方式。
4. 若局部代理改善与真实保持持续脱钩，下一独立假设应转向**候选自身诱导分布上的旧任务再采集/恢复验证**。这与继续放大父历史MSE不同；父教师只有真实恢复成功后才提供合格纠正监督。采集前需另立预算和有限回合数，不能把本建议理解为自动多轮DAgger或无限on-policy回放。

本轮可合理检验“补遗漏旧任务真实PG覆盖后，冲突缓解是否比均值梯度更少丢旧项”；不能声称已解决灾难性遗忘、获得安全证书或提出原创算法。
