# T628 一手资料核对（2026-11-17）

本轮重新查看以下一手页面，查看范围限明确列出内容，不声称穷尽近期研究或阅读全文。

- [PPO v2，2017-08-28](https://arxiv.org/abs/1707.06347)：arXiv摘要提出交替采样与代理目标优化。采用每轮当前策略重新收集，再做两次clipped-PG的原则；这里使用无Critic物理时间peer RTG，并非标准GAE/value PPO完整复现。clipping或KL不能保证某个确定性任务不退化。
- [Spinning Up TD3正式文档](https://spinningup.openai.com/en/latest/algorithms/td3.html)：查看探索/执行区别以及训练行动加入噪声的说明。它支持区分随机训练策略与确定性执行，未证明本项目降低噪声有效。TD3的target smoothing不是本次行为噪声退火；本轮不引入未验证Critic，也不把TD3换名。
- [CAGrad v2，2024-02-21](https://arxiv.org/abs/2110.14048)：arXiv摘要中的目标是用任务局部改善来正则化平均优化。此类局部目标与本项目完整闭环验收不同。T627实际证据已说明局部样本下降仍可伴随field4确定性失败，故本轮不再重复相同CAGrad更新。
- 原作者实现及CLEAR/DAgger/循环重放的既有核对见 `../t627/PRIMARY_RETENTION_REVIEW.md`。保持旧样本与纠正状态分布是有相关依据的研究方向，但本轮不构成CLEAR或DAgger的完整复现，也不证明终身学习或跨场地泛化。

两臂共同变更了相对T627的采集任务集合、重采样频率和每批更新次数；只能比较本轮固定sigma与退火日程，不能将相对旧实验的变化全归因于噪声。四个任务已参与开发，49也已反复用于选择，不能充作独立留出或顶刊统计证据。当前作用是检验一个具体失败机制，而非完成论文结论。
