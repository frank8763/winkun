# T381草案：原生模型MPPI式训练教师的单次恢复可行性

2026-11-05。**未实现、未注册、未预检或启动**。本文件使下一项改进具体可审阅，不借新编号继续T379拟合或T380简化模型预算。依据用户接受仅训练期规划教师、部署保持单Actor的最新授权；Phase隔离。

## 要回答的问题

T379去掉保持项后拟合改善但18.336秒碰撞；T380模型在真实learner上1秒位置p95约3.54cm，超过2cm筛选。下一项优先检验：不用该简化模型，原生MuJoCo采样优化是否能从**T379真实偏离状态**给出可执行恢复。原生预测也是额外仿真，全部纳入物理、命令、墙钟和磁盘预算。它是训练期仿真真值教师，拥有完整plant和环境碰撞查询权限；不能说整个训练过程不使用特权信息，也不能将其称部署无地图Actor成绩。

## 建议锁定的单一机制

- 原新0.70m/80s中心、同全车/轮胎/碰撞mask、wheel5/force120/禁止倒车、.002s物理与.2s实际控制。safeT255与全部历史原件保持。教师仅用最终目标，不加入手工中间路点或全局图搜索。
- 先完整复现冻结T379父控制的历史失败（重复非新独立样本），再从原起点精确重建其前40实际action holds（8.0s）。检查完整120、pose、真实history、执行器和积分；不将位置/时钟/速度/转角清零。这个8秒位置由已知失败选择，只是开发诊断点，不是fresh或已证明可恢复状态。
- 保存完整mjSTATE_INTEGRATION与环境Python属性、Witness四帧pose/goal/time、previous action/count，以及同父Actor的真实prefix hidden。每次restore后重绑当前env.history对象与Witness元数据，再逐位比较初态；恢复不推进物理，不是伪造动态reset的导航成绩。先用原prefix的一段真实已存动作验证预测与原轨迹一致。
- 原生预测时不调用stock环境的pose覆盖式bicycle response。必须走已核验Stage native.step_checked；保持真实执行器、轮胎和每物理步碰撞判据。所有lookahead mj_step都计费，不能把恢复snapshot作为免费分支隐去预测步数。
- 一次MPPI式更新：当前父mode作为恒定nominal；32个固定seed噪声序列+nominal共33候选，每条60个.2s holds（12秒预测），drive/steer噪声标准差固定[.20,.40]、每5holds一个块，原命令[-1,1]裁剪。仅一个采样批，不补seed/幅度/时域/迭代网格。记录实际执行动作分散及clip率，不能只看latent噪声。
- 预拟cost为1000*CONTACT+10*终端真实目标距离+.01*动作相邻差平方和，temperature1。按exp(-(J-minJ)/temperature)权重形成一条动作序列。包含动作裁剪、块噪声、自定义cost，故应称MPPI式有限采样控制pilot，不能声称完全复现原论文路径积分推导或得到全局最优。
- 加权序列必须另做真实原生校验；即使所有样本安全，加权均值也可能碰撞，不能拿均值自动当安全控制。失败保留，不能看过结果后改选best sample作为教师。成功候选仍只是这个有限horizon的控制建议。
- 校验通过后，在同一8秒真实前缀后执行这12秒教师控制，再交回同一个冻结父Actor直到原80秒终止。教师动作期间每个真实观测仍更新父Actor hidden，下一观测包含实际执行动作；不把旧policy在另一轨迹上的hidden缓存接入新状态。记录ownership mask，教师控制不是人工输入/on-policy RL，也不是Actor自主输出。
- 只有原生无接触到原.20m目标，才形成一条“教师纠正+Actor续行”的有效训练候选。未到达、接触、超时、horizon诊断结束、无效/删失分开。不得用教师辅助成功宣布Actor学会六米。保存完整原起点混合轨迹；独立第二pass重做相同预测和执行，所有候选/权重/积分与全数组精确，重复不算第二独立成功。

## 预拟有界资源，必须由实现重新核算才能注册

主计算1200秒/独立零native审计300/归档300/全部1800秒；全部物理<=600000（含两pass父历史复现、所有预测、候选校验、真实混合执行和全部重复），全部命令<=80含geometry。每pass最坏原父40000+33*6000预测+混合40000=278000，两pass556000，剩余用于已列预检/参考重建且必须精确去重核算。不能将main1200耗满后自动追加。

own上限拟1MiB：首pass混合full或首passpartial共用一份<=512KiB、全部预测紧凑原数据<=256KiB（内含全部controls）、prefix积分<=4KiB、metadata<=96KiB、日志<=32KiB、第二pass差异证据<=32KiB，合计932KiB、余92KiB。第二pass逐hold与首pass比较，首个不匹配立即停止，已相同前缀用首pass数组SHA引用，只保存首差异完整obs/history/integration及索引；不能继续生成无法保存的唯一后缀。实现仍须证明所有数组最坏编码和metadata界限，当前未做实际admission，不可直接按草案启动。当前全局余量需在T380完整归档后重测；不足则先另立已备份材料可逆存储，不删除唯一证据或扩1GiB。

原生预测紧凑记录至少保留每候选实际控制、每hold的pose/真实steering/速度、步数/终止、cost与完整数组/积分SHA；原混合轨迹保留full120/next/history/hidden/ownership/初末积分。是否真正穿指定wall–circle缺口应独立记录，不改变历史到达成功定义或将绕行宣称穿口。

预检仅零物理geometry与原生snapshot/capture/restore、同初态/同动作/因果history/合法动作范围和计数边界；若需要非零物理预测一致性检查，必须计入上述600k/80与独立输出额度，不能称零步预检。全部科学变量/输入SHA、源码提交与远端根树、实际容量、完整最坏合同后，才允许唯一launch。

原生教师若失败，报告该状态/有限采样的结果，不宣称整个MPPI无效或场景无解，不临时扫采样参数。教师若真能纠正，再另立训练协议将其数据用于纠偏学习，之后独立验收原old275+six54/fresh16/release78。当前不存在这个新训练或七八米启动。
