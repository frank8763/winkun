## Four primary sources: exact method and limits

1. **Net2Net — Chen, Goodfellow and Shlens, ICLR 2016, §§2.2–2.4.** The student initially represents the teacher's function. Widening duplicates units and divides outgoing weights among copies. Deepening inserts an identity only when the activation satisfies the required identity condition; ReLU qualifies, logistic sigmoid does not. Widened units may need symmetry breaking; adding noise sacrifices exact equality. Experiments use feedforward Inception/ImageNet networks. This supports separating an expansion's initial equivalence from subsequent learning. It provides no recurrent-controller repair or closed-loop retention guarantee, and does not establish that one can insert an identity GRU/tanh layer arbitrarily. [Primary paper](https://arxiv.org/pdf/1511.05641).

2. **Adapters — Houlsby et al., ICML 2019, §2.1 and §3.6.** A frozen pretrained Transformer receives nonlinear bottleneck residual modules, d→m→d, adding 2dm+d+m parameters per adapter including biases. Small random projection weights initialize an approximate identity; initialization scale matters. Their task isolation uses task-specific adapters and normalization parameters. Consequently their old-task memory statement is not a retention theorem for one shared adapter used on every Stage state. Evidence concerns text transfer, not navigation or locality. The author implementation uses down projection, GELU, up projection and a residual addition with small random weights; it is not an exactly zero-output initialization. [Primary paper](https://proceedings.mlr.press/v97/houlsby19a/houlsby19a.pdf), [author implementation, `feedforward_adapter`](https://github.com/google-research/adapter-bert/blob/master/modeling.py#L298).

3. **Dark Experience Replay — Buzzega et al., NeurIPS 2020, §3, Eqs.5–6, Algorithms1–2.** DER combines current supervision with squared error to stored past logits on replay inputs. Logits are sampled along optimization, using reservoir memory; DER++ also replays ground-truth labels, partly addressing biased historical logits after distribution shifts. The author `observe` implementation computes supervised loss plus alpha times buffer-output MSE and stores current logits. This is an empirical classification method, not a safety guarantee. T371 already used related functional preservation: merely naming it DER would add no mechanism. Fixing every target to one repair parent, using recurrent trajectories, and balancing named navigation groups are Stage design choices, not faithful DER replication. [Primary paper](https://papers.nips.cc/paper/2020/file/b704ea2c39778f07c617f6b7ce480e9e-Paper.pdf), [author implementation](https://github.com/aimagelab/mammoth/blob/master/models/der.py).

4. **DAgger — Ross, Gordon and Bagnell, AISTATS 2011, Algorithm3.1 and §3.** Iteratively execute the learner or an expert/learner mixture, obtain expert actions on the visited states, aggregate datasets, and train on the aggregate; return a validation-selected policy. The purpose is learner-induced distribution coverage. Guarantees depend on online-learning/loss assumptions, adequate policy-class fit and sample conditions; they do not automatically apply to finite nonconvex GRU optimization with sparse corrective labels. Replaying an old route, or matching the learner's own outputs on new states, is not new DAgger correction coverage. A successful forced branch supplies a few valid behavior targets, not the queried expert assumed by the reduction. [Primary paper](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf).

The papers and the two specific author implementations were inspected; this is not a claim to have reproduced them. No source establishes novelty or guaranteed Stage success.

## Next-design hypothesis: one shared nonlinear residual head

**Recommendation, speculative:** first distinguish finite-data interference from missing labels offline, then consider one fixed small nonlinear expansion. Do not simply repeat T371 with more steps, another loss weight, or another projection. T284/T285 projection failures and T369 auxiliary failure remain negative project evidence; they do not refute all nonlinear adapters or establish the next adapter's adequacy.

Let z_t be the existing 16-dimensional feature supplied to the steering row, produced by the unchanged 120-input true-GRU Actor with factual history. Keep the complete original network, original steering row, drive row and future head frozen. Add inside that same Actor:

`steer_location'(z) = steer_location_parent(z) + v^T ReLU(Az+a) + b`.

For one illustrative fixed width m=4, A has 64 parameters, a has4, v has4 and b has1: **73 new trainable parameters**, versus T371's17. This is a scalar residual head inspired by adapters, not the paper's full 16→4→16 adapter, which would add148 parameters. Initialize v=b=0 and A nondegenerately; the residual is mathematically zero everywhere at initialization. Do not initialize all layers to zero: the hidden transformation would fail to acquire diverse features. With zero v the first gradient into A is zero; learning of A begins only after v changes. Actual identical-history output/hidden/drive and saved-load equivalence still require numerical verification; mathematical equality alone is not a byte-level audit.

The nonlinearity is the proposed mechanism. Two linear projections collapse to another affine steering row, so adding linear factors adds no expressivity over the existing17-parameter affine function of z. A scalar linear output already has rank at most one: calling the adapter a higher-rank steering update would be misleading. Four ReLU units offer four learned hinges, not arbitrary local support. They can still affect large regions, memorize the five labels, or fail if z aliases states requiring different actions. Zero initialization preserves the initial function only; it imposes no preservation after fitting.

At deployment this is one unconditional neural forward pass with the same120 inputs and true recurrent history. There is no task adapter selection, separate controller, time/distance test, waypoint, map, planner, teacher or runtime router. Existing observations may inform the learned correction; no handcrafted activation window is introduced.

## Evidence needed before this becomes an experiment

These are proposed checks, **not performed in this note**:

- **Finite-data feasibility:** for the existing linear head, form the weighted design matrix [z,1] with full sequence histories. Report numerical rank/singular spectrum and the least-squares residual floor for correction and preservation targets. This separates an affine fitting conflict from an untested assertion that Adam alone failed. It establishes only finite fixed-history feasibility, not a closed-loop impossibility theorem. Check whether correction labels and preservation labels coincide or nearly coincide in z; exact incompatible duplicates cannot be solved by any deterministic head on z. Near duplicates require sensitivity to separate and are a warning, not a proof of impossibility.
- **Honest target provenance:** keep the five actual T370 intervention actions separately normalized; retain their branch identity and override mask. Do not give arbitrary neighboring states a neutral action label. Inspect existing learner-state correction data by whole route/family and keep genuine human/corrective actions distinct from parent-output preservation. In any overlap, a verified correction must not simultaneously be required to equal the erroneous parent action.
- **Functional preservation:** use the same immutable initial parent's unclipped steering-location outputs on factual histories, including early approach and each old/wide/original group. T371 already did mean matching; assess per-group and maximum deviations, correction/preservation tradeoffs, and every prior successful ID rather than only pooled loss or aggregate counts. Preserving a research parent's output also preserves its failures; it does not restore another retained model's capability. Recurrent histories must be fully unrolled from their real reset; five isolated hidden states cannot substitute for the sequence contract.
- **Data separation:** split whole trajectories or start families, not adjacent frames. Repeated native regeneration is evidence reproducibility, not independent coverage. Four extra hidden units and an offline fit improvement are inadequate grounds for native claims or promotion. A later separately registered bounded test must reproduce initial parent behavior, assess autonomous original-start outcomes, require original-success-ID retention, and repeat saved-model behavior. No new native work is authorized by this note.

## When correction aggregation should take priority

Capacity and aggregation answer different questions. If nonlinear fitting can meet correction targets with much smaller off-target changes on held-out factual families, that supports a capacity/locality pilot, while leaving closed-loop distribution shift unresolved. If fit succeeds but a learner reaches different unsupported histories, more replay of the same five corrections cannot supply the missing actions; genuine correction aggregation on learner states becomes the better-supported next direction. Existing corrections may cover some of those histories and should be inspected before requesting new human effort. No new human session is requested here.

If all fixed-z heads face incompatible labels or severe state aliasing, accumulating labels alone cannot make that frozen representation distinguish the states; the next design would need a separately motivated representation/recurrent change. Conversely, a larger head cannot invent reliable actions for unseen learner states. Therefore the narrow recommendation is **offline conflict/coverage diagnosis, then one zero-output nonlinear residual pilot with rehearsal if supported**, with learner-state correction aggregation as the next response to demonstrated coverage gaps. Neither branch has a guarantee, and neither is a new algorithm by virtue of combining these established components.
