# T199–T200：SAC均值梯度与残差位置（2026-10-30）

T199离线审计已完成，零物理/优化器更新。T200已锁定并准备，尚未开始在线训练。LEFT原始5米仍失败，T194已验证的旧六项+RIGHT保持，正式保留T159。

## 发现的局部优化障碍

现有策略先将原生均值clip到±.999999，再atanh得到SAC高斯潜变量均值，最后tanh采样。T194的原生头加.2提高速度后，在其LEFT原始冻结轨迹的151个共同状态中，约60.93%油门原生均值超过clip边界。对这些状态，潜变量油门均值对原native_head.bias的局部梯度严格0；熵项也无法通过这条均值通路调整该状态的油门均值。全局共享参数仍可从未饱和状态改变它，不是理论上永远不可训练。

T196/T197最终模型在同一共同状态集合上的饱和比例已不同，T197距离惩罚组为0。它们仍未完成LEFT，因此不能把截断单独认定为全部失败原因，也不能因修复梯度便宣布导航有效。

## 同参数量、同初始化行为的实现

两个候选都新增600→2的零初始化线性头，共1202参数：native组放在原生命令clip/atanh之前；latent组放在atanh之后。其余父网络、任务、训练目标和优化器规则相同。4096个已记录状态的确定性输出与原父策略误差均严格0，旧参数逐项不变。

在同一批饱和状态、同样八组高斯潜变量噪声下，对油门log-density熵目标求导，新头梯度范数native为0、latent为11.73525（尚未乘alpha.001）。这确认后置分支提供了可用的局部均值梯度通路，不是已学会控制/停车或LEFT5m通过。

## T200固定对照

共同初始化T194对应的零头状态；两个新头同参数量且都训练。每组32回合，四批×8，每批6个原始LEFT+2近LEFT。普通独立tanh高斯探索，不追加参数噪声，不用额外超时距离项或HER。新Critic/target/优化器，1500次Critic预热，四批各500Actor/Critic更新，七项保持权重10。

两个位置还影响动作条件数与步长，不能将所有差异只归因于“恢复一条梯度”。最终以两中心Actor原八项+12个未消费LEFT小扰动验收，原场景/目标/成功半径/时限不变。训练探索成功单列，所有失败保留，不挑最佳中间断点或自动晋升。

## 存储与恢复边界

批次前预留20MiB，覆盖行为Actor<3MiB、八个回合各<256KiB、临时完整断点<12MiB及元数据；自身峰值64MiB、最终40MiB、所有新runs硬上限1GiB。避免T197在partial分配时超出子预算的问题。

预算结束且最终验收后，通过逐参数相等核验保留Actor、Critic、target全部权重，只清除本轮不再需要的优化器payload；保留原/新文件SHA256和字节数。最终模型不支持完整优化器精确恢复，后续仅warm start，不冒充完整训练断点。
