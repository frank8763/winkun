# 与当前失败最相关的一手资料及决策

2026-11-09定向核查；非穷尽综述。以下是论文直接支持的内容与项目推论，二者分开。

| 一手资料 | 直接支持什么 | 对Stage的含义/限制 |
|---|---|---|
| [Ross等，DAgger，AISTATS 2011](https://proceedings.mlr.press/v15/ross11a.html) | 序列动作改变后续观测分布；迭代聚合策略自身分布上的标签 | 反复同示范BC不够；教师必须在学生真实history状态上有合法恢复标签。DAgger本身是已有方法 |
| [Pfrommer等，TaSIL，NeurIPS 2022](https://arxiv.org/abs/2205.14812) | 用高阶局部策略差异匹配研究稳定性；理论依赖专家增量输入状态稳定等假设 | 只匹配轨迹点动作未必保持附近反馈；不能把其条件理论直接当Stage安全保证，也不能仅加Jacobian项便称原创 |
| [Simchowitz等，连续动作模仿的陷阱，2025](https://arxiv.org/abs/2503.09722)及[Zhang等，动作块与探索增强，2025](https://arxiv.org/abs/2507.09061) | 在其连续控制假设下分析长期误差累积、动作块和探索增强的作用 | 支持先检验闭环鲁棒性，不支持“加动作块必胜”或把开环多步直接用于当前窄口。本文未复现这些方法 |
| [Ball等，RLPD，ICML 2023](https://proceedings.mlr.press/v202/ball23a.html) | 已有离线数据能够加速在线off-policy RL，但混采、critic等设计影响可靠性，并有消融 | 监督损失不是充分理由放弃RL；需要真正的新交互和价值验证。T336的工程pilot负结果不能否定整套RLPD，不能盲复制其性能数字 |
| [Tao等，RFCL，ICLR 2024](https://reverseforward-cl.github.io/)及[官方源码](https://github.com/StoneT2000/rfcl) | 结合示范反向和前向初态课程以提高示范/样本效率 | 原项目末段成功不等于原起点成功；需前向分布扩展。RFCL不是新颖性来源，不能把保留原clock的Stage工程实现声称为论文原版复现 |
| [ReIL，2022](https://arxiv.org/abs/2203.15390) | 干预式模仿与RL组合，包含实机移动导航，针对纠正后性能退化 | 与“有限恢复监督+RL”已很接近，单组合不是创新。具体效益须与同信息/预算的普通干预学习比较 |
| [Tai等，IROS 2017](https://arxiv.org/abs/1703.00420) | 稀疏激光/相对目标到连续指令的端到端RL，有仿真到实机 | 端到端无地图轮式导航可行；任务/动力学/实机目标接口与Stage不同，不保证本车全图 |
| [Pfeiffer等，RA-L 2018](https://arxiv.org/abs/1805.07095) | 示范预训练与强化学习相结合的mapless导航，有实机结果 | 训练期教师兼容部署单策略；应如实称示范辅助端到端学习，不能称从零纯RL |
| [Chiang等，AutoRL，RA-L 2019](https://arxiv.org/abs/1809.10124) | 学习P2P与路径跟随导航，并搜索奖励/结构 | P2P可借鉴；外部路点PF的长距离不能作为本项目无路点长程对照。大网格搜索也不适合当前资源 |
| [RoboRAN，TMLR，2025修订](https://arxiv.org/abs/2505.14526) | IsaacLab基础的跨机器人训练/评估/部署框架，有实机证据 | 可参考并行和真实接口；框架名曾为NavBench，以最新论文为准。换框架须先测同车同控制合同和吞吐，不是解算法的直接证据 |

## 三项可证伪干预，依顺序选择，当前未训练

1. **真实学生状态数据聚合。** 若失效源于训练分布缺恢复，则在新学生实际首偏离前后验证安全恢复并加入，应该比相同数量重复原示范提高独立自主恢复成功。比较信息/标签数/优化器预算匹配；教师失败无标签，测试全程单Actor，不许把教师控制记自主。
2. **时间局部功能保持。** 若平均保持掩盖关键动作，则同一数据和更新预算下，真实关键窗口/局部状态的保持应比轨迹均值减少新增失败。必须同时检查新技能获取；把更新全部压成零不算改善。TaSIL/稳定性匹配/信赖域是近邻，需证明本方法新增部分的区别。
3. **联合多任务学习与表示对照。** 若当前冻结表示/窄残差限制了兼容性，则从相同可复现初始化、完整新旧等权数据出发，可训表示对照应在近似训练拟合与自主面板上同时更好；若数据上就冲突或自主仍失效，容量解释被削弱。模型大小、数据、真实交互、训练与验收墙钟必须公开匹配。

T436的先后偏移只提供定位，不独立证明上述因果。近期最短可验证路线是补齐失败trace→固定一个多任务基线→只做一个针对性干预→完整开发/未见验收→长程与实机。未完成结果前不为方法起一个看似新颖的算法名，不称标准组合、数据合同或拒绝回退为安全证书。
