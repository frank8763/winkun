本轮完成了完整状态预检、128回合实际MC/PPO训练和一个动作头候选实现。**原始5米仍0/2，旧六项3/4米仍6/6，T159保留。** 新结果是近目标小扰动下的稳定性改善，不能当完整绕障或长距离能力。

## 3. 新发现：动作裁剪范围不等于当前均值策略能输出的范围

当前Actor先由600维特征压成2维Tanh，再经可训练2×2 `native_head`输出原生命令。对于一个固定保存的动作头，Tanh内部输出u∈[-1,1]^2，因此第j维均值有严格界：

`bias[j] - sum(abs(weight[j,:])) <= mean[j] <= bias[j] + sum(abs(weight[j,:]))`。

| 保存的模型 | 原生油门均值的解析下界 | 对应后轮命令下界(rad/s) |
|---|---:|---:|
| T177初始化 | 0 | 1.2500 |
| T177完整动作域组最终 | -0.002830 | 1.2429 |
| T183 keep10最终 | -0.001209 | 1.2470 |
| T187固定源最终 | -0.000523 | 约1.2487 |

原生接口为`wheel = 5*((native_throttle+1)/2)^2`，原生-1才是零驱动。以上当前确定性策略都无法请求该零驱动命令，尽管探索高斯噪声和最终动作裁剪允许[-1,1]。原生零驱动不等于主动制动、倒车或瞬间停车；实际车辆速度受动力学影响。

**需要限定这一发现：旧头本来可训练，理论上足够改变其偏置/尺度也能覆盖-1。** 这是当前检查点的实际输出域和优化参数化限制，不能定性为旧网络在所有参数下都不能停车。此前T177只放宽裁剪域，证明该具体试验未改善导航；不能据此排除“均值策略还没有学到低驱动控制”。

T187固定源组在仍保有上述下界时已经通过所有局部测试，说明它的局部改进不是由学会零驱动带来的；也说明这个限制不是全部失败的唯一解释。原始5米需要完整绕行，零驱动能力本身不能代替到达。

## 4. 已实现的动作头候选T188

新`DirectFeaturePolicy`保留父网络完整初始计算，同时增加**600维隐藏特征→2维原生命令**的线性分支，权重/偏置全部初始化0。输出为旧原生命令加内部特征分支，再按原生域裁剪；这是一个网络内的参数化变化，没有外部控制器、规划器或教师。

验证结果：4096个已存状态上初始化输出误差严格0；父参数逐项未变。诊断参数干预可表示原生油门-1，对应零后轮驱动命令，梯度路径非零。探测后参数恢复0，保存的是未训练初始化模型。**它尚未经过在线训练，没有证据证明新头优于旧头，也不能称学会停车或5米通过。**

该分支的目的是让隐藏特征能直接学习状态相关的原生控制调整，减少只在旧2维压缩输出后学习全局仿射变换的限制。旧头调大学习率、重新参数化尺度等也是需要对照的替代解释。新的初始化等价性与命令可表示性，只是进入后续RL对照的工程门槛。

## 下一步与文献边界

下一训练优先将旧头与新直接特征分支作同初始化的组件对照，同时保持原地图、最终目标、奖励和训练reset一致。只有观察到原始5米到达、旧六项保留及局部稳定性保持，才接受导航改进；只从碰撞变成原地超时不算通过。之后才扩展经实测成功率验证的局部起点区域，避免重演径向距离/直线插值课程的失败。具体有界草案见[next_protocol.md](next_protocol.md)，尚无T189训练。

训练任务按实际能力选择参考[Reverse Curriculum Generation](https://proceedings.mlr.press/v78/florensa17a.html)和[Automatic Goal Generation](https://proceedings.mlr.press/v80/florensa18a.html)的思想；本轮没有复现其全部算法，也没有实现GoalGAN。当前参数化和局部稳健性训练均不能单独支撑原创算法或顶刊有效性主张，仍需原任务、多种子、跨布局与传感误差证据。

全部协议/输入哈希、模型、成败配对与数据计量见[verification_and_metrics.json](verification_and_metrics.json)。Stage与Phase隔离，旧归档与失败证据保持不变。
