# T207参数探索策略梯度有界pilot

## 根据证据要检验的问题

T204物理动作减速覆盖确实扩展，LEFT仍0/48；T205短时干预36/36接触；T206单一局部特征方向12/12接触。它们不证明场景不可达，也不证明所有持续反馈扰动无效。下一假设是：在保留旧任务的低维参数子空间中，让整个回合保持同一神经反馈策略，并用真实整回合回报更新参数探索分布，能否产生并学会安全绕障？

## 两组及计算

三条预定义广义特征方向映射到现有神经Actor的两个动作仿射读出行，共六个系数。特征骨干冻结。每代共同4个标准高斯epsilon及反向样本，共8条原始LEFT回合/组；每条回合由单个确定性网络独立闭环。frozen组参数均值恒0，learned组用高斯参数分布的对称得分梯度估计更新均值。固定sigma，目标为原环境60秒折扣回报减10倍旧七项均衡动作MSE，未加入新奖励或学习Critic。更新的白化长度.4、Gaussian mean KL<=.08，old7硬门槛按1/.5/.25回退接受。没有按观察到的轨迹手动增加候选。

对称得分梯度与显式Gaussian参数得分估计数学检查相符；参数0时模型逐项完全相同，动作保持误差0，均值步长KL检查通过。该检查零物理步/零优化器。

此为参数探索策略梯度在现有深度策略上的低维微调，参数分布更新不等于全骨干端到端反传；执行仍是单个观测到动作Actor。与SAC/PPO和从零学习的范围明确区别。方法参考[PGPE](https://archive.air.in.tum.de/Main/Publications/Sehnke2010a.pdf)与[ES](https://arxiv.org/abs/1703.03864)，属于工程pilot，不声称新算法或论文创新。

## 预算及验收

最多8代，每组最多64探索回合。最多405全部回合、9.5M全部物理步、900秒；最后180秒只用于导出和验收。最终32MiB/峰值40MiB，全局runs1GiB/free40GiB。frozen数据单计诊断交互，learned新鲜探索单计训练交互，参数均值更新次数最多8；物理步与决策/回合分别报告。

任何样本原始LEFT安全GOAL，完成当前配对代后停止训练，按固定arm顺序/样本序号只核验首条见证，不循环挑选未预声明候选。先old7、保存模型全参数重载相同、成功轨迹精确重放，再原八项与左右各27个起点小扰动，8/8+54/54才通过稳定门槛。单次探索成功与learned中心策略通过分开报告；即使frozen首次命中也保留，不将随机命中冒充梯度学习效果。没有样本成功时，导出固定最终均值并显式原八项验收。不能把未执行的测试写成失败。
