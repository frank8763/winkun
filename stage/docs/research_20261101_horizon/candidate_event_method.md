# 候选事件价值方法：定义与上线前门槛（未训练）

令Tg是首次原生GOAL时刻，Tc是首次原生CONTACT时刻，H为本回合真实剩余物理时限。研究目标为P(Tg≤H且Tg<Tc)，同时约束旧任务的相应到达/接触退化。每步的到达与接触是竞争事件；goal-conditioned survival、failure-aware CRL和reach-avoid已有研究，这一定义与以下恒等式不是本文原创。

离散条件hazard hg(k)、hc(k)满足非负且和≤1；S(k)=∏j≤k(1-hg(j)-hc(j))，Fg(H)=Σk≤H S(k-1)hg(k)，Fc(H)=Σk≤H S(k-1)hc(k)。Fg+Fc+S=1，到达/碰撞累计概率随H非减。时限内尚无事件的质量S(H)表示该时限内未到达也未接触，不等于永远安全。真实cap超时是该目标时限内已知失败；墙钟/断电导致的行政删失，其未知后缀不得标为碰撞或永久不到达。

假设能够在同一初始分布及被比较策略的真实条件事件分布上，逐步一致控制两个hazard的误差之和≤epsilon(k)，可由标准耦合/乘积展开得到有限时域事件概率误差的累积上界min(1,Σepsilon(k))。这是普通概率敏感性界，不是已完成的神经安全证明。平均Brier/ECE、固定12点的成功率和单policy数据都不给出这种一致误差界；政策更新导致的状态分布变化也必须计入。不能删掉这些条件后宣称源任务保证。

可研究的训练方式：先用完整事件/真实删失标签学习训练侧的价值表示，预测仅使用与单Actor相容的因果观测、目标与真实剩余时间；通过整回合/家族留出校准与同状态原生动作排序门槛后，才另行锁定Actor更新协议。训练中可用旧任务风险/到达退化约束与原生验证；部署仅用一个Actor，不选路点、不切换安全策略、不做运行时优化。具体损失、网络、约束和参数尚未注册，不宣称已实现完整算法。

上线前必须解决：

1. T259紧凑轨迹删去了120维states/next_states。不能用已有动作/标签就宣称Critic训练集齐全；需要独立有界的精确状态恢复，逐数组/积分核验并计物理预算，保留原失败。行为策略随轮次更新，恢复不能全部拿最终模型重放。
2. 目标重标记必须重算所有受目标影响的因果字段和真实目标判据。初始history来自工厂旧短目标的既有语义要显式处理；只改当前三列会造成新的观测分布。不得直接在实际轨迹之前插入未来信息给Actor。
3. 先在原目标上拟合/校准，按整episode和reset家族留出；重叠训练/开发、同seed重放和大量相邻状态均不计独立样本。事件标签不输入case ID、seed、地图/障碍几何给Actor。
4. 对碰撞终止与行政删失分别建模/屏蔽，不能把碰撞当普通right-censoring；参考Safe-CRL对丢失失败质量的分析。任何新Critic要通过排序和校准，旧SAC Critic不复用。
5. 当前5–8m几何距离不等于可行运动时间，不强制在有碰撞/部分观测的空间里套欧氏或全局准度量假设。是否采用MQL/dual goal结构需单独验证。

T262现阶段仅验证1类数据契约和标准概率恒等式，没有Actor/价值训练，没有理论新颖性或安全证书。下一六米实际实验优先依据T259最终结果决定是否先检验更细课程；不把本候选直接并行接到当前训练。
