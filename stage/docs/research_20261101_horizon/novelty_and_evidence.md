# 论文主张、近邻与证据缺口

当前成果是单张已消费场景的局部3–5m基线和6m失败机制开发。6/7/8m依次达标属于工程里程碑；距离数字变大本身不足支撑顶刊。T255仅s2_reset通过，其他3组仍失败；当前保留模型无跨决策记忆，不能写GRU带来收益。warm-start继承旧RL与自身成功数据整合，不能写从零纯RL或外部专家无关的全部来源未用。211/64今后是已知回归，确定性重跑和shadow不是新训练种子。

候选主问题：在非完整观测与执行器动力学下，一个无地图单Actor如何扩展目标时域，同时保持已有reach-avoid能力？先检验能否比现有方法以更少真实交互获得更好的“新任务到达率—旧任务遗忘—碰撞风险”折中。若只得到课程或训练时间差异，收缩主张为工程结果，不包装为新算法。

| 待检验主张 | 必需受控证据 | 反证/停止条件 |
|---|---|---|
| 事件价值比旧动作MSE更能预测旧能力失守 | 整回合/起点家族留出校准；同状态动作分支MC排序；固定更新预算比较误判和旧完整回归 | 只有训练误差更小、事件概率不校准、动作排序不过关：不接Actor梯度 |
| 改进能扩展目标时域且保留旧能力 | 从相同初始化/父模型，匹配真实物理步和总预算；报告所有guard、回放、验证开销；绘制各距离完整到达/碰撞/超时与遗忘曲线 | 只有少数中心/某个seed成功或只是消耗更多仿真：不称优越 |
| 作用来自核心方法而非模块堆叠 | 分别比较固定课程/能力课程、普通MC/事件学习、函数保持/事件保持；参数量/数据量匹配 | 多项同时变化而无消融：不做单模块因果归因 |
| 适用于真实导航而非固定reset记忆 | 预先按地图/障碍布局家族切分训练、开发、最终测试；多独立训练seed、未见距离与执行器延迟/传感噪声；持续记录全部失败 | 重复同图±厘米扰动只能称局部鲁棒性 |
| 支持机器人论文贡献 | 固定单Actor部署、相同目标/安全规范；真机雷达/里程计/舵机测量、推理延迟、接触/干预记录 | MuJoCo真值输入不能直接称传感器真机端到端部署 |

近邻定位必须显式包含：SVL/SRL的时间分布和驻留目标、Safe-CRL的失败质量校正、SafeAdapt的安全保持证书、MQL/dual goal的目标表示、reach-avoid概率证书及课程基线。当前候选若只组合上述思想，不能直接称新颖。需要完整方法和作者实现复核后说明真正不同的估计量、更新约束或可证明性质，并实验验证。

统计方案草案：至少5个独立训练seed作为初步可行性规模，正式数量据方差/功效规划锁定；测试episode以训练seed、地图/起点家族分层，报告区间，不把同seed重放或同地图厘米网格当独立样本。最终测试家族在算法冻结前不访问导航结果；开发集反复消费和所有选择步骤单列。未执行/删失/无效初态不混算失败率，实际目标时限内超时则是真实任务失败。

这些是项目的论文证据计划，不是任何期刊官方录用门槛，也不保证录用。当前不启动多seed/多地图网格，不下载大数据；先完成当前有界六米和必要的新机制预检，继续遵守global1GiB与Stage隔离。
