# 2026-11-04：论文、记忆与六米失败的复盘

Stage only。本文是源码、既存模型和原始轨迹的只读复盘与下一步决策草案；新增原生物理步、导航训练、优化器更新均为0。没有启动新的记忆训练或恢复试验。Phase资料不参与。

## 结论与证据强度

当前六米研究主线没有启用跨决策循环状态；不能把现有结果描述成“已经有效使用长期记忆，仍无法导航”。已经观察到的直接问题是成功实例覆盖很窄、偏离后缺乏已证明有效的纠正，以及更新后既有成功丢失。长期记忆可能有用，但其缺失尚未被证明是六米失败的唯一或主要原因。

原窄六米仍未稳定。宽1.17m/80秒课程已有T340原起点自主成功67.064秒，以及T342另一开发起点自主成功71.584秒；不同策略各宽开发1/5。这说明宽课程至少这些实例可由单Actor实现，并不证明原窄缺口/56秒任务可达、其他起态可恢复或全地图可解。

## 为什么方法有引用，结果还不稳定

1. **成功路径与恢复动作的覆盖不同。** T340宽中心能成功，但邻域大多接触。T344从固定dx−0.03m与+0.03m两组起态得到8条新轨迹，全部接触；当前实际偏离状态上尚无已核验的成功纠正。旧成功示范可以提供监督，不能自动提供偏离后的专家动作。这是分布偏移的合理解释，尚非单因素因果证明。
2. **实际新学习数据远少于物理总账。** T344全部1,474,370物理步包括前缀、精确重放、评估和模型读回；新增训练为8条轨迹、1160次策略决策、115699原生步、16次live更新。重放是必要的复现证据，不增加独立训练样本。8条全失败仍能产生奖励/策略梯度；但不提供新的成功恢复源。增加轮数是否有效尚无证据，不能据此承诺多跑就会通过。
3. **获取与保持能力没有共同稳定。** T340宽中心成功时旧20仅2/20；T342平衡整合让旧20恢复17/20，但丢失T340原中心，改为另一宽开发起点成功。T344宽5又由初始1/5变0/5。监督误差小、优化目标改善或有参数更新，均不保证闭环路径稳定。T342/T344的相同实例前后变化支持能力丢失；不能把所有六米失败一概归为灾难性遗忘，因为新技能本身也没稳定获得。
4. **迁移方法的组成和任务前提不同。** 当前CAPG/PPO+MC同行基线+冻结残差+少量示范的工程pilot不是完整RFCL、DAPG或DAgger复现。RFCL原文使用SAC、Q集成、示范/在线回放和反向后再前向课程，主要在完全可观测操控任务评价。借用一种课程动机后失败，不能否定原算法；多个改动一起做，也不能归因其中一个组件。原窄任务的几何、可实现速度和56秒时限仍需独立证据。

另有工程限制必须分开报告：T344原audit因成熟Adam快照别名污染输入哈希而失败；追加隔离重构复现全部16实际更新与最终Actor/Adam，但不覆盖原失败。此次没有实际中断回退，不能据该bug直接断言它造成导航失败。下一实现必须用deepcopy和更新前不可变hash，验证成熟优化器状态的拒绝/中断隔离。

## 下一步的优先顺序（未注册、未启动）

**第一步是已有草案的固定失败前缀恢复可用性验证。** 按[NEXT_AFTER_T344_DRAFT.md](NEXT_AFTER_T344_DRAFT.md)，锁定已消费的两个失败前缀和一个接手时刻，完整真实执行并保留车体/执行器/clock/goal/120/history；原失败后缀作对照，T340/T342仅作固定训练资料候选。只有真正安全到达且原生精确复验后才把恢复行为用于学习。候选全失败就结束该诊断，再安排真实人工纠正，不能扫描接手时刻/模型或自动伪造专家。部署不使用接管或路由。

**第二步才是验证纠正后缀能否被学生学到并保住已会实例。** 新数据先保持完整后缀及行为来源；真人/旧策略数据不能伪造当前on-policy密度。使用既有成功中心与该恢复实例的真实闭环检查，平均MSE仅作辅助。若学生仍学不到，才有依据比较可学习表征/时序结构，而不是继续相同静态回归配方。有限实例检查不是全局安全证书，也不能替代完整旧275/原六米54门槛。

**第三步是独立的有效记忆对照，不与恢复数据、速度、场景、奖励一起更换。** 具体草案为同参数、同初始化、同数据源/预算的可训练循环残差与逐步reset对照。真实决策间传递hidden，只在真实回合开始清零；学习按因果序列重建hidden，从回合起点或明确的burn-in生成，训练/采样/读回密度与重置语义一致。要验证远处过去输入能影响后续动作、无未来信息泄漏、重载序列输出精确，并同时测新旧闭环结果。梯度截断不等于运行时hidden清零；不能通过改一个flag就声称训练完成。尚未定样本/步数/字节预算，不能当正式协议执行。

提高速度属于另一plant条件：T343已经证明提高force后直线均速增加，但冻结策略仍碰撞；不能把该动力学改变和记忆/恢复同时引入后单独归因。

目标依旧是单Actor无地图导航。原窄六米同候选旧275/275与54/54开发安全、16未消费留出和78独立模型原生重载全部通过、审计备份完成后，才另立有界七米、八米。现有未执行数据保持null。新方法作为已知基线/候选报告；论文创新需另经近邻排查、匹配消融与跨场景证据，不以模块名称或这个诊断当作创新成果。
