# T607 方法依据：逐历史投影与有限 Actor/Adam 回退

资料笔记，2026-11-16；只读研究＋本文件。未注册实验、未运行模拟器、未执行优化器，不改变 T606/T606R 的源、协议、结果或截止。Stage/Phase 完全隔离。

## 结论

建议下一独立有界试验只选 **GEM 式逐历史约束**，不同时扫 PCGrad、GEM、A-GEM。这里需要保住具体成功 ID，而平均梯度/平均损失约束允许项间补偿。投影应检查**实际 Adam 参数位移**；即使线性约束和全部历史前向检查通过，也必须经过真实闭环验收。方法是既有梯度投影思想的工程适配，不是新算法或安全证书。

本笔记采用主管任务提供的当前事实：T606 使用42完整历史的 raw/command 任务损失；T598 为未晋升研究起点、原49任务31成功；三恢复输出保持界为 .002；首 raw 候选新增1且丢旧1，因此拒绝。动态运行结果以唯一 driver 的原始记录为准。本文件不替代或重写它们。部署继续单个真实 carry 的循环 Actor，无规划器、教师或路由。

|---|---|---|
| Yu et al., **Gradient Surgery for Multi-Task Learning**, NeurIPS 2020，[原文 §2.3/Algorithm 1、§2.4](https://arxiv.org/pdf/2001.06782) | PCGrad 预先求每任务梯度；按随机顺序遇到负内积时去掉冲突分量，再汇总交给 SGD/Adam。论文包含多任务 RL 实验。 | 多任务顺序投影不能直接当作全部历史损失的联合硬约束求解器；两任务局部理论也不是循环导航闭环保持证明。Stage 历史已出现 PCGrad32（T283/T287），不能称首次引入。 |
| Lopez-Paz & Ranzato, **Gradient Episodic Memory for Continual Learning**, NeurIPS 2017，[原文 §3、式(6)–(8)](https://arxiv.org/pdf/1706.08840) | 用旧任务记忆损失作逐项不增约束；在局部线性和记忆具有代表性的假设下，投影当前梯度到满足所有旧梯度内积非负的最近方向，解二次规划。 | 正好对应“不能用新成功补偿旧 ID 失守”；但原文假设不能消除有限步非线性、历史覆盖缺口或闭环分布变化。原任务描述符/分类实验不是本 Actor 部署合同。 |
| Chaudhry et al., **Efficient Lifelong Learning with A-GEM**, ICLR 2019，[原文 §4、式(9)–(11)](https://arxiv.org/pdf/1812.00420) | 将 GEM 的多项约束替换为从全部旧记忆抽样得到的一个参考梯度约束；冲突时有单次闭式投影，降低训练开销。 | 约束平均历史损失，不逐项保持。效率优点真实，但与“31个已成功 ID 一个不能丢”的目标较弱；本轮无需再开一个 A-GEM 臂。 |
| Kingma & Ba, **Adam: A Method for Stochastic Optimization**, ICLR 2015，[原文 Algorithm 1、§2](https://arxiv.org/pdf/1412.6980) | Adam 位移由一、二阶矩、步数偏置修正和逐坐标缩放决定。 | 由更新公式可推知：原始梯度满足投影内积约束，不代表实际 Adam 位移满足相同约束。拒绝后只恢复权重会留下不同的后续优化状态；应恢复整个 Actor＋Adam。 |

## 一个有限 pilot 建议（尚未授权或启动）

1. **固定一个 raw 臂、一块最多32次提案。** 从锁定 SHA 的 T598＋fresh Adam 开始；保持42历史、标签、tail/任务权重、架构、学习率与原 raw 块一致，仅增加逐历史位移投影。最多32 live、32 shadow、32历史重构；丢弃预检另行明确计费。不能继承 T606 的剩余额度或把本文件当 launch 授权。原 T606 同初始块只作历史描述对照，不能冒称独立训练重复。
2. **逐项梯度取自原完整历史。** 锁定 T598 原49中的31个成功 ID；对其中每项定义与原 raw 完全相同的监督损失 `L_i`，从真实完整输入序列重算当前 Actor 自己的 carry，求 `h_i = ∇L_i`。不要沿用旧参数的隐状态或把逐帧数当独立样本。训练侧 ID 只索引损失，不加入 Actor 输入/部署选择。
3. **投影实际位移，不混淆符号。** 在丢弃副本作一次原 Adam 提案，得 `d_A = θ_Adam − θ_before` 及 proposed moments。求 `min_d ½‖d−d_A‖²`，约束每个旧成功历史 `h_iᵀd ≤ 0`。下降梯度写法是 `g_iᵀg ≥ 0`，参数位移写法符号相反。这是 GEM 思想用于 Adam 位移的变体，不是原版 GEM；Stage T285 已有实际位移投影，须与其失败边界并列记录。固定求解迭代上限、数值容差与零范数处理；残差不合格/非有限直接拒绝，不临时加迭代或换约束。
4. **实际有限前向门保留。** 对投影位移沿用原五个固定比例及同一先后顺序，不增加网格；从相同 before-state 形成候选。每项31历史 raw 损失均不增（仅允许预先锁定的浮点容差）、原42目标不增、三恢复相对固定成功起点的完整历史 raw 最大漂移仍≤.002，才可应用。平方保持损失在完全匹配处梯度为零，此时线性投影没有保护力，不能因此删掉有限前向门。所有历史 carry 必须重新计算。
5. **明确优化器语义并硬回退。** 接受参数 `θ_before+αd` 时保留该一次 Adam 提案的完整 moments/step（与既有位移缩放思路一致）；声明这是自定义更新。任一前向/影子/真实验收拒绝，整个 Actor、Adam moments/step及有关可变训练状态恢复到 before-state，并逐字节/哈希核验。零位移、求解失败、五比例全拒绝或整块候选闭环失守即结束，不重复同状态确定性提案、不换 seed/权重/目标域。
6. **真实保持决定研究保留。** 只对这一块最终候选执行预注册三恢复＋exact；全 safe 才按原15哨兵→补齐49＋key exact。31个初始成功 ID 全保留且至少修回一个原失败 ID，才称有原起点改善；新增1/丢旧1仍拒绝。三恢复成功使用原场景时钟/cap，不称原80秒六米通过。完整407、fresh16、reload78未测则明确 null，T550部署不替换。

实际注册前还须把原生验收、所有投影梯度/backward、live/shadow/audit、模型和原始数据的**完整最坏**物理/命令/墙钟/存储单独列入预算；不得在 T606R 活动期间编辑其源或并发运行。以上32步只是建议上限，不是可直接运行的预算。

## 可证伪问题与解释边界

记录每步投影前后各项 `h_iᵀd`、位移范数/投影比例、求解残差、实际逐项损失、三恢复最大漂移、接受比例、Actor/Adam SHA，以及最终成功 ID 的新增/丢失集合。问题是：**在同一有限学习块内，逐历史方向限制是否能得到有真实原起点新增且无旧 ID 丢失的候选？**

GEM/A-GEM 的局部记忆约束不等于闭环保持。固定历史上的预测即使很接近，学生进入自己的新状态后，动作反馈与 recurrent carry 仍可累积偏离；本笔记对此作方法推断，不声称四篇论文已证明当前 Stage 的具体失败原因。若代理门全过而旧闭环丢失，就得到“本轮代理不足”的直接反例；若投影把方向压成零，只说明该局部目标/约束/有限预算未找到可用步，不证明任务不相容、整个网络不可表示或导航无解。
