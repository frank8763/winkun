# 方法近邻与证据界限

- PPO：[Schulman et al., 2017](https://arxiv.org/abs/1707.06347)。本任务沿用截断比率与实际history条件密度；小样本平均KL并不是闭环安全或逐病例保持证书，T490已有反例。
- AWR：[Peng et al., 2019](https://arxiv.org/abs/1910.00177)。原文以价值目标拟合与优势加权动作回归利用自身/离线经验。T493采用固定权重形式与现有有界命令密度，只是AWR式适配；未复现所有超参数和实验，不能宣称原创或原论文性能。
- 自模仿：[Oh et al., 2018](https://arxiv.org/abs/1806.05635)。该文利用自身好经验，早期T479已实现辅助SIL。T493不将确定性成功均值伪装为新随机on-policy数据；本次函数保持与加权回归分别标识，不把常见组件组合当作顶刊创新证据。
- 完整回报/时间信用的比较：当前8m探索成功而确定性没稳定，完整episode credit与reward-to-go只是不同梯度估计/缩放假设，不证明新机制普遍优越。T493明确原生时间折扣、真实有限cap、无行政删失伪bootstrap、每轮完整序列h0重算和Actor/Value/双Adam拒绝回退。

所有今晚分支仍是同地图工程开发；开发54、固定初态留出、真实新地图、动力学扰动、多训练seed与实体机验证是不同证据层次。即使本协议全过，创新、统计泛化和真机安全仍需后续独立研究；不承诺顶刊接受。相机、外部规划器或运行时教师本夜不加入，避免改变用户要求的端到端部署边界。
