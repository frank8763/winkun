# T303注册后的近期近邻补查

2026-11-02。此补充不改T303已锁定输入/科学协议，也不启动另一训练。

[Direction-Conditioned Policies for Online Goal-Conditioned RL](https://arxiv.org/html/2610.05087)，2026-10-04 v1预印本：本轮查正文§1/3与附录实现概述。相对目标输入使用critic goal encoder的位移方向与模长，采集时选择已访问目标，训练时future achieved goals，部署直接用最终目标、去掉候选池/评分器。论文需要完整physical state和可提取的achieved-goal坐标，不能直接套到Stage局部雷达/120历史输入。可借鉴的是让Actor利用已验证的目标价值几何；训练侧目标选择及编码器部署都会改变当前接口/数据合同，必须独立协议和匹配对照。它没有部署路点规划，但也不能被描述成训练中完全没有中间目标。本轮没有复制或运行作者代码，预印本收益不保证Stage表现，也说明“表示方向+单Actor长距离”本身已有近邻。

[Distributionally Robust and Safe Imitation Learning](https://arxiv.org/html/2607.13436)，2026-07-15 v1预印本：本轮查§II–III方法/假设。已有TaSIL+分布鲁棒/安全目标以及L1自适应控制结构，依赖特定已知动力学结构与局部增量ISS等条件。Stage未满足/核验这些条件，额外自适应控制层也不是当前单Actor部署。仅将导数保持加安全惩罚不能据此主张原创或安全证书。本轮不实现该复合控制器。

研究决策不变：先完成T303固定描述诊断，再有证据地选择一个新学习机制，不把近期论文各取一个模块同时堆入。若进目标条件Actor-Critic，主要工作是动作价值的真实可控性、因果目标历史和安全终止语义，后续方向输入/准度量只能作为独立变量。当前六米仍未过，不进入7/8。
