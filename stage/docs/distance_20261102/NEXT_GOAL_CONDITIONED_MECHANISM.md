# 下一机制：从未来状态学习目标条件价值，而非继续修同一基线

本文件是T292失败后的新机制草案，未注册、未训练、未启动原生；不是T292/T291续预算。不混SRU、GAE、换奖励、改成功半径或长距seed网格。user已授权继续研究，但后续每个具体作业仍须完整容量/源锁/零步/备份和有界协议。

## 选择的算法方向

采用训练侧goal-conditioned contrastive actor-critic思路，借鉴CRL/Single-Goal CRL：从动作后真实经过的未来状态提取学习信号，即使尚未抵达原六米终点也能学习行为与目标的关系。部署仍一个Actor直接接真实最终目标，Critic只在训练中使用；不生成运行时子目标/路点/规划器/模型路由，不把原六米失败改写成功。这不是本项目原创方法，是否改进需新实验。

## 下一项具体工作必须先落清的合同

1. 价值语义固定。CRL的折扣future占用密度不是首次安全GOAL概率，不能用同一数值称Q成功率。若增加碰撞惩罚或改为first-hit价值，需要说明新目标及行为/续行策略，不能套原CRL等价定理。CONTACT优先，原GOAL对新目标可能是行政截断；未经过的位置是未知/对比噪声，不是假定物理不可达。
2. 先利用已有T275 goal-neutral107编码与T277原生first-hit证据，禁止重跑已结束T277。原120含目标历史，不能仅替换当前goal列后把历史观测/logp当新目标on-policy数据。新训练如果保留原目标120作为行为上下文、额外输入查询目标，须明确这是条件future预测；若训练Actor到重标记目标，须完整重建对应120及终止，不拿107编码冒充已有120。
3. 查询几何与目标可观测性。Actor部署只得当前允许的雷达/最终目标相对向量/车态；不输入未来完整场景、全局地图或仿真特权真值。Critic未来目标编码必须说明是全状态还是2D位置、相对坐标如何跨帧一致，不能把理论全状态值密度直接叫2D首次命中概率。
4. 离线Critic最先与同容量action-blind/仅几何模型比较，整轨迹/噪声家族留出，并限制Actor输出附近的真实动作支持。T272/274曾出现“预测好但动作无用”，分类AUC/对比loss下降不够。只有预先固定的同完整原生状态动作分支、相同续行策略、真实回报/首次到达排序通过，才考虑给Actor梯度。四次小脉冲T269不是这个新Critic的控制验证，不能沿用当通过。
5. 拟合通过后独立真实RL。保持safeT255父和原验收，只有新策略更新机制改变；全部采集/提案/拒绝/shadow/物理费用计账，先旧275+六米54，全部过才fresh16+78独立原生重载，六米全门槛过才七米。某个future训练目标成功或若干中心成功不晋升。

## 与旧负结果的区别及停止条件

本方向须学习动作—未来目标关系并验证控制作用，而不是重复T276正例用时回归、T272事件头或T192旧SAC-HER。缺动作支持、未来观测一致性或动作排序失败时，不连接Actor，不扫lambda/表示维数/种子/轮数。一个失败不证明整个CRL家族无效，但不借新编号加同机制预算。

当前global约1009.86MiB，仅约14MiB剩余，正式Actor+Critic训练的最坏模型/数据/完整验收容量尚未满足，不能先许诺启动；允许继续对已完整远端读回资料做真正可逆无损编码，但不把文件移到别处绕逻辑上限、不删唯一模型/视频。先准备最小明确的Critic/终止/输入合同，再锁单一有界pilot。
