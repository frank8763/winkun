# T304：先取得真实、可定义的动作价值

检索2026-11-02。只用Stage项目数据/已验证历史命名的模拟器依赖，不查看Phase。以下是方法动机，不是已实现全文算法或收益保证。

[Three Steps at a Time: Learning Representations from Action Sequences in Contrastive RL](https://arxiv.org/html/2608.30640)，2026-08-31 v1预印本：本轮读§3–5方法及局限、作者[仓库README](https://github.com/M-Korniak/action-chunked-contrastive-rl)，没有复制/运行作者源码。短动作片段给价值表示更多动作信息，但长片段的预测更好并不保证策略提取成功；不同在线/离线执行间隔的效果也有差别。其H=3给本次固定0.6秒诊断一个依据，不宣称这是Stage最优时长或所有执行器都需三步。T304只测真实固定续行MC值和小价值头，未复现其CRL、actor chunk输出或论文成绩。

[Reinforcement Learning with Action Chunking](https://arxiv.org/abs/2507.07969)：本轮核对论文摘要及[作者方法概览](https://colinqiyangli.github.io/qc/index.html)，未声称全文复现。其动作序列空间及多步价值备份提示：单步动作信息不足是可检验假设。Stage目前没有这个算法的flow行为约束/TD链，不能将一次固定短片段干预叫Q-chunking。

现有项目负结果不能跳过：T293是混合行为的future端点预测，动作模型并未明显优于盲模型；T294是safeT255在两新近目标reset上的首0.2秒三分位干预，全部超时。T304改问**有真实成功控制的原6m任务，在同一冻结T299策略下，三步局部动作对真实回报的影响能否学习并跨reset排序**。策略/起态区域/片段时长与旧实验不同，因此不是T294单因素改时长、不是通过旧失败关卡的宣言；不继续扫幅度、时机、长度、seed。

动作片段预先固定：从已消费父轨迹中间三步取drive/steer，三个分支drive逐位相同，steer只做-.03/0/+.03固定偏移。全部分支从原起点完整重走；到干预处之前必须全120/prefix相同，三步后冻结Actor在各自真实状态闭环反馈。不把反事实后的旧未来动作继续当反馈控制，不把未来响应后才选的动作塞进“预先动作片段”。

值的定义限定为三步宏动作加固定确定性续行的eta.1真实MC回报；不是某个混合噪声policy的Q、first-hit成功概率、未来占用密度、已验证策略梯度或场景不可达证明。训练/评估以原真实reward、碰撞与56秒cap为准，旧成功不被改判；不引入地图/规划器/子目标或运行时教师。

若pilot失败：不接Actor/扩步/扫片段长度；区分“干预本身没有足够回报差别”和“有差别但价值头在留出的reset预测错误”。若通过：也只说明这些固定局部动作的价值可预测，随后仍须新有界真实RL和完整6m稳定门槛，不自动晋升。
