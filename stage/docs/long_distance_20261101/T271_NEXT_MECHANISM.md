# 六米下一机制草案：失败轨迹提供的目标表征信号

本草案未注册/未启动导航训练，不延续T267/T271预算；不改原失败记录。T271两臂0/16，不追加噪声网格、不进七/八米。冻结安全T255保留，T267仅研究候选。

## 改什么，为什么

当前纯整回合MC在同起态、同cap、全部超时的一组里没有终点进展排序信号，T271实测差异仅浮点舍入。左侧则全部接触，最多从接触时刻差异得到信号。下一研究应在不改变最终任务/成功半径/碰撞规范的前提下，利用失败轨迹仍然真实到达过的未来状态，学习可达几何或有限时域事件价值。最终目标始终是真实六米目标；不生成运行时路点、图、规划或恢复控制器。

[Single-goal CRL，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/c34ddd05eb089991f06f3c5dc36836e0-Paper-Conference.pdf)提供“始终向最终目标采集、用真实未来状态进行表示学习”的相关依据。其目标是折扣占用，不能直接称为本项目的首次到达概率。[Safe-CRL，2026预印本](https://arxiv.org/abs/2608.26571)明确研究失败终止导致未来正样本归一化丢失的概率质量；直接对碰撞前未来点做普通对比训练可能再产生风险偏差。现有方法、假设与本项目不同，需正式实现/许可核对，不把标准修正冒称原创。

## 下一次可执行阶段的进入条件

1. **先完成离线数据可用性与识别性检查（可用性部分已完成）。** 固定T267原80完整120维训练记录及T271新臂16记录（32原AR/重复不补造未保存状态）；逐SHA核验Actor输入、实际动作、native_counts、终止及目标历史。不同历史Actor/课程目标分列，不把replay边际占用当更新后策略的Q值。按整回合及起态家族拆分；同seed精确重生与历史完全重合不得跨训练/验证。T271_NEXT_DATA_AUDIT已核验96记录/22,456行/4行为policy hash及全数组/前动作hold；左5.5m仅2/24随机安全、5.75m0/8，新六米双向各0/8。未来目标历史重标记与概率识别性仍未验证，未来点重标记不会凭空创造六米成功。
2. **固定一种表示学习假设，先离线验证，Actor不动。** 候选为有限物理时域、失败感知的未来目标表示；需要明确目标不变字段/目标历史重建、接触吸收/真实timeout/行政删失区别和因果输入。不得直接沿用T262原标签列序错误；原恢复契约保留。对比分数不能当校准概率，检验须包括整回合留出及同状态动作分支排序，而非只看训练loss。若无法在已有数据识别安全动作排序，明确“不足”，不接Actor梯度。
3. **只有表示/排序进入条件满足，另立新鲜在线学习协议。** 固定同初始化/同Actor容量的对照，报告全部采集、保持守卫、回放、回退及验收物理开销。用新鲜行为与正确密度更新，不把诊断干预/历史重放当on-policy数据或自动做成功BC。全Actor+Adam回退、20旧原生接受、完整旧275+六米54全过再16新导航留出与78保存重载复验；未过不进七/八米。
4. **完整磁盘合同先于启动。** 当前global剩约7.68MiB；不得再发生T267式预留不足。下一离线阶段可引用已有数组、模型放RAM并仅保留小checkpoint/清单；若新导航学习和完整终验最坏容量无法满足，先对已核验远端的结束资料作有恢复哈希账本的无损整理。保留所有失败/模型/唯一证据，global1GiB/free40GiB不扩，不能只计算训练而漏掉最终验收。

## 顶刊主张怎样保持可证伪

候选问题是无地图单Actor的“目标时域扩展—旧任务保持—接触风险”折中，不是把距离从5改成6/8就构成贡献。未来如果只有课程或通用CRL复现收益，应如实定位工程结果。若形成新估计量、约束或表示性质，再对照gSDE/LATTICE、CRL/Single-goal CRL/Safe-CRL、时间距离/准度量近邻，明确单因素消融与公平总物理预算。跨地图、独立训练seed、现实感知/延迟尚无证据；本草案不自动启动多seed/地图网格。参考研究记录exploration_and_goal_representation.md及novelty_and_evidence.md。
