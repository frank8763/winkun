# T264：梯度诊断与下一机制

T264已结束，0物理、0新增导航更新、8次仅RAM历史克隆Adam调用，37.67秒。T263原首48条数据锁定，前两轮全部8个提案的所有报告字段、Actor与Adam哈希精确重建。最后重建Actor为f7b66810f9e34f321f0b7778314ddd6d7cb3aa2858a21ca32a1e91339221f11c，即实际第三轮5.75m采集策略；没有导出或替换活动模型。

原始结果在stage/runs/t264_offline_gradient_audit/summary.json。三个行为策略的PCGrad/普通平均梯度范数比为1.1061、1.0387、1.0170；旧软保持梯度/PCGrad范数比为0、0.0837、0.3554。在第三轮四个reset组，当前合成方向与各任务损失梯度内积均为正。因此这三个批次的起始点不支持“PCGrad已把梯度消为零”或“软保持范数完全支配”解释；尚未测曲率、整个更新路径或受Adam预条件后的因果作用。原FP32余弦自对角最高1.000052是归约舍入，解释仅使用非对角及远离0的量，不能把超1数值当真实几何。

前两轮8个提案共有28个步长尝试：10个先被数值/信赖条件拒绝、10个被真实旧任务接受检查拒绝、8个接受。保留因子依次为0.25、1、0.03125、0.5、0.0625、0.5、0.015625、0.5。拒绝涉及dev_task6_24七次、hold_task6_06五次、dev_task6_00一次（同个尝试可失败多个点）。保持约束确实限制可接受步长，但移除它会允许已知旧任务失败，不能以放宽安全要求作为解决方案。

新的具体线索：r1右侧外扰04四条全部同cap超时，完整起始回报均约-0.0812181751，起始LOO优势仅浮点舍入量；该组原逐时刻代理损失梯度范数仍为7.7492。当前实现每时刻用G_t减其他回合起始回报均值，再乘起始到当前折扣。它是可用的动作无关基线，不据此判定代码有偏或数学错误；但中途势函数和已发生奖励没有同时进入对应时间的基线，可能留下明显的有限样本信号。这里没有测得跨独立采集批次的方差，不能把单批范数当总体方差或唯一失败原因。

优先检验的轻量候选是因果时间基线：保留原奖励和完整终止目标，把其他三条起始回报均值B_0转换到当前时刻，即b_t=(B_0-P_t)/gamma^t，P_t为本回合当前动作之前已经发生的折扣奖励。于是gamma^t(G_t-b_t)=G_0-B_0，每条轨迹的完整任务好坏信号保持一致。它不需要新Critic、BC、地图、教师或额外观测；实质是既有轨迹REINFORCE/控制变量形式，不是原创公式。先做T265代数/枚举和固定48系数合同，不能直接改T263。

该候选不会凭空制造左5.75m成功样本，也不保证任意任务的方差更小。左侧仍须按T263已锁规则回到有正例的课程，最终看完整旧275/新54而不是探索成功。右侧是否因此更容易把正例转成确定性策略，需要实际参数梯度和另行注册的单因素有界导航实验；PPO离开行为策略后的clip、批次RMS缩放和Adam均使简单无偏推导不足以保证最终改善。若T263结束仍未过六米，先完成审计/备份，再核定这一新机制，不能用新编号延续旧预算。

参考：[PCGrad](https://papers.neurips.cc/paper_files/paper/2020/file/3fe78a8acf5fda99de95303940a2420c-Paper.pdf)给出梯度冲突与支配分析；[CAGrad](https://proceedings.neurips.cc/paper/2021/file/9d27fdf2477ffbff837d73ef7ae23db9-Paper.pdf)讨论梯度操纵的收敛局限，不能直接把其保证移到本项目随机PPO+Adam。[Greensmith等](https://www.jmlr.org/papers/v5/greensmith04a.html)研究控制变量与基线，说明基线选择需要验证；[Ng等](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)的势函数策略不变性不等于有限样本梯度不变。以上均是已有方法依据，不构成顶刊原创性证明。
