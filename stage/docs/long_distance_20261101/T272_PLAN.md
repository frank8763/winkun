# T272：原目标有限时域竞争事件表征，第一次真实离线价值学习

背景：T271两种探索各0/16；同起点完整超时回报不区分终点距离。T262只有标签合同，没有学过价值模型；不能把它写成已上线算法。此次沿T271_NEXT_MECHANISM中的有限时域事件分支推进，**实际拟合一个新小模型，Actor、环境、目标与历史全部不改**。

## 为什么先保留原目标

T267/T271有完整120状态，但没有所有原生历史帧的生成位姿/目标见证，不能只改当前目标三列就宣称真实新目标重标记已验证。本试验不依赖该未过合同：状态保持真实原目标与历史，预测标签是该记录行为在1/2/4/8/16/32物理秒内先GOAL、先CONTACT、或尚无事件。未来标签仅进监督损失，不进入状态输入。模型输入=真实120维因果观测+当步真实执行的2维动作，禁止case/seed/policy hash、绝对位姿、地图或未来轨迹作为输入。

模型122→64Tanh→64Tanh→18，对6个时段各输出GOAL/CONTACT/存活hazard，经竞争风险递推得到累计Fg/Fc/S，保持非负、和1、Fg/Fc随时域非减。它是标准多时域事件模型，不是原创公式、Safe-CRL复现或安全证书。预测的是已有混合行为分布下的原目标事件，**不是改变Actor后的Q值，也没有识别动作干预因果**。

[Single-goal CRL（ICLR 2025）](https://proceedings.iclr.cc/paper_files/paper/2025/file/c34ddd05eb089991f06f3c5dc36836e0-Paper-Conference.pdf)提示失败轨迹仍可有学习信息；[Safe-CRL（2026预印本）](https://arxiv.org/abs/2608.26571)提示不能丢失碰撞终止信息。此处选择保留原任务的首事件监督，不直接复制其对比占用目标或把相近思想冒称新颖。未来目标重标记/对比表示仍需独立合同，不在本次隐式上线。

## 固定数据、留出与训练

只引用T267的80条原训练记录+T271新臂16条，共96条/22456决策/4行为policy hash，全部文件SHA锁定，不复制状态数据到新目录。T271原AR没有完整120状态，明确不纳入。旧历史重合标识保留，数据不是96次新交互或96独立训练seed。

所有原生(-3cm,-3cm,0deg)起态家族16完整episode作为新预测头的测试；其余80训练，跨课程距离、方向及behavior统一划分，不按相邻决策随机切分，精确轨迹签名不得跨split。该家族和地图以前已在整个Stage开发中消费，**只能称当前新头的家族留出，不能称整个导航项目未见测试**。测试只有5.25m与6m若干记录，分布与训练不完全相同，逐方向/距离结果必须同时报告。

仅训练侧、每episode等权计算输入均值方差，std下限.001，归一化后截[-10,10]。每步先均匀抽训练episode，再抽其中有有效时域标签的决策，batch64；每决策对有效时域的累计事件负对数似然取均值。固定seed2026111201、Adam lr.001、500步、梯度norm≤5；不改学习率/步数/seed，不选best checkpoint，不在失败后续训。训练中不按测试结果选择；预声明初始化及最终500步比较，最终模型和完整Adam保存。

目标标签复用T262显式修复过的native[CONTACT,GOAL,TIMEOUT]适配器，并独立测试列序、物理区间端点、真实cap和行政删失。真实timeout在已观察时域内为“无首事件”，超过原cap的标签屏蔽；行政中断未知后缀不伪造标签。此次96记录均完整，仍保留该合同以防未来误用。

对照是训练episode等权的逐时域事件频率预测及未训练同模型；不是算法/种子网格。固定描述性筛选：测试总Brier≤频率基线90%，GOAL与CONTACT各自Brier不比基线差，5-bin两事件ECE均≤.10。该门槛只是是否值得继续研究的筛选，相关决策的ECE不能给独立样本置信界。无论筛选过否，**本次都不接Actor、不做新导航，不凭预测loss声称六米通过**。
