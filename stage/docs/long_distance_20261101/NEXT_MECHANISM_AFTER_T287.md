# 下一步优先分清“提案有没有新能力”和“为何不能保留”

本文件是草案，未注册、未启动；本夜T287已结束不追加。六米完整仍0/54，safeT255与全部失败模型保留。不能将以下草案换新编号当作同一失败预算续跑。

## 1. 先补目前缺少的反事实读数

T287四个已存在的数值合格候选都因旧五米guard失败，从未测它们在真实六米/新终点的闭环表现。优先固定重建这4个已消费候选（原Actor+Adam/live-shadow报告精确，非新训练），分别冻结测原左右6米与真实终点余1米左右中心，并独立精确重生。不要换更大步长/种子/挑新候选，不用代理改善替代导航。候选一次性导出保存以免丢失原反例，所有物理必须独立注册、容量/源码/完整预检通过；这里只给候选设计，不是今夜启动授权。

若这些候选均未改善新任务，不能把失败简单归结为保持太严格；若有真实新能力且旧失败，才支持继续研究保持与适应的冲突。几个中心仍不足六米稳定/晋升。

## 2. 必要时做独立、隔离的六米学习能力消融

若反事实仍无法判定，另立有界研究对照，从同safeT255/freshAdam、相同回报/AR/seed/预算开始，仅取消**研究候选的旧20硬接受**，仍逐次记录旧20真实后果，保持原数值信赖与soft项，其余不变。该模型只供MuJoCo因果诊断，旧安全基线始终保留且不晋升、不替代部署；完整旧275/六米54最后都报告。目的区分“允许更新后能否学到六米”和“保持约束阻止获得新能力”，不能把旧任务失守包装成整体成功。

T216取消保持的旧五米专攻曾失败；它的任务、父策略与当前六米不同，不能直接作为本问题的因果答案。新的六米消融须清楚说明差异并注册，不能重跑T216或自动扩大轮数。

## 3. 若新任务学习仍弱，再检查状态条件的信用估计

现有事件头的动作盲对照否定了将其直接当Q动作排序的用法，但**状态价值baseline本来就不要求当前action输入**。因此不能用T274动作盲结果一概否定所有V(s)基线。可另提出整回合交叉拟合的状态价值控制变量：只用与当前父policy/奖励完全一致的历史轨迹，目标为真实Gt而非事件标签，整轨迹/噪声家族拆分，避免随机时间片泄漏；独立比较time-LOO与状态V的留出回报误差和梯度方差代理。未通过离线门槛不连接Actor，不把旧SAC Critic直接复用或恢复它的训练。

这是后备假设，不是本夜再加头/参数网格。批次依赖RMS、PPO剪裁与PCGrad仍影响偏差，不把baseline独立性等同完整算法无偏。

## 4. 论文创新的决策门槛

当前可成立的研究观察是：微小保存状态动作误差并不足以保持真实闭环；时间/梯度处理改变提案，但真实旧任务约束仍使所有更新回退。它们是单地图、已消费反例上的发现，尚无新算法有效性。

潜在问题是“怎样在扩展目标距离时，学习可获得新能力且保持已掌握闭环的更新”。若上述反事实和能力消融支持这个问题，才设计新的训练机制并与标准保持/投影/约束RL比较，不把组合取名就称原创。真正支撑高水平论文仍需完整6→7→8→10米结果、未见起态/障碍/地图、多个训练种子与匹配消融、计算与物理成本，以及适用条件明确的理论/解释。

[Constrained Policy Optimization, ICML 2017](https://proceedings.mlr.press/v70/achiam17a.html)已有约束策略改进；[Greensmith等, JMLR 2004](https://www.jmlr.org/papers/v5/greensmith04a.html)已有baseline/actor-critic控制变量与最优baseline分析。本轮只核对论文页和摘要，不声称审计实现/套用其保证。OGD/Adam-NSCL/TaSIL/CAPS/CLEAR等近邻及负结果见CLOSED_LOOP_RETENTION_REVIEW；自有数据合同、缓存、精确重构都不是算法原创或安全证书。
