# 下一方法草案：把“预测失败”与“学习可达目标”分开

本草案不启动训练/新seed/动作或场景网格，不给T272/274任何Actor耦合授权。T273真实方向门槛失败；T274动作可用性消融显示现有事件头主要是状态预报，不能再用更低预测loss代替导航改进。所有旧失败/模型/安全T255保留。

## 优先机制

研究用已有失败中**真实经过的未来位置**学习目标关系，而非仅拟合原终点GOAL/CONTACT。这样即使原六米全失败，也有实际运动的时间关系监督。该方向属于已有CRL/Single-goal CRL/时间距离研究范围，不是Stage已证实原创。碰撞不能当作普通无事件截断，需与Safe-CRL/事件学习近邻核对；没有原最终目标成功不等于未来表示可以保证六米可达。

下一首先完成一个零优化器、零物理的数据语义合同，固定同96记录，不新增采集：

1. 明确训练侧目标无关编码。当前120输入里的当前目标字段48:53及四历史帧目标距/角字段需要显式剥离；必须先依共享Stage依赖源码核对准确索引/全部目标依赖路径，不能仅凭旧文档硬编码。其余雷达、车速、执行器、前动作、hold和真实时间保留。它是**新训练侧编码**，不是伪称原120在新目标下已精确重建；部署Actor暂不改变。
2. 每个查询目标仅以合法请求的相对几何输入进入。用于训练的目标位置来自严格在锚点之后的真实记录next_pose，转成锚点车体坐标；绝对位姿、case/seed、地图与未来状态向量不作模型输入。未来坐标是目标监督/查询，不把未来传感器状态泄漏给Actor。
3. 首轮只定义**决策端点的未来占用/时距关系**，不称0.2m首次到达概率。已有轨迹没有所有hold内部的完整原生位置见证；必须排除碰撞终止端点，并保留实际物理时差、成功/接触/timeout及超过原cap的掩码。不把在chosen future前已经首次进入半径的中间点漏掉却声称first-hit。
4. 按完整原生起态家族及精确轨迹hash拆分，历史重生不跨split；固定采样索引/hash。验证剥离所有目标字段后的不变性、目标相对坐标变换、边界时序/接触端点/行政删失和合成泄漏测试。原目标状态/回报/导航结果全部不变；原54仍失败。
5. 合同通过后另注册一种小型未来目标表征pilot，明确预测的是哪种记录行为分布，比较简单几何/时间基线，保留整episode与家族留出。未验证动作排序前不把分数当改策略后的Q或安全概率；不复用旧SAC Critic，不把历史future数据当on-policy/成功BC。

## 真正转向Actor前

原始未来表示的训练若没有对留出方向/时间关系产生有效收益就停止该机制，不追加模型/seed网格。若有收益，下一应先定义**固定续行策略**和有区分力的任务/行为对比，所有实际原生步计入单独预算，避免继续在同一个全接触状态扫描幅度。需要由新鲜受控行为得到可检验信号，而非将混合噪声回归梯度直接外推到确定性部署。

新Actor方法只有在独立有界、完整容量预留、保存回退合同和原275+六米54/fresh16/78重载验收都已注册后才启动。当前global剩余约6.34MiB，任何新导航学习都必须先证明训练+模型+最终验收最坏容量；不能以新编号续旧预算或删未核验唯一证据。六米未过不进7/8。

## 论文定位

应检验的问题是：何种目标/行为表示在扩时域时提供真正可用的控制信号，同时保持旧reach-avoid能力？T272预测筛选、T273原生方向失败、T274动作消融共同构成“预测≠控制”的开发证据，不是现成顶刊贡献。新估计量/表示约束若只是标准CRL/课程/风险头组合，应如实表述，并以公平全部物理预算和单因素消融验证。多地图/独立训练seed/真机感知证据仍缺，不自动开网格。Stage与Phase完全隔离，无地图/规划器/路点/运行时教师或路由。
