# T261：六米学习信号的固定数据审计

只分析T259最初48条完整轨迹：两轮5.5m桥接32条、第一轮6m16条。前16是T257原数据的精确重建，不是新独立样本。此审计没有加载Actor、计算梯度、训练或步进模拟器，新增物理/优化器均0。逐文件SHA与日志固定前缀均已锁定，后续训练日志追加不扩大本审计样本。

48条原始逐步奖励的MC、直接折扣求和和闭式表达全部一致，最大误差3.28e-15。包含成功与失败的5个同reset四抽样组中，成功的完整回报全部高于失败。这排除了这些已观测数据上的奖励符号/折扣计时实现错误；不证明总体Actor梯度低方差、有效或已完成六米。

闭式表达为 G0 = 0.03*d0 - 0.000002*(1-gamma^N)/(1-gamma) + gamma^(N-1)*event，其中gamma=exp(-0.002/60)，event分别为到达+1、接触-1、超时-0.5。势函数在所有真正终止处置零，因此固定初态和固定终止事件/时间的完整回报没有最终距离项。这是原目标的数学性质，T197已有同类公式记录，不能称为本次新发现的唯一根因。

本次六米实际证据：右侧外扰07的四条都在56s超时，最终剩余分别0.824/0.384/1.263/0.923m，但四条完整回报都为-0.05182780044686（数值误差量级1e-16）。初始leave-one-out优势也近0。故这组失败数据没有用完整回报排序“更接近终点”的信息。右中心成功样本回报+0.538323、优势+0.591356，全程优势为正；到达55.788s，距56s时限只0.212s，不能说明中心策略或鲁棒扰动已通过。保存状态上成功轨迹的实际drive相对clipped保存mean的时间加权差约+0.0226，仅是描述性相关，不是油门干预因果证明。

左侧六米8条全部接触，40.372–48.242s结束。晚发生的接触可能比更接近终点但更早接触获得更高回报：左中心s2余2.331m但回报-0.305749，s3余1.718m回报-0.313583。当前数据可提供延迟接触的信号，但缺少该批六米左侧安全到达的正例。5.5米桥接左侧前两轮分别2/8、1/8安全，已有较近距离到达覆盖。不能因此判定场景不可达、网络容量不足，或SAC普遍无效。

T197已做过单独超时剩余距离项的SAC对照，原左五米仍无成功；因此不直接重复添加距离罚项。T259仍按原协议完成，不在运行中换奖励、baseline、seed、阈值、轮数或时限。完整结果后若六米门槛未过，应优先区分“没有目标到达覆盖”和“有成功却没有保留到确定性策略”两种机制，再独立锁定下一有界受控方案。

若到达覆盖是主要剩余问题，可依据GoalGAN的适当难度课程思想，评估预声明的更细独立目标距离课程；各回合从真实初态到唯一真实终点，不使用运行时路点/规划器。若有稳定成功覆盖而确定性仍不学，应先核查成功轨迹条件score与PCGrad/保持项的梯度冲突、Actor更新的实际作用，不能只加训练轮次。以上是决策草案，尚未注册/启动下一训练。六米完整旧275、新54、fresh16与重载复验全过才七米，七米过后八米。
