# 下一机制草案：同状态控制分支，未注册未启动

T268完整六米0/54（左27接触、右27超时），原已知275/275保持。当前不再自动追加同类训练、seed/噪声/奖励网格，不进七/八米。无损整理及完整冻结验收已完成，不把“验收缺测”继续作为算法原因。以下是决定下一实验的草案，不是新运行授权或已实现算法。

**优先左侧诊断问题**：在相同车体、执行器、历史观测、当前真实六米目标和剩余cap下，小的早期控制变化能否改变接触结局？末步驱动接近0.9不证明应减速，转向末命令也不证明唯一错误；需真实反事实分支，而非对不同策略/目标的曲线作因果推断。

建议只锁一个已知六米左中心、同一T267冻结Actor，首先从原初态完整重生T268该轨迹，要求全部十数组与最终积分哈希精确匹配。原生记录实际接触geom/body、舵角/角速度/车速及目标相对状态，确认碰撞对象，不从二维末位置猜测。该完整重生不是新独立样本，所有物理另计。

可在两个预先固定、均早于最早碰撞的真实时间点24s/36s捕获完整native积分、执行器/传感历史、观测与120维Actor的前动作/前hold上下文。恢复后在不干预下必须与原后缀逐数组/积分精确一致，再允许分支；只保存qpos或重新填历史不合格。无跨决策hidden也不能省略前动作和hold字段。

每个同状态仅预注册三条一次性控制分支：原神经动作、第一控制保持内转向±0.03（驱动不改，边界截断规则预注册），之后全程恢复同一神经Actor，目标始终为原六米终点，剩余物理时限不延长。六条分支用于控制反事实诊断，不部署动作切换、路点、地图或运行时教师；诊断干预不直接作为RL/BC标签使用。幅度/时间点一次锁定，失败不追加扫描。原动作后缀控制、状态恢复、所有模拟器步与墙钟/存储、未完成分支须先有独立有界协议。

若存在安全到达分支，可证明该同状态存在局部可行的控制变化，优先研究提前信用分配、控制敏感性与真实动作价值排序。若只推迟碰撞仍不能当成功；若全部失败，也不能证明场景不可达或连续动作空间无解。先据此判断是否需要更早探索/新表示，再决定新训练。旧275安全要求不降低。

右侧先利用完整轨迹分析偏航/绕行/早期速度与目标接近过程，末步已满驱动，不能只加油门。最近差2.4mm与最远差0.545m到成功半径的病例须同时解释，禁止只挑最近一例调时间/成功阈值。右侧若要做原生分支，须另锁问题和有限预算，不与左侧诊断隐式扩大网格。

任何后续事件Critic都先做整回合/起点家族留出校准和同状态动作排序，未通过就不接Actor。五米到六米时域扩展、旧能力保持与风险的科学问题仍在，但标准反事实控制、REINFORCE基线、课程及事件价值本身不是论文创新；最终需区分新机制与工程修复，并有公平总物理预算控制。下一协议还要核算实际剩余global容量，Stage/Phase完全隔离。
