# T276：真实未来目标时间关系学习pilot

目的：检验失败轨迹中的真实运动关系是否比纯几何/当前速度提供额外预测信息，不再只预测原终点的失败事件。T275合同和独立复算已通过；本次实际拟合一个新模型，仍不是Actor强化学习，不将分数当已验证控制价值。

## 固定数据与标签

只引用T275固定26395个pair（21836训练/4559留出）、96旧轨迹，拆分沿用80/16整起态家族。111输入=107移除直接目标字段的新训练侧状态+2当步实际动作+2相对查询目标XY/10。无实际delta时间、未来传感、绝对位置、case/seed或policy ID作为输入。当前真实速度、执行器、前动作/hold与原cap时钟保留；行为与cap可能体现原目标，不称统计独立。

标签为log1p从锚点到已观察非接触future端点的真实物理秒数。目标是**记录行为的正例时间关系**，不是最短路径/时域可达概率、首次进入0.2m、Safe-CRL价值或新策略Q。未经位置无可靠负标签；未来端点取样与生存偏差明确保留，不能外推成六米一定安全可达。

## 一次固定学习与基线

MLP111→64Tanh→64Tanh→1（11393参数），预测log时间。仅训练侧按每episode等权、episode内pair等权计算均值/std（下限.001）、输入归一化clip[-10,10]；输出加训练标签均值。固定seed2026111601、500 Adam lr.001、batch128、MSE、clip gradient5；每batch先均匀抽episode，再均匀抽该episode pair，不按数量给长轨迹更多权重。

两个固定非导航对照：训练标签均值常数，以及12项几何/运动/动作/时钟的加权ridge（lambda=.001，intercept不罚）。ridge项固定为1、log1p查询欧氏距、欧氏距、body XY、当前body vx/vy/归一化yaw-rate/速度模、当前drive/steer、原cap时钟。只拟合训练侧，不搜正则/特征组合。MLP不能仅比常数好就宣称学到避障；必须同时报告ridge和全部分层退化。

预先描述性筛选：整家族留出episode等权log-MAE≤ridge的90%，且六米左右各自log-MAE均不坏于ridge。报告log-RMSE、将预测物理时间clip[0,56]后的秒MAE、四方向/距离组。原始未clip的log指标仍是主指标，不用裁剪掩盖失败；不选best checkpoint、不加步/seed/参数网格。测试只做初始及最终500步指标，不参与训练/选择。

筛选不过则保留负结果，不延长。即使过也只说明正例时距信息可学习，不能据此接Actor梯度或宣布六米稳定；仍需固定续行与动作可辨识性。T272/274事件头不参与本次模型，T255安全基线与失败Actor均保持。

## 可复核与预算

0原生/物理/Actor/导航RL，新小头500优化器；300秒总、学习≤210秒，末90秒保存验收。own2MiB（完整head+Adam≤512KiB、4559留出预测≤512KiB、metadata≤1MiB），global1GiB/free40GiB完整预留。原数组和Actor只引用，特征RAM，不扩大磁盘预算。

第一次预检前补闭全部96原NPZ SHA到输入清单，初始清单保存在protocol_before_input_closure.json；科学设置/数据/seed/预算不变、没有预检错误或优化器开始。源协议/零优化器全依赖、入口、归一化/线性解、参数梯度及容量预检通过并远端完整根树核验后唯一启动。结束独立读回head/Adam500、归一化、全部留出标签/预测/索引及ridge和所有分层指标精确复算，核对父退出，再RAM完整远端读回归档。所有失败原件保留。
