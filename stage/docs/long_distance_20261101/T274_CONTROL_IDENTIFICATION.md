# 为什么事件预测头不能直接当控制价值

本说明是T272–T274的可识别性分析，不新增导航、优化器、动作分支或种子。应区分三个问题：给定记录状态/动作能否预测结局；从同状态改变动作会怎样；改掉整个Actor后续行会怎样。三者一般不相同。

## 记录行为和干预续行的差异

T272监督来自4个历史Actor及AR/feature-copula随机行为的混合。模型只输入120因果观测+当前动作，没有原Actor身份或整条随机噪声潜变量。T273在同快照强制首动作，此后续行是**固定确定性T267 Actor**。因此T272的P(event|logged observation,logged action)不能不加条件就当成P(event|do(action),fixed deterministic continuation)。

特别地，原AR的潜变量rho=.98持续相关；feature-copula的随机矩阵持续50决策。当前命令可能同时透露了未来噪声方向，这是一种预测信息，但强制改首命令并不意味着随后随机噪声也跟着改。T273更直接将随后噪声全部移除。部署Actor没有这些随机变量，不应把行为相关当成已验证的部署控制梯度。这是机制混淆的可能来源，不是本项目已经独立分离的唯一根因。

一个标准有限例子可说明“不充分”：U取±1等概率，记录动作A=U。模型一的结果Y=A；模型二Y=U。两模型观察数据(A,Y)完全相同，都可得到完美预测Y=A；干预do(A=+1)时，模型一Y恒+1，模型二Y仍均值0。仅观察预测loss不能区分二者。本例不是新定理、不是Stage物理不可识别的证明；真实车辆动作当然会影响状态。

## 下一真正学习机制需要补的内容

1. 在有界新数据协议里，明确目标是哪个**固定续行策略**及未来探索分布，避免把多个Actor/不同噪声潜状态混成同一个Q。记录必要噪声状态只可用于训练侧价值条件化，不静默扩大部署Actor输入或引入老师。
2. 获得能够区分真实事件结果的动作/行为覆盖。T269和T273目前所有同状态分支的16秒类别全平局，未给安全到达方向提供反事实排序。不能继续扫描相同状态的幅度/噪声并择优讲故事。
3. 若学习“未来目标表示”而非仅原终点事件，要完成目标依赖观测字段的因果重建，或**明确设计一个剥离旧目标字段的新训练侧状态编码**，并证明新目标只以合法请求输入进入，不能保留旧目标历史又声称已正确重标记。目标first-hit与决策端点占用是不同目标，内部hold到达标签须有原生见证或不作first-hit声称。
4. 源表示训练loss、留出校准、动作排序和真实Actor改进需分层验证。任何新表示/事件概率都与Single-goal CRL、Safe-CRL、survival GCRL和时间距离方法比对，不称首次。理论/新颖性主张需明确假设和新成分。

当前尚未完成这些进入条件。T274仅检验当前动作输入对记录事件预测是否有用，不直接解决控制，不据结果自动启动新导航。六米完整门槛未过，不进七/八米；Phase完全隔离。
